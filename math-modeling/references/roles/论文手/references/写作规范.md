# 论文写作规范

- 术语和符号严格服从 `术语表格.md`。
- 每段围绕一个明确论点，先给事实或推理，再解释其含义。
- 数值、单位、公式、图号、表号和引用前后一致。
- 不使用“专家认为”“效果显著”等无来源表述。
- 不用宣传性语言代替证据；创新点必须对应具体方法、实现和验证。
- 不虚构数据、实验、文献或官方要求。
- 两个模型得到相近结论时，如有比较价值，可如实保留并解释。
- 模型评价采用“优势与证据 → 非致命局限与适用边界 → 对应改进”的顺序；优势条目和篇幅通常约为局限的3倍，局限写具体、不重复、不泛化，避免自我否定式表述。重大缺陷必须在成稿前修复或更换模型，不留到评价部分。
- 中文或英文表达服从目标竞赛和用户要求。
