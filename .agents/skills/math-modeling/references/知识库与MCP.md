# 私有知识库与 MCP

本参考说明如何使用 `math_modeling_knowledge` MCP。它统一检索八个文字库和一个多模态库，配置、密钥和数据集 ID 由桥接程序管理，不要把密钥复制到 Skill、论文或项目产物中。

## 九库职责

| 知识库 | 主要用途 |
|---|---|
| 数学建模-建模算法库 | 模型、算法、假设、约束与求解方法 |
| 数学建模-编程实现库 | 代码实现、调试、数值计算与工程化 |
| 数学建模-竞赛规则库 | 竞赛规则、格式规范和提交要求 |
| 数学建模-领域知识库 | 跨学科背景、术语和机理知识 |
| 数学建模-论文写作库 | 论文结构、表达、图表与写作规范 |
| 数学建模-优秀案例库 | 可迁移建模思路、算法组合、验证方式，以及摘要、章节、公式图表、模型评价和附录的组织表达参考 |
| 数学建模-错题本 | 练习复盘、错误根因、已验证修正、适用条件和分阶段防错提示 |
| 数学建模-实践复盘库 | 内部完成且有真实验证证据的推理摘要、完整建模决策链、模型取舍、实现架构、验证闭环、可迁移成功经验与使用边界 |
| 数学建模-多模态库 | 独立视觉补充层；只在明确需要图片时按文本命中的来源文档、图号或主题定向检索 |

桥接器按检索范围并行查询对应库，不再默认九库混检。不要仅凭知识库名称预设结论，应按相关度、来源文档和题目条件筛选命中。

## 工具调用

### `search_math_modeling_knowledge`

参数：

- `query`：明确、独立的自然语言问题，最长 250 字。优先写清对象、目标、约束和所需证据，例如“回焊炉炉温曲线优化可采用哪些机理模型，常见目标函数与约束是什么，并返回相关曲线图”。
- `include_images`：默认 `true`。只查文字证据时设为 `false`。
- `max_images`：默认 4，范围 0～8。先用默认值，只有图片不足以判断时再增加。
- `knowledge_scope`：默认 `core`。`core` 查询5个核心文本库；`experience` 查询优秀案例、错题本和实践复盘3个经验文本库；`all` 查询全部8个文本库；`multimodal` 只查询多模态库。多模态内容不并入其他范围。

复杂问题可拆成少量聚焦查询，但不要为同一问题反复改写近义句刷检索。模型选择、规则引用、案例借鉴和图表解释均须回到题目条件核验。

完整解题默认执行两次角色不同的检索，而不是一次混合检索：

1. **核心检索**：用 `core` 获取当前题所需模型、算法、领域机理、编程实现和规则证据。
2. **经验检索**：用 `experience` 获取可迁移候选思路、历史错误、防错检查和验证设计。查询中明确“当前题是新问题”，输出时把历史经验与当前题差异分开。
3. **按需查图**：只有图像能补充结构、版面或图表信息时，才用 `multimodal` 二次检索。查询应带上前两步获得的来源文档名、图号、图题、模型名或具体视觉目标，避免把核心与经验内容重新混检。

多模态库同时覆盖核心资料和经验资料，因此不归入任何文本层，也不在 `core`、`experience` 或 `all` 中自动执行。`include_images` 只控制是否返回真实图片内容块；要检索多模态库，必须显式使用 `knowledge_scope="multimodal"`。

经验命中既不是必须照用，也不是必须隔离。采用前记录“历史经验—当前相同点—当前差异—适配方式—独立验证”；不匹配的部分舍弃，匹配的部分重新推导和实现。

## 赛题模式与案例隔离

- 默认按真实竞赛条件解题：建模阶段以题目、附件、领域知识库和建模算法库为依据，编程阶段以编程实现库为依据，论文阶段以论文写作库和规则库为依据。
- **比赛启发模式（默认）**：实际比赛、开放建模或用户未要求隔离案例时，可检索多个不同题、相似题和可迁移案例，从中归纳模型族、状态变量、目标函数、约束构造、算法组合、参数估计、稳健性与验证方法。案例用于产生和筛选候选思路，不直接提供当前题目的结论；所有采用内容都要根据当前条件重新推导、独立编码并以真实数据验证。
- **独立练习模式**：练习往届题且用户明确要求独立作答时，即使优秀案例库中存在同题论文，也先独立完成模型推导、程序运行和结果验证；主方案锁定前，不用同题案例提供模型路线、公式、参数、代码或答案。只有用户要求赛后比较时，才把同题案例与独立方案分开对照。
- 两种模式均可学习摘要信息密度、章节层级、公式/表格/图片布局、模型评价措辞和附录组织。只学习可迁移的方法和呈现方式，不复制原句、图、代码、参数或结论。
- 练习开始及建模手、编程手、论文手切换阶段，用 `experience` 范围执行“新题题型＋阶段＋风险”查询。只采用状态为“已验证”且适用条件与当前题相符的错题条目；命中只表示历史上出现过该风险，不表示当前题已经存在该错误。
- 需要复用完整成功流程时，使用“题型＋任务结构＋当前阶段＋目标/风险”查询实践复盘库。优先采用关键结果标为“已验证”的文档，迁移决策方法、模块接口和验证设计；题目特有数值只用于理解旧文证据，不得成为当前题结论。
- 练习结束后先在项目目录生成复盘报告和结构化错题条目。修正完成并验证通过后再上传；未经验证、重复、互相矛盾或仅对单次文件路径有效的内容不入库。
- 原始复盘报告和优秀案例对比报告不作为默认入库文件。先按 `实践复盘入库模板.md` 提炼，分开标注推理摘要、可迁移经验、题目特有结论、未采用方法和不适用边界；Skill 只生成本地入库稿，不自动上传。后续若发现关键结论变化，更新原文状态或将旧文标为“已失效”，避免自我强化历史错误。

## 全面交叉检索

完整建模或用户要求“参考知识库”时，执行“广搜—逐篇—交叉—综合”，不得命中一篇或少数片段后停止：

1. **广搜建集**：围绕核心对象、任务和方法检索算法、编程、领域和写作资料；查询返回的新相关来源也加入候选集。
2. **分层深挖**：分别围绕各子问题、机理、模型假设、核心公式、算法实现和误差/灵敏度检验查询四个主体库。
3. **跨库核验**：用算法库核对方法，用编程库核对实现，用领域库核对机理与参数，用写作库和规则库核对表达与格式。
4. **按模式使用案例**：比赛启发模式可在候选方案阶段检索多个案例寻找可迁移方法；独立练习模式将同题案例后置到主方案和真实结果锁定之后。无论哪种模式，案例都不得直接成为当前题目结论或数值结果的证据。
5. **综合而非拼贴**：建立简洁的来源覆盖表，记录“来源文档—可迁移方法—当前题差异—采用与否—独立验证”；最终模型必须基于当前题目重新推导和实际计算。

实践复盘库的命中属于内部经验，不是独立外部证据。它可用于缩短候选方案筛选、复用程序架构和提醒验证步骤，但不能用来证明当前题的模型正确。当前题仍须依据题目、附件、领域资料和真实运行结果重新建立证据链。

“全面”指覆盖全部直接相关来源与关键证据维度，不要求为了数量使用低相关命中。只有在新增检索不再产生新的高相关来源或实质性模型信息后，才能认为案例学习基本饱和。

检索指定优秀论文的程序语言、软件或支撑文件时：

1. 每篇论文单独查询，查询词优先包含“附录”“程序代码”“支撑材料清单”“文件名”“软件环境”等末页常见标题；程序代码通常位于论文最后几页，不要只检索正文模型描述。
2. 只把 `document` 与目标文档名完全一致的命中作为该论文证据；其他年份或其他编号的相似片段一律视为检索噪声。
3. 使用 `.m`、`clc`、`clear`、`fzero`、`fmincon`，或 `import`、`numpy`、`scipy`、`.py` 等可核验标记判断语言，优先采用论文对软件的明确声明。
4. 语义检索不是全文读取。目标附录未召回时只能写“当前召回无法确认”，不得把未命中推断为论文没有代码或使用另一种语言；能访问原文时改为逐页检查末页附录。

返回内容通常包括：

- `text_hits`：当前检索范围内文字库的统一排序结果；`core` 命中可作为主体资料，`experience` 命中只作启发和防错参考。
- `multimodal_context_hits`：围绕图片构建的上下文，用于判断图片是否真正相关。
- `images`：图片元信息。
- 交替出现的图片说明文本和 MCP 图片内容块：这是需要实际查看的原图。

图片命中为零不代表没有文字证据；图片已返回也不代表它自动支持当前结论。图中数值、坐标、图例或结构无法看清时，应说明不确定性，不得臆测。

### `math_modeling_knowledge_status`

该工具检查 Dify 连接、API 密钥以及 YAML 中的知识库名称和 ID 映射。只在以下情形调用：

1. 首次验证接入；
2. 检索工具报连接、鉴权或数据集错误；
3. 用户明确要求检查九库状态。

状态正常后直接检索，不要在每次建模任务中重复检查。

## 证据与优先级

1. 题目原文、附件和原始数据决定当前问题边界。
2. 当届官方规则、官方模板和原始发布页面优先于知识库旧资料。
3. 可追溯的论文和领域资料用于支撑机理、算法与参数依据。
4. 优秀案例可用于启发候选模型、算法和验证设计，也可用于比较与复核；不得照搬结论、参数、代码或表述，采用的方法必须经过当前题目的适配与独立验证。
5. 多模态原图用于理解图表与结构；引用时同时记录知识库名、来源文档名和图的实际含义。

不同来源冲突时，应呈现冲突、判断适用条件，并以更权威、更新且更贴合当前题目的来源为准。

## 降级处理

- MCP 未注册、服务器不可达或鉴权失败：说明当前无法访问私有知识库，继续使用题目附件、本 Skill 资料和可核验来源完成其余工作。
- 部分知识库失败：使用成功库的结果，同时列出失败库，不把“未检索到”写成“没有相关资料”。
- 原图下载失败：可使用文字上下文，但必须注明未实际看到图片，不能声称已完成视觉核验。
- 检索噪声过高：收窄查询对象和证据类型；仍不相关时舍弃命中，不为凑引用而使用。
