# 红队评审门与证据等级

本参考用于完整建模交付、赛后审稿和依据评审意见修改论文。评审手先证明“算的对象正确”，再评价“算得是否够好”。

## 必查维度

| 检查键 | 检查内容 | 常见反例或证据 |
|---|---|---|
| `domain_and_visibility` | 样本域、可见域、评价对象是否正确 | 内部点误入轮廓、未来数据泄漏、不可达状态 |
| `boundary_and_extremes` | 边界、极端值、零输入和终止事件 | 无资源、寿命结束、上下界、空集合 |
| `units_and_invariants` | 量纲、守恒、单调性和不变量 | 严格模型不得优于放松模型、概率和为1 |
| `set_and_time_measure` | 并集、交集、重叠和时间窗口 | 独立时长和不得代替联合并集 |
| `marginal_contribution` | 多资源独立效果与删除损失 | 删除资源后目标不变却声称有贡献 |
| `discrete_assignment` | 离散空间、候选生成与同预算复算 | 启发式固定指派包装成全局最优 |
| `stochastic_stability` | 多随机种子、初值和超参数 | 单一种子偶然最优、收敛曲线误读 |
| `grid_convergence` | 时间、空间、网格或采样加密 | 末级仍漂移却保留过多小数 |
| `cross_output_consistency` | 摘要、正文、表、图、附录同源 | 同一指标在两张表中不同 |

每项必须是：

- `pass`：已执行且有证据文件；
- `fail`：发现错误；
- `pending`：尚未验证；
- `na`：确实不适用，并写明理由。

## 主张证据等级

| `strength` | 允许措辞 | 最低证据 |
|---|---|---|
| `feasible` | 可行方案 | 全部硬约束和核心判据通过 |
| `budget_best` | 当前搜索预算或已比较候选中的较优方案 | 公开搜索空间、预算、多种子或候选对照 |
| `discrete_global` | 离散层全局最优候选 | 穷举或可验证地覆盖全部离散组合；连续层单独降级 |
| `global` | 全局最优 | 严格证明或具有可核验全局保证的算法与条件 |

论文手不得提高审计文件给出的等级。“收敛曲线变平”“局部扰动没有更优点”只支持局部稳定或当前预算较优，不支持全局最优。

## 多资源删除试验

对资源集合 `S` 和目标 `J` 计算：

```text
独立效果_i = J({i})
删除损失_i = J(S) - J(S\{i})
```

- 删除损失为正：可声称该资源对当前集合有正边际贡献。
- 删除损失为零：只能写冗余、备用或当前方案中无边际贡献。
- 删除损失为负：目标实现或约束处理可能错误，必须复核。

## 离散—连续耦合

1. 明确离散组合总数和覆盖约束。
2. 用低预算或上界筛选候选，但保留筛选方法和随机种子。
3. 对入围候选使用相同连续优化预算复算。
4. 报告实际比较集合、未覆盖范围和推翻条件。
5. 只有全部离散组合都被可验证覆盖时，才允许使用 `discrete_global`。

## 结果注册表

`result_registry.json` 为论文重复数值的唯一来源。每条至少包含：

```json
{
  "key": "problem3.union_duration_s",
  "value": 4.655,
  "unit": "s",
  "precision": 3,
  "source": "results/结果摘要.json",
  "generator": "python 求解.py --seed 2025"
}
```

同一 `key` 不得重复；论文构建脚本只读取注册表，不再次手写数值。

## 通过条件

- 九项检查均为 `pass` 或有理由的 `na`。
- 所有关键主张状态为 `pass`，证据和推翻条件非空。
- `critical`、`major` 发现均已关闭；`pending` 不得被包装成通过。
- `global` 主张必须具有非空的严格证明说明。
- 论文中的主张强度不高于审计等级。
