## 1. 最短路径问题 (Shortest Path Problem)

### 算法介绍

最短路径问题是指在给定网络图中，寻找两个顶点之间总权重最小的路径。

#### 1.1 Dijkstra算法

适用于**非负权图**，是求解单源最短路径的经典算法。

**核心思想**：贪心策略，每次选择距离源点最近的未访问顶点。

**算法步骤**：
1. 初始化：源点距离为0，其他顶点距离为∞
2. 选择未访问顶点中距离最小的顶点$u$
3. 松弛$u$的所有邻接边：若$dist[v] > dist[u] + w(u,v)$，则更新$dist[v]$
4. 重复2-3直到所有顶点都被访问

**时间复杂度**：$O((V+E)\log V)$（使用优先队列）

**距离更新公式**：
$$
dist[v] = \min\{dist[v], dist[u] + w(u, v)\}
$$

#### 1.2 Bellman-Ford算法

适用于**含负权边**的图，可检测负权回路。

**松弛操作**：
$$
dist[v] = \min\{dist[v], dist[u] + w(u, v)\}
$$

对所有边进行$|V|-1$轮松弛。

**时间复杂度**：$O(VE)$

#### 1.3 Floyd-Warshall算法

适用于**全源最短路径**，可处理负权边（不含负权回路）。

**状态转移方程**：
$$
dp[i][j][k] = \min\{dp[i][j][k-1], dp[i][k][k-1] + dp[k][j][k-1]\}
$$

简写为：
$$
dist[i][j] = \min\{dist[i][j], dist[i][k] + dist[k][j]\}
$$

**时间复杂度**：$O(V^3)$

```python
import heapq
import itertools
import numpy as np
import matplotlib.pyplot as plt
import networkx as nx
from matplotlib.patches import FancyArrowPatch
import warnings
# 不全局屏蔽数值或收敛警告；按具体类别诊断并记录。

# 设置中文字体 - 多字体备选防止渲染问题
plt.rcParams['font.sans-serif'] = ['SimHei', 'DejaVu Sans', 'Arial Unicode MS', 'Microsoft YaHei', 'Arial']
plt.rcParams['axes.unicode_minus'] = False

class ShortestPathAlgorithms:
    """
    最短路径算法集合
    """
    
    @staticmethod
    def _validate_graph(graph, allow_negative):
        if not isinstance(graph, dict) or not graph:
            raise ValueError("graph 必须是非空邻接字典")
        vertices = set(graph)
        for vertex, neighbors in graph.items():
            if not isinstance(neighbors, dict):
                raise ValueError(f"顶点 {vertex!r} 的邻接项必须是字典")
            unknown = set(neighbors) - vertices
            if unknown:
                raise ValueError(f"邻接表引用了未定义顶点: {unknown}")
            for neighbor, weight in neighbors.items():
                if not np.isfinite(weight):
                    raise ValueError(f"边 {vertex!r}->{neighbor!r} 的权重必须有限")
                if not allow_negative and weight < 0:
                    raise ValueError("Dijkstra 不允许负权边；改用 Bellman-Ford 等适用算法")
        return graph

    @staticmethod
    def dijkstra(graph, start, end=None):
        """
        Dijkstra最短路径算法
        :param graph: 图的邻接表 {顶点: {邻居: 权重}}
        :param start: 起点
        :param end: 终点，若为None则计算到所有点的最短路径
        :return: 最短距离字典, 前驱节点字典
        """
        graph = ShortestPathAlgorithms._validate_graph(graph, allow_negative=False)
        if start not in graph or (end is not None and end not in graph):
            raise ValueError("起点和终点必须在图中")
        distances = {vertex: float('infinity') for vertex in graph}
        distances[start] = 0
        previous = {vertex: None for vertex in graph}

        counter = itertools.count()
        pq = [(0, next(counter), start)]
        visited = set()
        
        while pq:
            current_distance, _, current = heapq.heappop(pq)
            
            if current in visited:
                continue
            visited.add(current)
            
            if end is not None and current == end:
                break
            
            for neighbor, weight in graph[current].items():
                if neighbor in visited:
                    continue
                distance = current_distance + weight
                if distance < distances[neighbor]:
                    distances[neighbor] = distance
                    previous[neighbor] = current
                    heapq.heappush(pq, (distance, next(counter), neighbor))
        
        return distances, previous
    
    @staticmethod
    def reconstruct_path(previous, start, end):
        """根据前驱节点重建路径"""
        if start not in previous or end not in previous:
            raise ValueError("start 和 end 必须存在于前驱字典")
        path = []
        current = end
        seen = set()
        while current is not None:
            if current in seen:
                raise ValueError("前驱链含环，无法重建最短路径")
            seen.add(current)
            path.append(current)
            current = previous[current]
        path.reverse()
        return path if path and path[0] == start else []
    
    @staticmethod
    def bellman_ford(graph, start):
        """
        Bellman-Ford算法（可处理负权边）
        :param graph: 图的邻接表
        :param start: 起点
        :return: 最短距离字典, 前驱节点字典, 是否存在负权回路
        """
        graph = ShortestPathAlgorithms._validate_graph(graph, allow_negative=True)
        if start not in graph:
            raise ValueError("起点必须在图中")
        distances = {vertex: float('infinity') for vertex in graph}
        distances[start] = 0
        previous = {vertex: None for vertex in graph}
        
        # 松弛操作 |V|-1 次
        for _ in range(len(graph) - 1):
            updated = False
            for u in graph:
                for v, weight in graph[u].items():
                    if distances[u] + weight < distances[v]:
                        distances[v] = distances[u] + weight
                        previous[v] = u
                        updated = True
            if not updated:
                break
        
        # 检测负权回路
        has_negative_cycle = False
        for u in graph:
            for v, weight in graph[u].items():
                if distances[u] + weight < distances[v]:
                    has_negative_cycle = True
                    break
        
        return distances, previous, has_negative_cycle
    
    @staticmethod
    def floyd_warshall(adjacency_matrix):
        """
        Floyd-Warshall全源最短路径算法
        :param adjacency_matrix: 邻接矩阵（inf表示不可达）
        :return: 距离矩阵, 前驱矩阵
        """
        dist = np.asarray(adjacency_matrix, dtype=float)
        if dist.ndim != 2 or dist.shape[0] != dist.shape[1] or dist.shape[0] == 0:
            raise ValueError("邻接矩阵必须是非空方阵")
        if np.any(np.isnan(dist)) or np.any(np.isneginf(dist)):
            raise ValueError("邻接矩阵只能使用有限权重或 +inf 表示不可达")
        dist = dist.copy()
        n = len(dist)
        next_node = np.full((n, n), None, dtype=object)
        
        # 初始化
        for i in range(n):
            for j in range(n):
                if dist[i][j] != float('infinity') and i != j:
                    next_node[i][j] = j
                if i == j:
                    dist[i][j] = min(dist[i][j], 0)
        
        # 动态规划
        for k in range(n):
            for i in range(n):
                for j in range(n):
                    if dist[i][k] + dist[k][j] < dist[i][j]:
                        dist[i][j] = dist[i][k] + dist[k][j]
                        next_node[i][j] = next_node[i][k]
        
        negative_cycle_nodes = np.where(np.diag(dist) < 0)[0]
        if len(negative_cycle_nodes):
            raise ValueError(f"存在负权回路，最短路无定义，涉及节点: {negative_cycle_nodes.tolist()}")
        return dist, next_node
    
    @staticmethod
    def reconstruct_floyd_path(next_node, start, end):
        """重建Floyd-Warshall路径"""
        if next_node[start][end] is None:
            return []
        path = [start]
        max_steps = len(next_node)
        while start != end:
            start = next_node[start][end]
            path.append(start)
            if len(path) > max_steps + 1:
                raise ValueError("路径重建超过节点数，next_node 可能含环")
        return path
```

## 2. 最小生成树问题 (Minimum Spanning Tree, MST)

### 算法介绍

最小生成树是指在一个连通的无向图中，找到一棵包含所有顶点且总权重最小的树。

#### 2.1 Prim算法

从一个顶点开始，逐步添加权重最小的边，直到包含所有顶点。

**算法步骤**：
1. 选择任意顶点作为起始点
2. 在已访问顶点和未访问顶点之间找权重最小的边
3. 将该边和对应顶点加入树
4. 重复2-3直到所有顶点都被访问

**时间复杂度**：$O(E \log V)$（使用优先队列）

#### 2.2 Kruskal算法

按边的权重从小到大选择，不形成回路则加入，直到有$V-1$条边。

**算法步骤**：
1. 将所有边按权重排序
2. 从小到大选择边
3. 若边连接两个不同连通分量，则加入
4. 重复2-3直到有$V-1$条边

使用**并查集**检测回路。

**时间复杂度**：$O(E \log E)$

### 适用范围

| 题型类型 | 典型问题 | 特征 |
|---------|---------|------|
| 网络设计 | 通信网络、电力网络 | 连接成本最小 |
| 交通规划 | 道路建设规划 | 建设费用最小 |
| 管网布局 | 水管、气管布局 | 铺设成本最小 |
| 电路设计 | PCB布线 | 线路最短 |
| 聚类分析 | 层次聚类 | 相似度最大 |

- **权重分布图**：边权重的分布
- **树状结构图**：MST的树形结构

```python
import heapq
import itertools
import numpy as np


def _validate_undirected_weighted_graph(graph):
    if not isinstance(graph, dict) or not graph:
        raise ValueError("graph 必须是非空邻接字典")
    vertices = set(graph)
    for vertex, neighbors in graph.items():
        if not isinstance(neighbors, dict):
            raise ValueError(f"顶点 {vertex!r} 的邻接项必须是字典")
        for neighbor, weight in neighbors.items():
            if neighbor not in vertices:
                raise ValueError(f"邻接表引用了未定义顶点: {neighbor!r}")
            if neighbor == vertex:
                raise ValueError("此 MST 实现不接受自环")
            if not isinstance(graph[neighbor], dict) or vertex not in graph[neighbor]:
                raise ValueError("MST 要求无向图的邻接关系双向出现")
            try:
                finite = bool(np.isfinite(weight))
            except TypeError as exc:
                raise ValueError("边权必须是有限实数") from exc
            if not finite or graph[neighbor][vertex] != weight:
                raise ValueError("无向边的双向权重必须相同且有限")
    return graph

def prim(graph):
    """
    Prim最小生成树算法
    :param graph: 图的邻接表 {顶点: {邻居: 权重}}
    :return: MST边列表, 总权重
    """
    graph = _validate_undirected_weighted_graph(graph)

    start = next(iter(graph.keys()))
    visited = set([start])
    edges = []
    counter = itertools.count()

    # 初始化优先队列
    for neighbor, weight in graph[start].items():
        heapq.heappush(edges, (weight, next(counter), start, neighbor))

    mst_edges = []
    total_weight = 0

    while edges and len(visited) < len(graph):
        weight, _, u, v = heapq.heappop(edges)

        if v in visited:
            continue

        visited.add(v)
        mst_edges.append((u, v, weight))
        total_weight += weight

        for neighbor, w in graph[v].items():
            if neighbor not in visited:
                heapq.heappush(edges, (w, next(counter), v, neighbor))

    if len(visited) != len(graph):
        raise ValueError("图不连通，不存在覆盖全部顶点的最小生成树")
    return mst_edges, total_weight

def kruskal(edges, vertices):
    """
    Kruskal最小生成树算法
    :param edges: 边列表 [(权重, 顶点1, 顶点2), ...]
    :param vertices: 顶点集合
    :return: MST边列表, 总权重
    """
    vertices = list(vertices)
    if not vertices or len(set(vertices)) != len(vertices):
        raise ValueError("vertices 必须非空且不重复")
    vertex_set = set(vertices)
    validated_edges = []
    for edge in edges:
        if len(edge) != 3:
            raise ValueError("每条边必须是 (权重, 顶点1, 顶点2)")
        weight, u, v = edge
        if u not in vertex_set or v not in vertex_set:
            raise ValueError("边端点必须存在于 vertices")
        if u == v:
            continue
        if not np.isfinite(weight):
            raise ValueError("边权必须有限")
        validated_edges.append((float(weight), u, v))

    # 并查集
    parent = {v: v for v in vertices}
    rank = {v: 0 for v in vertices}

    def find(x):
        if parent[x] != x:
            parent[x] = find(parent[x])
        return parent[x]

    def union(x, y):
        px, py = find(x), find(y)
        if px == py:
            return False
        if rank[px] < rank[py]:
            px, py = py, px
        parent[py] = px
        if rank[px] == rank[py]:
            rank[px] += 1
        return True

    # 按权重排序
    validated_edges.sort(key=lambda edge: edge[0])

    mst_edges = []
    total_weight = 0

    for weight, u, v in validated_edges:
        if union(u, v):
            mst_edges.append((u, v, weight))
            total_weight += weight
            if len(mst_edges) == len(vertices) - 1:
                break

    if len(mst_edges) != len(vertices) - 1:
        raise ValueError("图不连通，不存在覆盖全部顶点的最小生成树")
    return mst_edges, total_weight
```

## 3. 网络流问题 (Network Flow Problem)

### 算法介绍

网络流问题研究在网络中从源点到汇点的最大流量。

#### 3.1 最大流问题

**基本概念**：
- **容量**：每条边的最大流量限制$c(u,v)$
- **流量**：每条边的实际流量$f(u,v)$
- **源点**：流出的起点$s$
- **汇点**：流入的终点$t$

**流量守恒**：
$$
\sum_{v} f(v, u) = \sum_{v} f(u, v), \quad \forall u \neq s, t
$$

**容量限制**：
$$
0 \leq f(u, v) \leq c(u, v)
$$

#### 3.2 Ford-Fulkerson算法

通过寻找增广路径增加流量，直到不存在增广路径。

**残差网络**：
$$
c_f(u, v) = \begin{cases}
c(u, v) - f(u, v), & \text{如果}(u, v) \in E \\
f(v, u), & \text{如果}(v, u) \in E \\
0, & \text{否则}
\end{cases}
$$

#### 3.3 Edmonds-Karp算法

Ford-Fulkerson的实现，使用BFS找增广路径。

**时间复杂度**：$O(VE^2)$

#### 3.4 Dinic算法

使用层次图和多路增广，效率更高。

**时间复杂度**：$O(V^2E)$

#### 3.5 最小费用最大流

在最大流的基础上使总费用最小。

**目标**：
$$
\min \sum_{(u,v) \in E} f(u, v) \cdot cost(u, v)
$$

### 适用范围

| 题型类型 | 典型问题 | 特征 |
|---------|---------|------|
| 交通流 | 城市交通流量 | 通行能力 |
| 物流配送 | 货物运输调度 | 运输量最大化 |
| 通信网络 | 数据传输 | 带宽分配 |
| 电力系统 | 电力调配 | 输电容量 |
| 项目调度 | 任务分配 | 资源分配 |
| 匹配问题 | 二分图匹配 | 转化为最大流 |

### 可视化图表类型

- **网络流图**：流量/容量标注
- **残差网络图**：残差容量可视化
- **增广路径图**：增广路径高亮
- **流量分配图**：流量分配情况
- **瓶颈分析图**：瓶颈边识别

| 论文名称 | 作者 | 年份 | 来源 |
|---------|------|------|------|
| Maximal Flow Through a Network | Ford & Fulkerson | 1956 | Canadian Journal of Mathematics |

| An algorithm for fast calculation of the best route | Dinic | 1970 | Soviet Math. Dokl. |

### 代码实现要点

```python
from collections import deque
import numpy as np

class Edge:
    def __init__(self, to, rev, capacity, cost=0):
        self.to = to
        self.rev = rev
        self.capacity = capacity
        self.cost = cost

class MaxFlow:
    def __init__(self, n):
        if not isinstance(n, int) or n <= 0:
            raise ValueError("n 必须为正整数")
        self.n = n
        self.graph = [[] for _ in range(n)]

    def add_edge(self, fr, to, cap, cost=0):
        """添加边"""
        if not 0 <= fr < self.n or not 0 <= to < self.n or fr == to:
            raise ValueError("边端点必须是范围内的不同节点")
        if cap < 0 or not np.isfinite(cap) or not np.isfinite(cost):
            raise ValueError("容量必须有限非负，费用必须有限")
        forward = Edge(to, len(self.graph[to]), cap, cost)
        backward = Edge(fr, len(self.graph[fr]), 0, -cost)
        self.graph[fr].append(forward)
        self.graph[to].append(backward)

    def _validate_terminals(self, s, t):
        if not 0 <= s < self.n or not 0 <= t < self.n or s == t:
            raise ValueError("源点和汇点必须是范围内的不同节点")

    def max_flow_edmonds_karp(self, s, t):
        """Edmonds-Karp最大流"""
        self._validate_terminals(s, t)
        flow = 0
        n = len(self.graph)

        while True:
            # BFS寻找增广路径
            level = [-1] * n
            queue = deque([s])
            level[s] = 0
            parent = [(-1, -1)] * n

            while queue:
                v = queue.popleft()
                for i, edge in enumerate(self.graph[v]):
                    if edge.capacity > 0 and level[edge.to] < 0:
                        level[edge.to] = level[v] + 1
                        parent[edge.to] = (v, i)
                        queue.append(edge.to)

            if level[t] < 0:
                break

            # 计算增广量
            min_cap = float('inf')
            v = t
            while v != s:
                p, i = parent[v]
                edge = self.graph[p][i]
                min_cap = min(min_cap, edge.capacity)
                v = p

            # 更新流量
            v = t
            while v != s:
                p, i = parent[v]
                edge = self.graph[p][i]
                edge.capacity -= min_cap
                self.graph[v][edge.rev].capacity += min_cap
                v = p

            flow += min_cap

        return flow

    def min_cost_max_flow(self, s, t, maxf=float('inf')):
        """最小费用最大流（Successive Shortest Path算法）"""
        self._validate_terminals(s, t)
        if maxf <= 0:
            raise ValueError("maxf 必须为正")
        n = len(self.graph)
        res = 0
        h = [0] * n  # 势能
        prevv = [0] * n
        preve = [0] * n
        flow = 0

        while flow < maxf:
            # 队列式最短路松弛；含负费用边时不能把它误称为普通 Dijkstra。
            dist = [float('inf')] * n
            dist[s] = 0
            in_queue = [False] * n
            queue = deque([s])
            in_queue[s] = True

            while queue:
                v = queue.popleft()
                in_queue[v] = False
                for i, edge in enumerate(self.graph[v]):
                    if edge.capacity > 0 and dist[edge.to] > dist[v] + edge.cost + h[v] - h[edge.to]:
                        dist[edge.to] = dist[v] + edge.cost + h[v] - h[edge.to]
                        prevv[edge.to] = v
                        preve[edge.to] = i
                        if not in_queue[edge.to]:
                            queue.append(edge.to)
                            in_queue[edge.to] = True

            if dist[t] == float('inf'):
                break

            for v in range(n):
                if dist[v] < float('inf'):
                    h[v] += dist[v]

            # 计算增广量
            d = maxf - flow
            v = t
            while v != s:
                d = min(d, self.graph[prevv[v]][preve[v]].capacity)
                v = prevv[v]

            flow += d
            res += d * h[t]

            # 更新残差网络
            v = t
            while v != s:
                edge = self.graph[prevv[v]][preve[v]]
                edge.capacity -= d
                self.graph[v][edge.rev].capacity += d
                v = prevv[v]

        return flow, res
```

## 4. 关键路径问题 (Critical Path Method, CPM)

### 算法介绍

关键路径法用于项目管理中确定项目完成的最短时间和关键活动。

**基本概念**：
- **活动**：项目中的任务
- **持续时间**：活动需要的时间
- **最早开始时间(ES)**：活动可以开始的最早时间
- **最早完成时间(EF)**：$EF = ES + 持续时间$
- **最晚完成时间(LF)**：活动必须完成的最晚时间
- **最晚开始时间(LS)**：$LS = LF - 持续时间$
- **总时差**：$TF = LS - ES = LF - EF$

**关键路径**：总时差为0的活动组成的路径。

### 算法步骤

#### 正向计算（最早时间）
1. $ES_{start} = 0$
2. $EF_i = ES_i + 持续时间_i$
3. $ES_j = \max\{EF_i\}$（所有前驱活动$i$）

#### 反向计算（最晚时间）
1. $LF_{end} = EF_{end}$
2. $LS_i = LF_i - 持续时间_i$
3. $LF_i = \min\{LS_j\}$（所有后继活动$j$）

### 适用范围

| 题型类型 | 典型问题 | 特征 |
|---------|---------|------|
| 项目管理 | 工程项目进度 | 活动依赖关系 |
| 生产调度 | 车间作业调度 | 工序约束 |
| 软件开发 | 软件项目计划 | 任务依赖 |
| 建筑工程 | 建筑进度规划 | 工序安排 |
| 活动策划 | 大型活动筹备 | 时间管理 |

### 可视化图表类型

- **网络图**：活动依赖关系图
- **甘特图**：活动时间安排
- **关键路径图**：关键路径高亮
- **时差分析图**：各活动时差
- **PERT图**：不确定时间的项目管理

### 关键文献

| 论文名称 | 作者 | 年份 | 来源 |
|---------|------|------|------|
| Critical-Path Planning and Scheduling | Kelley & Walker | 1959 | Proceedings of the Eastern Joint Computer Conference |

### 代码实现要点

```python
from collections import deque
import math
import sys

def critical_path_method(activities):
    """
    关键路径法
    :param activities: 活动列表 {活动名: {'duration': 持续时间, 'predecessors': [前驱活动]}}
    :return: 一条关键路径, 各活动时间参数, 项目总工期
    """
    if not isinstance(activities, dict) or not activities:
        raise ValueError("activities 必须是非空字典")

    # 校验活动合同并建立邻接结构
    validated_predecessors = {}
    durations = {}
    successors = {activity: [] for activity in activities}
    for activity, data in activities.items():
        if not isinstance(data, dict) or 'duration' not in data or 'predecessors' not in data:
            raise ValueError(f"活动 {activity!r} 必须含 duration 和 predecessors")
        try:
            duration = float(data['duration'])
        except (TypeError, ValueError, OverflowError) as exc:
            raise ValueError(f"活动 {activity!r} 的持续时间必须是有限非负实数") from exc
        predecessors = data['predecessors']
        if not math.isfinite(duration) or duration < 0:
            raise ValueError(f"活动 {activity!r} 的持续时间必须有限非负")
        if isinstance(predecessors, (str, bytes)):
            raise ValueError(f"活动 {activity!r} 的 predecessors 必须是活动名序列")
        try:
            predecessors = list(predecessors)
        except TypeError as exc:
            raise ValueError(f"活动 {activity!r} 的 predecessors 必须是活动名序列") from exc
        if len(set(predecessors)) != len(predecessors):
            raise ValueError(f"活动 {activity!r} 的前驱不能重复")
        validated_predecessors[activity] = predecessors
        durations[activity] = duration

    # 添加依赖关系边
    for activity, predecessors in validated_predecessors.items():
        for pred in predecessors:
            if pred not in activities or pred == activity:
                raise ValueError(f"活动 {activity!r} 含未知前驱或自依赖: {pred!r}")
            successors[pred].append(activity)

    # Kahn 拓扑排序；保留用户字典顺序，避免要求异构活动名可比较。
    indegree = {
        activity: len(predecessors)
        for activity, predecessors in validated_predecessors.items()
    }
    ready = deque(activity for activity in activities if indegree[activity] == 0)
    topo_order = []
    while ready:
        activity = ready.popleft()
        topo_order.append(activity)
        for successor in successors[activity]:
            indegree[successor] -= 1
            if indegree[successor] == 0:
                ready.append(successor)
    if len(topo_order) != len(activities):
        raise ValueError("活动依赖图含环，关键路径无定义")

    # 正向计算（最早时间）
    ES = {}
    EF = {}
    for activity in topo_order:
        duration = durations[activity]
        predecessors = validated_predecessors[activity]
        if predecessors:
            ES[activity] = max(EF[pred] for pred in predecessors)
        else:
            ES[activity] = 0
        EF[activity] = ES[activity] + duration

    # 反向计算（最晚时间）
    project_duration = max(EF.values())
    LF = {}
    LS = {}

    for activity in reversed(topo_order):
        duration = durations[activity]
        activity_successors = successors[activity]
        if activity_successors:
            LF[activity] = min(LS[succ] for succ in activity_successors)
        else:
            # 所有终止活动共享项目完工时刻；较短终止支路因此保留正确时差。
            LF[activity] = project_duration
        LS[activity] = LF[activity] - duration

    # 计算总时差
    TF = {activity: LS[activity] - ES[activity] for activity in activities}

    # 找出关键路径（时差为0的活动）
    tolerance = (
        sys.float_info.epsilon * max(1.0, abs(project_duration))
        * max(1, len(activities)) * 32
    )
    critical_activities = {act for act in activities if abs(TF[act]) <= tolerance}

    # 构建关键路径
    critical_path = []
    starts = sorted(
        (act for act in critical_activities if abs(ES[act]) <= tolerance),
        key=repr,
    )
    for start in starts:
        path = [start]
        current = start
        while EF[current] < project_duration - tolerance:
            candidates = sorted(
                (
                    succ for succ in successors[current]
                    if succ in critical_activities
                    and abs(EF[current] - ES[succ]) <= tolerance
                ),
                key=repr,
            )
            if not candidates:
                break
            current = candidates[0]
            path.append(current)
        if abs(EF[path[-1]] - project_duration) <= tolerance:
            critical_path = path
            break
    if not critical_path:
        raise RuntimeError("关键活动子图未能重建从开工到完工的关键路径")

    # 汇总时间参数
    time_params = {}
    for activity in activities:
        time_params[activity] = {
            'ES': ES[activity],
            'EF': EF[activity],
            'LS': LS[activity],
            'LF': LF[activity],
            'TF': TF[activity],
            'critical': activity in critical_activities,
        }

    return critical_path, time_params, project_duration
```

## 5. 欧拉路径与哈密顿路径

### 算法介绍

#### 5.1 欧拉路径

**定义**：经过图中每条边恰好一次的路径。

**存在条件**：
- 欧拉回路：所有顶点度数为偶数
- 欧拉路径：恰好两个顶点度数为奇数

**Fleury算法**：
1. 选择起点（度数为奇数的顶点或任意顶点）
2. 沿边前进，避免走桥边（除非无其他选择）
3. 直到回到起点（回路）或无法继续

**Hierholzer算法**：
1. 从任意顶点开始，沿边前进回到起点形成回路
2. 若有未访问边，将回路分解并合并

#### 5.2 哈密顿路径

**定义**：经过图中每个顶点恰好一次的路径。

**哈密顿回路**：起点和终点相同的哈密顿路径。

**NP完全问题**：没有多项式时间算法。

**求解方法**：
- 回溯法（小规模）
- 动态规划（中等规模）
- 启式算法（大规模）

### 适用范围

| 题型类型 | 典型问题 | 特征 |
|---------|---------|------|
| 路线规划 | 邮递员送信 | 中国邮递员问题 |
| 巡回路线 | 巡检路线 | 经过每条边 |
| 环球旅行 | 旅游规划 | 经过每个城市 |
| 基因测序 | DNA片段组装 | 超级路径问题 |
| 电路设计 | PCB布线 | 笔画问题 |

### 可视化图表类型

- **路径图**：欧拉/哈密顿路径可视化
- **度数分布图**：顶点度数分布
- **搜索树图**：回溯搜索过程
- **对比图**：欧拉路径vs哈密顿路径

| 论文名称 | 作者 | 年份 | 来源 |

```python
from collections import deque


def _validate_simple_undirected_graph(graph):
    if not isinstance(graph, dict) or not graph:
        raise ValueError("graph 必须是非空无向简单图邻接字典")
    vertices = set(graph)
    normalized = {}
    for vertex, raw_neighbors in graph.items():
        if isinstance(raw_neighbors, (str, bytes)):
            raise ValueError("邻接项必须是顶点序列，不能是字符串")
        neighbors = list(raw_neighbors)
        if len(set(neighbors)) != len(neighbors) or vertex in neighbors:
            raise ValueError("此实现要求无重复边、无自环的简单图")
        if any(neighbor not in vertices for neighbor in neighbors):
            raise ValueError("邻接表引用了未定义顶点")
        normalized[vertex] = set(neighbors)
    for vertex, neighbors in normalized.items():
        if any(vertex not in normalized[neighbor] for neighbor in neighbors):
            raise ValueError("无向图的每条边必须在两个端点的邻接表中同时出现")

    nonisolated = {vertex for vertex, neighbors in normalized.items() if neighbors}
    if nonisolated:
        start = next(iter(nonisolated))
        reached = {start}
        queue = deque([start])
        while queue:
            current = queue.popleft()
            for neighbor in normalized[current]:
                if neighbor not in reached:
                    reached.add(neighbor)
                    queue.append(neighbor)
        if reached != nonisolated:
            raise ValueError("含边顶点不连通，不存在覆盖全部边的欧拉迹")
    return normalized


def has_eulerian_path(graph):
    """判断是否存在欧拉路径"""
    graph = _validate_simple_undirected_graph(graph)
    odd_degree_count = sum(len(neighbors) % 2 for neighbors in graph.values())
    return odd_degree_count == 0 or odd_degree_count == 2

def hierholzer_eulerian_circuit(graph, start):
    """Hierholzer算法找欧拉回路"""
    graph = _validate_simple_undirected_graph(graph)
    if start not in graph:
        raise ValueError("start 必须是图中顶点")
    if any(len(neighbors) % 2 for neighbors in graph.values()):
        raise ValueError("存在奇度顶点，只可能有欧拉路径而非欧拉回路")
    if any(graph.values()) and not graph[start]:
        raise ValueError("有边图的起点不能是孤立顶点")
    circuit = []
    stack = [start]
    current_path = {vertex: set(neighbors) for vertex, neighbors in graph.items()}

    while stack:
        current = stack[-1]
        if current_path[current]:
            next_vertex = next(iter(current_path[current]))
            current_path[current].remove(next_vertex)
            current_path[next_vertex].remove(current)
            stack.append(next_vertex)
        else:
            circuit.append(stack.pop())

    circuit = circuit[::-1]
    edge_count = sum(len(neighbors) for neighbors in graph.values()) // 2
    if len(circuit) != edge_count + 1:
        raise RuntimeError("Hierholzer 结果未覆盖全部边")
    return circuit

def hamiltonian_path(graph):
    """回溯法找哈密顿路径"""
    graph = _validate_simple_undirected_graph(graph)
    vertices = list(graph.keys())
    n = len(vertices)
    path = []
    visited = set()

    def backtrack(current):
        path.append(current)
        visited.add(current)

        if len(path) == n:
            return True

        for neighbor in graph[current]:
            if neighbor not in visited:
                if backtrack(neighbor):
                    return True

        visited.remove(current)
        path.pop()
        return False

    for start in vertices:
        if backtrack(start):
            return path

    return None
```

## 6. 匹配问题

### 算法介绍

匹配是指图中一组没有公共顶点的边。

#### 6.1 二分图最大匹配

**定义**：在二分图中找边数最多的匹配。

**匈牙利算法**：
1. 初始匹配为空
2. 寻找增广路径
3. 沿增广路径增加匹配
4. 重复直到无增广路径

**时间复杂度**：$O(VE)$

#### 6.2 最大权匹配

在带权图中找总权重最大的匹配。

**KM算法**（Kuhn-Munkres）：
- 适用于完全二分图
- 使用顶标和相等子图
- 时间复杂度：$O(V^3)$

### 适用范围

| 题型类型 | 典型问题 | 特征 |
|---------|---------|------|
| 任务分配 | 人员分配任务 | 二分图匹配 |
| 婚姻匹配 | 男女婚配 | 稳定匹配 |
| 课程排课 | 教师课程分配 | 匹配问题 |
| 器官移植 | 供体受体匹配 | 权重匹配 |
| 运输调度 | 司机车辆分配 | 最大权匹配 |

### 可视化图表类型

- **二分图**：二分图结构可视化
- **匹配边图**：匹配边高亮
- **增广路径图**：增广路径显示
- **权重标注图**：边的权重标注

### 关键文献

| 论文名称 | 作者 | 年份 | 来源 |

### 代码实现要点

```python
import numpy as np
from scipy.optimize import linear_sum_assignment


def hungarian_algorithm(cost_matrix, maximize=False):
    """
    匈牙利算法解决指派问题
    :param cost_matrix: 成本矩阵
    :param maximize: False 求最小成本，True 求最大收益
    :return: 目标值和匹配索引；矩形矩阵匹配较小一侧的全部对象
    """
    costs = np.asarray(cost_matrix, dtype=float)
    if (costs.ndim != 2 or costs.shape[0] < 1 or costs.shape[1] < 1
            or np.any(~np.isfinite(costs))):
        raise ValueError("cost_matrix 必须是非空有限二维数组")
    if not isinstance(maximize, (bool, np.bool_)):
        raise ValueError("maximize 必须是布尔值")
    row_indices, column_indices = linear_sum_assignment(costs, maximize=maximize)
    matching = list(zip(row_indices.tolist(), column_indices.tolist()))
    objective_value = float(costs[row_indices, column_indices].sum())
    return objective_value, matching
```

## 图论算法选择指南

图算法由任务、权重与结构共同决定，顶点数本身不能形成跨问题阈值。必须同时记录边数、稀疏性、方向、权重符号、容量/费用、动态图性质、查询次数和精确性要求。

| 决策维度 | 必查问题 | 候选方法与边界 |
|---|---|---|
| 最短路查询 | 单源、两点还是全源；是否存在负权或负环 | 非负权可用 Dijkstra；含负权用 Bellman–Ford/Johnson 等并检查负环；Floyd–Warshall 适合内存允许的稠密全源场景 |
| 启发信息 | 是否有可证明可采纳且最好一致的启发函数 | A* 只有在启发条件满足时保留相应最优性；“图很大”本身不是采用 A* 的理由 |
| 连通与生成结构 | 需要最小生成树、Steiner 结构还是有向树 | Prim/Kruskal 解决 MST，不可直接替代 Steiner、方向或额外约束问题 |
| 流与费用 | 容量、费用、供需、下界和多商品是否存在 | 最大流、最小费用流或线性/整数规划；算法选择结合复杂度、负费用环和数值范围 |
| 匹配与指派 | 图是否二分、是否带权、是否要求完美匹配 | 增广路、Hopcroft–Karp、匈牙利/指派算法或一般图匹配，不能把所有配对都写成匈牙利算法 |
| 路径覆盖 | 要经过每条边还是每个顶点，允许重复和优化什么 | 欧拉问题与哈密顿/TSP 的复杂度和判据不同，必须先区分对象 |
| 时变与不确定 | 边权是否随时间、状态或情景变化 | 时间依赖最短路、动态图算法、情景/鲁棒网络模型；静态最短路不能直接复用 |
| 存储与规模 | $V$、$E$、密度、查询批量和内存上限如何 | 邻接表/矩阵、堆结构、并行与分解按实测瓶颈选择，报告时间和空间复杂度而非固定规模档位 |

用手算小图、守恒关系、割容量、路径可行性和小规模枚举作为 oracle。若只筛选了部分路径、指派或网络结构，只能陈述候选范围内结论。
