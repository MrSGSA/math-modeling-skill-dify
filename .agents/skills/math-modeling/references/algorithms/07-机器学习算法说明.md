## 1. 随机森林 (Random Forest)

### 算法介绍

随机森林是一种集成学习方法，通过构建多棵决策树并合并它们的预测结果来提高模型的泛化能力和稳定性。

#### 1.1 基本原理

**Bagging（Bootstrap Aggregating）**：
- 有放回抽样生成多个训练集
- 每个训练集训练一个基学习器
- 合并预测结果（投票或平均）

**随机特征选择**：
- 每个节点分裂时，随机选择一部分特征
- 增加树之间的多样性
- 减少方差

#### 1.2 回归随机森林

**预测**：
$$
\hat{y} = \frac{1}{T} \sum_{t=1}^{T} f_t(x)
$$

其中$T$是树的数量，$f_t(x)$是第$t$棵树的预测值。

**OOB误差（Out-of-Bag Error）**：
- 使用未被抽样的样本（袋外数据）验证
- 交叉验证的替代方案

#### 1.3 分类随机森林

**多数投票**：
$$
\hat{y} = \arg\max_{c} \sum_{t=1}^{T} \mathbb{I}(f_t(x) = c)
$$

**概率估计**：
$$
P(c|x) = \frac{1}{T} \sum_{t=1}^{T} \mathbb{I}(f_t(x) = c)
$$

#### 1.4 特征重要性

**Gini重要性**：
$$
GI_j = \frac{1}{T} \sum_{t=1}^{T} \Delta GI_{jt}
$$

其中$\Delta GI_{jt}$是特征$j$在树$t$中带来的Gini不纯度减少量。

**置换重要性**：
- 随机打乱某特征值
- 观察预测误差的变化
- 误差增加越多，特征越重要

### 适用范围

| 题型类型 | 典型问题 | 特征 |
|---------|---------|------|
| 分类预测 | 客户流失、疾病诊断 | 分类标签 |
| 回归预测 | 房价、销量预测 | 连续目标 |
| 特征选择 | 关键特征识别 | 高维数据 |
| 异常检测 | 欺诈检测 | 不平衡数据 |
| 非线性与交互 | 复杂表格数据 | 可学习分段非线性与变量交互 |

### 可视化图表类型

- **特征重要性图**：各特征重要性排序
- **决策树可视化**：单棵树结构
- **OOB误差曲线**：误差随树数变化
- **偏依赖图**：特征对预测的影响
- **类别概率图**：分类概率分布

### 代码实现要点

```python
import numpy as np
from sklearn.ensemble import RandomForestClassifier, RandomForestRegressor
from sklearn.metrics import accuracy_score, mean_squared_error
import matplotlib.pyplot as plt

def random_forest_classification(X_train, y_train, X_test, y_test,
                                  n_estimators=100, max_depth=None, random_state=42):
    """
    随机森林分类
    :param X_train: 训练特征
    :param y_train: 训练标签
    :param X_test: 测试特征
    :param y_test: 测试标签
    :return: 模型, 预测结果, OOB分数
    """
    rf = RandomForestClassifier(
        n_estimators=n_estimators,
        max_depth=max_depth,
        random_state=random_state,
        oob_score=True,
        n_jobs=-1
    )

    rf.fit(X_train, y_train)
    y_pred = rf.predict(X_test)
    y_proba = rf.predict_proba(X_test)

    accuracy = accuracy_score(y_test, y_pred)

    return rf, y_pred, y_proba, accuracy, rf.oob_score_

def random_forest_regression(X_train, y_train, X_test, y_test,
                              n_estimators=100, max_depth=None, random_state=42):
    """
    随机森林回归
    :param X_train: 训练特征
    :param y_train: 训练目标
    :param X_test: 测试特征
    :param y_test: 测试目标
    :return: 模型, 预测结果, MSE, OOB分数
    """
    rf = RandomForestRegressor(
        n_estimators=n_estimators,
        max_depth=max_depth,
        random_state=random_state,
        oob_score=True,
        n_jobs=-1
    )

    rf.fit(X_train, y_train)
    y_pred = rf.predict(X_test)

    mse = mean_squared_error(y_test, y_pred)

    return rf, y_pred, mse, rf.oob_score_

def plot_feature_importance(rf_model, feature_names, top_n=20):
    """
    绘制特征重要性
    :param rf_model: 随机森林模型
    :param feature_names: 特征名称列表
    :param top_n: 显示前N个特征
    """
    importances = rf_model.feature_importances_
    indices = np.argsort(importances)[::-1][:top_n]

    plt.figure(figsize=(10, 6))
    plt.bar(range(len(indices)), importances[indices])
    plt.xticks(range(len(indices)), [feature_names[i] for i in indices], rotation=90)
    plt.xlabel('Feature')
    plt.ylabel('Importance')
    plt.title('Feature Importance (Random Forest)')
    plt.tight_layout()
    plt.show()

def plot_oob_score(X, y, task, max_estimators=200,
                   min_estimators=10, step=5, random_state=42):
    """
    绘制OOB分数随树数变化。

    task 必须由题目中目标变量的语义明确指定，不能根据唯一值个数猜测：
    整数型连续计数仍可能是回归，类别编码也可能有很多水平。
    :param X: 特征矩阵
    :param y: 目标变量
    :param task: 'classification' 或 'regression'
    :param max_estimators: 最大树数
    """
    if task not in {'classification', 'regression'}:
        raise ValueError("task 必须为 'classification' 或 'regression'")
    if min_estimators < 1 or step < 1 or max_estimators < min_estimators:
        raise ValueError("树数范围必须为正且 max_estimators >= min_estimators")

    estimator_counts = list(range(min_estimators, max_estimators + 1, step))
    oob_scores = []

    for n in estimator_counts:
        if task == 'classification':
            rf = RandomForestClassifier(n_estimators=n, oob_score=True,
                                        random_state=random_state, n_jobs=-1)
        else:
            rf = RandomForestRegressor(n_estimators=n, oob_score=True,
                                       random_state=random_state, n_jobs=-1)
        rf.fit(X, y)
        oob_scores.append(rf.oob_score_)

    plt.figure(figsize=(10, 6))
    plt.plot(estimator_counts, oob_scores, 'o-')
    plt.xlabel('Number of Trees')
    plt.ylabel('OOB Score')
    plt.title(f'Random Forest ({task}): OOB Score vs Number of Trees')
    plt.show()
    return estimator_counts, oob_scores

def plot_partial_dependence(rf_model, X, feature_names, feature_idx):
    """
    绘制偏依赖图
    :param rf_model: 随机森林模型
    :param X: 特征矩阵
    :param feature_names: 特征名称
    :param feature_idx: 特征索引
    """
    from sklearn.inspection import PartialDependenceDisplay

    PartialDependenceDisplay.from_estimator(rf_model, X, [feature_idx],
                                              feature_names=feature_names,
                                              kind='average')
    plt.show()
```

## 2. AdaBoost (Adaptive Boosting)

### 算法介绍

AdaBoost是一种自适应提升算法，通过迭代训练弱分类器并调整样本权重来构建强分类器。

#### 2.1 基本原理

**核心思想**：
- 训练一系列弱分类器
- 每轮关注之前分类错误的样本
- 组合多个弱分类器形成强分类器

**算法流程**：

1. 初始化样本权重：$w_i^{(1)} = 1/n$，$i = 1, 2, \ldots, n$

2. 对于$t = 1, 2, \ldots, T$：
   - 使用权重$w^{(t)}$训练弱分类器$h_t(x)$
   - 计算分类错误率：$\epsilon_t = \sum_{i=1}^{n} w_i^{(t)} \mathbb{I}(y_i \neq h_t(x_i))$
   - 计算分类器权重：$\alpha_t = \frac{1}{2} \ln\left(\frac{1-\epsilon_t}{\epsilon_t}\right)$
   - 更新样本权重：
     $$
     w_i^{(t+1)} = \frac{w_i^{(t)} \exp(-\alpha_t y_i h_t(x_i))}{\sum_{j=1}^{n} w_j^{(t)} \exp(-\alpha_t y_j h_t(x_j))}
     $$

3. 最终分类器：
   $$
   H(x) = \text{sign}\left( \sum_{t=1}^{T} \alpha_t h_t(x) \right)
   $$

#### 2.2 AdaBoost变体

**AdaBoost.M1**：二分类版本

**AdaBoost.M2**：多分类版本

**AdaBoost.R2**：回归版本

#### 2.3 梯度提升

**梯度提升机（GBM）**：
- 使用梯度下降方向训练新分类器
- 拟合负梯度（残差）
- 更灵活，可使用任意损失函数

**与AdaBoost关系**：
- AdaBoost是指数损失下的梯度提升
- GBM推广到任意可微损失函数

### 适用范围

| 题型类型 | 典型问题 | 特征 |
|---------|---------|------|
| 二分类 | 欺诈检测、垃圾邮件 | 标签不平衡 |
| 多分类 | 图像分类、文本分类 | 多类别 |
| 回归 | 价格预测、需求预测 | 连续目标 |
| 特征工程 | 特征选择 | 重要特征 |
| 集成学习 | 模型融合 | 提升性能 |

### 可视化图表类型

- **错误率曲线**：训练/测试错误率随轮数变化
- **分类器权重图**：各弱分类器权重
- **决策边界图**：分类边界可视化
- **特征重要性图**：特征重要性排序
- **残差图**：残差随轮数变化（回归）

### 代码实现要点

```python
import numpy as np
from sklearn.ensemble import AdaBoostClassifier, AdaBoostRegressor
from sklearn.tree import DecisionTreeClassifier, DecisionTreeRegressor
from sklearn.metrics import accuracy_score, mean_squared_error
import matplotlib.pyplot as plt

def _validate_boosting_split(X_train, y_train, X_validation, y_validation):
    X_train = np.asarray(X_train, dtype=float)
    X_validation = np.asarray(X_validation, dtype=float)
    y_train = np.asarray(y_train)
    y_validation = np.asarray(y_validation)
    if (X_train.ndim != 2 or X_validation.ndim != 2
            or X_train.shape[1] != X_validation.shape[1]
            or X_train.shape[0] != len(y_train)
            or X_validation.shape[0] != len(y_validation)
            or X_train.shape[0] < 2 or X_validation.shape[0] < 1
            or y_train.ndim != 1 or y_validation.ndim != 1
            or np.any(~np.isfinite(X_train)) or np.any(~np.isfinite(X_validation))):
        raise ValueError("训练/验证特征与标签必须有限、二维/一维且样本合同一致")
    return X_train, y_train, X_validation, y_validation

def select_adaboost_classifier(X_train, y_train, X_validation, y_validation,
                               max_estimators, learning_rate, random_state):
    """
    只用训练集拟合候选路径、验证集选择弱学习器数量，再在训练+验证上重拟合。
    最终测试集不得传入本函数。
    """
    if (not isinstance(max_estimators, int) or isinstance(max_estimators, bool)
            or max_estimators < 1):
        raise ValueError("max_estimators 必须是正整数")
    if not np.isfinite(learning_rate) or learning_rate <= 0:
        raise ValueError("learning_rate 必须是有限正数")
    X_train, y_train, X_validation, y_validation = _validate_boosting_split(
        X_train, y_train, X_validation, y_validation
    )
    base_clf = DecisionTreeClassifier(max_depth=1, random_state=random_state)
    candidate = AdaBoostClassifier(
        estimator=base_clf,
        n_estimators=max_estimators,
        learning_rate=learning_rate,
        random_state=random_state
    )
    candidate.fit(X_train, y_train)
    training_errors = [
        1 - accuracy_score(y_train, prediction)
        for prediction in candidate.staged_predict(X_train)
    ]
    validation_errors = [
        1 - accuracy_score(y_validation, prediction)
        for prediction in candidate.staged_predict(X_validation)
    ]
    if not validation_errors:
        raise RuntimeError("AdaBoost 未产生可供验证的阶段预测")
    selected_n_estimators = int(np.argmin(validation_errors)) + 1

    selected_model = AdaBoostClassifier(
        estimator=DecisionTreeClassifier(max_depth=1, random_state=random_state),
        n_estimators=selected_n_estimators,
        learning_rate=learning_rate,
        random_state=random_state,
    )
    selected_model.fit(
        np.concatenate([X_train, X_validation], axis=0),
        np.concatenate([y_train, y_validation], axis=0),
    )
    return selected_model, {
        "training_error": training_errors,
        "validation_error": validation_errors,
        "selected_n_estimators": selected_n_estimators,
        "selection_scope": "validation_only",
    }

def evaluate_adaboost_classifier(model, X_test, y_test):
    """模型冻结后对最终测试集调用一次。"""
    predictions = model.predict(X_test)
    return predictions, float(accuracy_score(y_test, predictions))

def select_adaboost_regressor(X_train, y_train, X_validation, y_validation,
                              max_estimators, learning_rate, loss,
                              random_state):
    """
    用验证 MSE 选择弱学习器数量，再在训练+验证上重拟合。
    """
    if (not isinstance(max_estimators, int) or isinstance(max_estimators, bool)
            or max_estimators < 1):
        raise ValueError("max_estimators 必须是正整数")
    if not np.isfinite(learning_rate) or learning_rate <= 0:
        raise ValueError("learning_rate 必须是有限正数")
    if loss not in {'linear', 'square', 'exponential'}:
        raise ValueError("loss 必须是 linear/square/exponential")
    X_train, y_train, X_validation, y_validation = _validate_boosting_split(
        X_train, y_train, X_validation, y_validation
    )
    base_reg = DecisionTreeRegressor(max_depth=3, random_state=random_state)
    candidate = AdaBoostRegressor(
        estimator=base_reg,
        n_estimators=max_estimators,
        learning_rate=learning_rate,
        loss=loss,
        random_state=random_state
    )
    candidate.fit(X_train, y_train)
    training_mse = [
        mean_squared_error(y_train, prediction)
        for prediction in candidate.staged_predict(X_train)
    ]
    validation_mse = [
        mean_squared_error(y_validation, prediction)
        for prediction in candidate.staged_predict(X_validation)
    ]
    if not validation_mse:
        raise RuntimeError("AdaBoost 未产生可供验证的阶段预测")
    selected_n_estimators = int(np.argmin(validation_mse)) + 1

    selected_model = AdaBoostRegressor(
        estimator=DecisionTreeRegressor(max_depth=3, random_state=random_state),
        n_estimators=selected_n_estimators,
        learning_rate=learning_rate,
        loss=loss,
        random_state=random_state,
    )
    selected_model.fit(
        np.concatenate([X_train, X_validation], axis=0),
        np.concatenate([y_train, y_validation], axis=0),
    )
    return selected_model, {
        "training_mse": training_mse,
        "validation_mse": validation_mse,
        "selected_n_estimators": selected_n_estimators,
        "selection_scope": "validation_only",
    }

def evaluate_adaboost_regressor(model, X_test, y_test):
    """模型冻结后对最终测试集调用一次。"""
    predictions = model.predict(X_test)
    return predictions, float(mean_squared_error(y_test, predictions))

def plot_adaboost_errors(training_errors, validation_errors,
                         title="AdaBoost Error Rate"):
    """
    绘制AdaBoost错误率曲线
    :param training_errors: 训练错误率列表
    :param validation_errors: 验证错误率列表
    :param title: 图标题
    """
    plt.figure(figsize=(10, 6))
    plt.plot(training_errors, 'o-', label='Training Error')
    plt.plot(validation_errors, 's-', label='Validation Error')
    plt.xlabel('Number of Estimators')
    plt.ylabel('Error Rate')
    plt.title(title)
    plt.legend()
    plt.show()

def plot_feature_importance_adaboost(ada_model, feature_names, top_n=20):
    """
    绘制特征重要性（AdaBoost）
    :param ada_model: AdaBoost模型
    :param feature_names: 特征名称
    :param top_n: 显示前N个特征
    """
    importances = ada_model.feature_importances_
    indices = np.argsort(importances)[::-1][:top_n]

    plt.figure(figsize=(10, 6))
    plt.bar(range(len(indices)), importances[indices])
    plt.xticks(range(len(indices)), [feature_names[i] for i in indices], rotation=90)
    plt.xlabel('Feature')
    plt.ylabel('Importance')
    plt.title('Feature Importance (AdaBoost)')
    plt.tight_layout()
    plt.show()

def plot_decision_boundary(model, X, y, title="Decision Boundary"):
    """
    绘制决策边界（适用于2D特征）
    :param model: 训练好的模型
    :param X: 特征矩阵
    :param y: 标签
    :param title: 图标题
    """
    if X.shape[1] != 2:
        raise ValueError("Decision boundary plot only works for 2D features")

    x_min, x_max = X[:, 0].min() - 1, X[:, 0].max() + 1
    y_min, y_max = X[:, 1].min() - 1, X[:, 1].max() + 1
    xx, yy = np.meshgrid(np.arange(x_min, x_max, 0.1),
                         np.arange(y_min, y_max, 0.1))

    Z = model.predict(np.c_[xx.ravel(), yy.ravel()])
    Z = Z.reshape(xx.shape)

    plt.figure(figsize=(10, 6))
    plt.contourf(xx, yy, Z, alpha=0.3, cmap=plt.cm.Paired)
    plt.scatter(X[:, 0], X[:, 1], c=y, cmap=plt.cm.Paired, edgecolors='k')
    plt.xlabel('Feature 1')
    plt.ylabel('Feature 2')
    plt.title(title)
    plt.tight_layout()
    plt.show()
```

## 3. 孤立森林 (Isolation Forest)

### 算法介绍

孤立森林是一种异常检测算法，通过随机分割特征空间来隔离数据点，异常点更容易被隔离（需要更少的分割步骤）。

#### 3.1 基本原理

**核心思想**：
- 异常点是少数且不同的
- 异常点更容易被孤立
- 使用路径长度衡量异常程度

**孤立树（iTree）构建**：

1. 随机选择特征和分割值
2. 递归分割数据空间
3. 直到：所有数据点被孤立 或 达到最大深度

**路径长度**：
$$
h(x) = \sum_{i=1}^{\text{path}} \Delta i + C(\psi)
$$

其中$\Delta i$是节点到子节点的路径长度，$C(\psi)$是调整项。

#### 3.2 异常得分

**归一化路径长度**：
$$
H(x) = h(x) / c(\psi)
$$

其中$c(\psi) = 2H(\psi - 1) - (2(\psi - 1)/\psi)$是调整路径长度，$\psi$是样本数。

**异常得分**：
$$
s(x, \psi) = 2^{-\frac{E[H(x)]}{c(\psi)}}
$$

**得分解释**：
- $s \approx 1$：异常点
- $s < 0.5$：正常点
- $s \approx 0.5$：无异常

#### 3.3 算法特点

**优点**：
- 无需假设数据分布
- 线性时间复杂度
- 内存效率高
- 可处理高维数据

**参数**：
- `n_estimators`：树的数量
- `max_samples`：每棵树的样本数
- `contamination`：异常比例

### 适用范围

| 题型类型 | 典型问题 | 特征 |
|---------|---------|------|
| 欺诈检测 | 信用卡欺诈 | 极度不平衡 |
| 网络入侵 | 异常流量 | 异常模式 |
| 设备故障 | 设备异常检测 | 传感器数据 |
| 数据清洗 | 异常值识别 | 数据质量 |
| 医疗诊断 | 罕见病识别 | 罕见模式 |

### 可视化图表类型

- **异常得分图**：各样本异常得分
- **异常散点图**：异常点在特征空间的分布
- **异常分数分布**：`score_samples` 转换后的模型分数；若要画真实路径长度，须逐树遍历并明确归一化定义
- **ROC曲线**：检测性能评估
- **2D投影图**：二维特征空间的异常点

```python
import numpy as np
from sklearn.ensemble import IsolationForest
from sklearn.metrics import classification_report, roc_auc_score, roc_curve
import matplotlib.pyplot as plt

def isolation_forest_anomaly_detection(X_fit, X_score, contamination,
                                       random_state=42):
    """
    只在 X_fit 上拟合，并对独立的 X_score 输出标签和异常分数
    :param X_fit: 拟合特征矩阵
    :param X_score: 待评分特征矩阵
    :param contamination: 有依据的异常比例，或使用 sklearn 支持的 'auto'
    :return: 模型, 异常标签, 异常得分
    """
    X_fit = np.asarray(X_fit, dtype=float)
    X_score = np.asarray(X_score, dtype=float)
    if (X_fit.ndim != 2 or X_fit.shape[0] < 2 or X_fit.shape[1] < 1
            or X_score.ndim != 2 or X_score.shape[0] < 1
            or X_score.shape[1] != X_fit.shape[1]
            or np.any(~np.isfinite(X_fit)) or np.any(~np.isfinite(X_score))):
        raise ValueError("X_fit/X_score 必须是有限二维数组且特征数一致")
    if contamination != 'auto' and not (
        isinstance(contamination, (int, float, np.integer, np.floating))
        and not isinstance(contamination, (bool, np.bool_))
        and np.isfinite(contamination) and 0 < contamination <= 0.5
    ):
        raise ValueError("contamination 必须为 'auto' 或位于 (0, 0.5] 的比例")
    iso_forest = IsolationForest(
        n_estimators=100,
        max_samples='auto',
        contamination=contamination,
        random_state=random_state,
        n_jobs=-1
    )

    iso_forest.fit(X_fit)

    # 预测：-1表示异常，1表示正常
    labels = iso_forest.predict(X_score)

    # 计算异常得分
    scores = iso_forest.score_samples(X_score)
    # 只反转方向，使数值越大越异常；这不是真实路径长度，也没有缩放到 0-1。
    anomaly_scores = -scores

    return iso_forest, labels, anomaly_scores

def plot_anomaly_scores(X, anomaly_scores, labels, feature_names=None):
    """
    绘制异常得分可视化
    :param X: 特征矩阵
    :param anomaly_scores: 异常得分
    :param labels: 异常标签
    :param feature_names: 特征名称
    """
    if X.shape[1] < 2:
        raise ValueError("Need at least 2 features for visualization")

    fig, axes = plt.subplots(1, 2, figsize=(14, 6))

    # 散点图（使用前两个特征）
    normal_mask = labels == 1
    anomaly_mask = labels == -1

    axes[0].scatter(X[normal_mask, 0], X[normal_mask, 1],
                   c='blue', label='Normal', alpha=0.5)
    axes[0].scatter(X[anomaly_mask, 0], X[anomaly_mask, 1],
                   c='red', label='Anomaly', alpha=0.8)
    axes[0].set_xlabel(feature_names[0] if feature_names else 'Feature 1')
    axes[0].set_ylabel(feature_names[1] if feature_names else 'Feature 2')
    axes[0].set_title('Anomaly Detection Results')
    axes[0].legend()
# 异常得分分布
    axes[1].hist(anomaly_scores[normal_mask], bins=50, alpha=0.5,
                label='Normal', color='blue')
    axes[1].hist(anomaly_scores[anomaly_mask], bins=50, alpha=0.5,
                label='Anomaly', color='red')
    axes[1].set_xlabel('Anomaly Score')
    axes[1].set_ylabel('Frequency')
    axes[1].set_title('Anomaly Score Distribution')
    axes[1].legend()
    plt.tight_layout()
    plt.show()

def evaluate_anomaly_detection(y_true, y_pred, scores):
    """
    评估异常检测性能
    :param y_true: 真实标签（1正常，-1异常）
    :param y_pred: 预测标签
    :param scores: 异常得分
    :return: 分类报告、AUC 及适用性说明
    """
    y_true = np.asarray(y_true)
    y_pred = np.asarray(y_pred)
    scores = np.asarray(scores, dtype=float)
    if (y_true.ndim != 1 or y_pred.shape != y_true.shape or scores.shape != y_true.shape
            or len(y_true) < 1 or np.any(~np.isfinite(scores))):
        raise ValueError("y_true、y_pred、scores 必须是等长有限一维数组")
    if not np.all(np.isin(y_true, [-1, 1])) or not np.all(np.isin(y_pred, [-1, 1])):
        raise ValueError("y_true 与 y_pred 只能用 1 表示正常、-1 表示异常")

    y_true_binary = (y_true == -1).astype(int)
    y_pred_binary = (y_pred == -1).astype(int)
    report = classification_report(
        y_true_binary,
        y_pred_binary,
        labels=[0, 1],
        target_names=['Normal', 'Anomaly'],
        zero_division=0,
        output_dict=True,
    )
    auc_applicable = np.unique(y_true_binary).size == 2
    auc_value = (
        float(roc_auc_score(y_true_binary, scores))
        if auc_applicable else None
    )
    return {
        "classification_report": report,
        "roc_auc": auc_value,
        "roc_auc_applicable": bool(auc_applicable),
        "roc_auc_note": (
            "同时含正常与异常真实标签"
            if auc_applicable else "真实标签只有一个类别，ROC/AUC 无定义"
        ),
    }

def plot_roc_curve(y_true, scores):
    """
    绘制ROC曲线
    :param y_true: 真实标签（1正常，-1异常）
    :param scores: 异常得分
    """
    from sklearn.metrics import roc_curve, auc

    y_true = np.asarray(y_true)
    scores = np.asarray(scores, dtype=float)
    if (y_true.ndim != 1 or scores.shape != y_true.shape
            or np.any(~np.isfinite(scores)) or not np.all(np.isin(y_true, [-1, 1]))):
        raise ValueError("y_true 与 scores 必须是等长一维数组，标签取 ±1 且分数有限")
    y_true_binary = (y_true == -1).astype(int)
    if np.unique(y_true_binary).size != 2:
        raise ValueError("真实标签只有一个类别，不能绘制 ROC 曲线")

    fpr, tpr, thresholds = roc_curve(y_true_binary, scores)
    roc_auc = auc(fpr, tpr)

    plt.figure(figsize=(8, 6))
    plt.plot(fpr, tpr, 'b-', label=f'ROC curve (AUC = {roc_auc:.2f})')
    plt.plot([0, 1], [0, 1], 'r--', label='Random')
    plt.xlabel('False Positive Rate')
    plt.ylabel('True Positive Rate')
    plt.title('ROC Curve - Anomaly Detection')
    plt.legend()
    plt.show()

    return roc_auc

def plot_anomaly_score_distribution(iso_forest, X, max_samples=1000):
    """
    绘制由 score_samples 得到的异常分数分布；这不是原始树路径长度。
    :param iso_forest: 训练好的孤立森林模型
    :param X: 特征矩阵
    :param max_samples: 采样数量
    """
    anomaly_scores = -iso_forest.score_samples(X[:max_samples])

    plt.figure(figsize=(10, 6))
    plt.hist(anomaly_scores, bins=50, alpha=0.7, edgecolor='black')
    plt.xlabel('Anomaly Score (-score_samples; larger is more anomalous)')
    plt.ylabel('Frequency')
    plt.title('Distribution of Isolation-Forest Anomaly Scores')
    plt.show()

def contamination_sensitivity_analysis(X_fit, X_validation, y_validation,
                                       contamination_candidates,
                                       random_state=42, plot=True):
    """
    只用拟合集训练模型、验证集选择 contamination；最终测试集不得参与。
    """
    from sklearn.metrics import f1_score, precision_score, recall_score

    y_validation = np.asarray(y_validation)
    contamination_candidates = list(contamination_candidates)
    if y_validation.ndim != 1 or not np.all(np.isin(y_validation, [-1, 1])):
        raise ValueError("y_validation 必须是一维 ±1 标签")
    if (not contamination_candidates
            or len(set(contamination_candidates)) != len(contamination_candidates)):
        raise ValueError("contamination_candidates 必须是非空不重复候选")
    f1_scores = []
    precisions = []
    recalls = []

    for contamination in contamination_candidates:
        _, labels, _ = isolation_forest_anomaly_detection(
            X_fit, X_validation, contamination=contamination,
            random_state=random_state,
        )
        if len(labels) != len(y_validation):
            raise ValueError("X_validation 与 y_validation 样本数不一致")

        y_binary = (y_validation == -1).astype(int)
        y_pred_binary = (labels == -1).astype(int)

        f1 = f1_score(y_binary, y_pred_binary, zero_division=0)
        prec = precision_score(y_binary, y_pred_binary, zero_division=0)
        rec = recall_score(y_binary, y_pred_binary, zero_division=0)

        f1_scores.append(f1)
        precisions.append(prec)
        recalls.append(rec)

    selected_index = int(np.argmax(f1_scores))
    if plot:
        plt.figure(figsize=(10, 6))
        plt.plot(contamination_candidates, f1_scores, 'o-', label='Validation F1')
        plt.plot(contamination_candidates, precisions, 's-', label='Validation Precision')
        plt.plot(contamination_candidates, recalls, '^-', label='Validation Recall')
        plt.xlabel('Contamination Rate')
        plt.ylabel('Validation Score')
        plt.title('Validation Sensitivity: Contamination Rate')
        plt.legend()
        plt.show()

    return {
        "contamination_candidates": contamination_candidates,
        "validation_f1": f1_scores,
        "validation_precision": precisions,
        "validation_recall": recalls,
        "selected_by_validation_f1": contamination_candidates[selected_index],
        "selection_scope": "validation_only",
    }
```

## 机器学习算法选择指南

算法名称不能由“分类/回归”“小样本”或“高维”直接决定。先建立朴素基线和与题目一致的验证协议，再比较能在当前数据结构、计算预算和解释要求下真实复现的候选。

| 决策维度 | 必查问题 | 方法与风险 |
|---|---|---|
| 目标与损失 | 分类、回归、排序、异常还是概率预测；代价是否不对称 | 选择与最终指标一致的损失、阈值和校准方法，准确率不能替代题目决策损失 |
| 数据结构 | 样本是否独立，是否含时间、空间、个体、图或重复组 | 使用组别/时间隔离和适配结构的模型；随机切分可能产生泄漏 |
| 样本与容量 | 有效独立样本能否支撑特征数、树深和调参自由度 | 从线性/规则基线到树集成逐步增容，以嵌套验证或独立验证控制过拟合；小样本不自动推出随机森林 |
| 缺失与预处理 | 缺失机制如何，所用库和版本是否原生支持缺失 | 插补、编码、缩放和特征选择必须在训练折内拟合；随机森林/XGBoost 的缺失支持依实现而异 |
| 类别不平衡 | 正例率、误分类代价和部署阈值如何 | 类权重、采样或阈值移动均只在训练内完成，报告 PR、召回、成本和校准而非只报准确率 |
| 解释需求 | 需要预测解释、因果解释还是可执行规则 | 置换重要性、SHAP/PDP 与单树规则含义不同；杂质重要性可能偏向高基数变量，相关特征会分摊重要性 |
| 不确定性 | 是否需要概率、区间或风险上界 | 树投票比例不自动是校准概率；用校准集、Bootstrap、分位数或共形方法并检查覆盖 |
| 异常检测 | “异常”由低密度、规则违反还是未来损失定义 | 孤立森林分数不是客观真值，污染率、阈值和外部验证必须有依据 |

OOB 误差可作随机森林内部诊断，但不能替代时间/组别隔离的最终验证。所有模型在相同数据切分、特征可用性和调参预算下比较，并报告多随机种子、误差分布、校准与失败子群。
