## 1. 灰色预测模型 (Grey Prediction Model, GM)

### 算法介绍

灰色预测模型传统上用于信息有限的短序列。最常用的 GM(1,1) 通过累加生成（AGO）拟合近似指数型的一阶动态；“小样本”本身不是采用依据，仍须核对正值/非负序列条件、级比与机制合理性，并用滚动样本外预测和朴素基线验证。

**GM(1,1)模型**：

原始序列：$X^{(0)} = \{x^{(0)}(1), x^{(0)}(2), \ldots, x^{(0)}(n)\}$

一次累加生成：$X^{(1)} = \{x^{(1)}(1), x^{(1)}(2), \ldots, x^{(1)}(n)\}$

其中 $x^{(1)}(k) = \sum_{i=1}^{k} x^{(0)}(i)$

白化微分方程：$\frac{dx^{(1)}}{dt} + ax^{(1)} = b$

**参数估计**：
$$
\begin{bmatrix} a \\ b \end{bmatrix} = (B^T B)^{-1} B^T Y
$$

其中：
$$
B = \begin{bmatrix} -\frac{1}{2}[x^{(1)}(1) + x^{(1)}(2)] & 1 \\ -\frac{1}{2}[x^{(1)}(2) + x^{(1)}(3)] & 1 \\ \vdots & \vdots \\ -\frac{1}{2}[x^{(1)}(n-1) + x^{(1)}(n)] & 1 \end{bmatrix}, \quad Y = \begin{bmatrix} x^{(0)}(2) \\ x^{(0)}(3) \\ \vdots \\ x^{(0)}(n) \end{bmatrix}
$$

**预测公式**：
$$
\hat{x}^{(0)}(k+1) = (1 - e^{a})[x^{(0)}(1) - \frac{b}{a}]e^{-ak}, \quad k = 1, 2, \ldots
$$

```python
import numpy as np
import matplotlib.pyplot as plt
from matplotlib.patches import Rectangle

# 设置中文字体 - 多字体备选防止渲染问题
plt.rcParams['font.sans-serif'] = ['SimHei', 'DejaVu Sans', 'Arial Unicode MS', 'Microsoft YaHei', 'Arial']

class GreyPredictionModel:
    """
    GM(1,1)灰色预测模型实现
    """
    def __init__(self, data):
        self.data = np.array(data, dtype=float)
        self.n = len(data)
        if self.data.ndim != 1 or self.n < 4:
            raise ValueError("GM(1,1)需要至少4个一维观测；样本数门槛不代表模型一定适用")
        if not np.all(np.isfinite(self.data)) or np.any(self.data <= 0):
            raise ValueError("此基础实现要求有限正值序列；含零/负值时须重新论证变换或改用其他模型")
        self.a = None  # 发展系数
        self.b = None  # 灰色作用量
        self.fitted_values = None
        self.residuals = None
        
    def fit(self):
        """拟合GM(1,1)模型"""
        # 一次累加生成（AGO）
        x1 = np.cumsum(self.data)
        
        # 构造数据矩阵B和向量Y
        B = np.zeros((self.n - 1, 2))
        Y = self.data[1:].reshape(-1, 1)
        
        for i in range(self.n - 1):
            B[i, 0] = -(x1[i] + x1[i + 1]) / 2  # 紧邻均值生成
            B[i, 1] = 1
        
        # 最小二乘估计参数 [a, b]^T
        params, _, rank, _ = np.linalg.lstsq(B, Y, rcond=None)
        if rank < 2:
            raise ValueError("GM(1,1)参数矩阵秩不足，参数不可辨识")
        self.a = params[0, 0]
        self.b = params[1, 0]
        
        # 计算拟合值
        self.fitted_values = self.predict(self.n)
        self.residuals = self.data - self.fitted_values[:self.n]
        
        return self
    
    def predict(self, steps):
        """
        预测未来steps个值
        :param steps: 预测步数（包含历史数据的拟合）
        :return: 预测序列
        """
        if self.a is None:
            raise ValueError("请先调用fit()方法拟合模型")
        if not isinstance(steps, int) or isinstance(steps, bool) or steps < 1:
            raise ValueError("steps 必须是正整数，并表示返回序列的总长度")
        
        predictions = []
        for k in range(steps):
            if k == 0:
                pred = self.data[0]
            else:
                # expm1(a)/a 在 a 很小时保持数值稳定；仅在 a 精确为 0 时取极限 1。
                exponential_ratio = np.expm1(self.a) / self.a if self.a != 0 else 1.0
                pred = (
                    (self.b - self.a * self.data[0])
                    * exponential_ratio
                    * np.exp(-self.a * k)
                )
            predictions.append(pred)
        
        return np.array(predictions)
    
    def calculate_metrics(self):
        """计算模型评估指标"""
        if self.residuals is None:
            raise ValueError("请先调用fit()方法拟合模型")
        
        # 残差检验
        relative_errors = np.abs(self.residuals) / self.data * 100
        mean_relative_error = np.mean(relative_errors)
        
        # 后验差检验
        std_original = np.std(self.data, ddof=1)
        std_residual = np.std(self.residuals, ddof=1)
        C = std_residual / std_original if std_original > 0 else np.nan  # 方差比
        
        # 小误差概率
        S0 = 0.6745 * std_original
        small_error_count = np.sum(np.abs(self.residuals - np.mean(self.residuals)) < S0)
        P = small_error_count / self.n
        
        # 关联度检验
        rho = 0.5  # 分辨系数
        min_diff = np.min(np.abs(self.data - self.fitted_values[:self.n]))
        max_diff = np.max(np.abs(self.data - self.fitted_values[:self.n]))
        
        if max_diff == 0:
            R = 1.0
        else:
            xi = (min_diff + rho * max_diff) / (np.abs(self.data - self.fitted_values[:self.n]) + rho * max_diff)
            R = np.mean(xi)
        
        return {
            'mean_relative_error': mean_relative_error,
            'C': C,
            'P': P,
            'R': R,
            'grade': self._grade_model(C, P)
        }
    
    def _grade_model(self, C, P):
        """返回传统后验差描述等级；不得据此替代样本外验证。"""
        if not np.isfinite(C):
            return '不可判定'
        if C < 0.35 and P > 0.95:
            return '优秀'
        elif C < 0.5 and P > 0.80:
            return '良好'
        elif C < 0.65 and P > 0.70:
            return '合格'
        else:
            return '不合格'
```

## 2. 插值与拟合 (Interpolation and Fitting)

### 算法介绍

插值与拟合是数据处理的基础方法，用于构造近似函数来逼近给定数据点。

#### 2.1 多项式插值

**拉格朗日插值**：
$$
L_n(x) = \sum_{i=0}^{n} y_i \prod_{j \neq i} \frac{x - x_j}{x_i - x_j}
$$

**牛顿插值**：
$$
N_n(x) = f[x_0] + f[x_0, x_1](x-x_0) + \cdots + f[x_0, \ldots, x_n](x-x_0)\cdots(x-x_{n-1})
$$

#### 2.3 样条插值

**三次样条函数**：
在每个区间 $[x_i, x_{i+1}]$ 上：
$$
S_i(x) = a_i + b_i(x-x_i) + c_i(x-x_i)^2 + d_i(x-x_i)^3
$$

满足条件：
- 插值条件：$S_i(x_i) = y_i$, $S_i(x_{i+1}) = y_{i+1}$
- 连续性条件：一阶、二阶导数连续
- 边界条件：自然边界或固定边界

#### 2.3 最小二乘拟合

**线性最小二乘**：
$$
\min_{a,b} \sum_{i=1}^{n} [y_i - (ax_i + b)]^2
$$

**多项式拟合**：
$$
\min_{a_0,\ldots,a_m} \sum_{i=1}^{n} [y_i - \sum_{j=0}^{m} a_j x_i^j]^2
$$

**正则化拟合（岭回归）**：
$$
\min_{\beta} \|y - X\beta\|^2 + \lambda \|\beta\|^2
$$

```python
import numpy as np
import matplotlib.pyplot as plt
from scipy.interpolate import interp1d, CubicSpline, lagrange
from scipy.optimize import curve_fit
from sklearn.metrics import r2_score, mean_squared_error
# 不全局屏蔽数值或收敛警告；按具体类别诊断并记录。

# 设置中文字体 - 多字体备选防止渲染问题
plt.rcParams['font.sans-serif'] = ['SimHei', 'DejaVu Sans', 'Arial Unicode MS', 'Microsoft YaHei', 'Arial']
plt.rcParams['axes.unicode_minus'] = False

class InterpolationFitting:
    """插值与拟合方法集合。"""

    @staticmethod
    def _validate_xy(x, y, *, min_points, require_unique_x):
        x = np.asarray(x, dtype=float)
        y = np.asarray(y, dtype=float)
        if (x.ndim != 1 or y.ndim != 1 or x.shape != y.shape
                or len(x) < min_points or np.any(~np.isfinite(x))
                or np.any(~np.isfinite(y))):
            raise ValueError(
                f"x 与 y 必须是等长有限一维数组，且至少含 {min_points} 个点"
            )
        if require_unique_x and np.unique(x).size != len(x):
            raise ValueError("插值节点 x 必须互不重复")
        return x, y

    @staticmethod
    def _validate_x_new(x_new):
        x_new = np.asarray(x_new, dtype=float)
        if np.any(~np.isfinite(x_new)):
            raise ValueError("x_new 必须为有限数")
        return x_new

    @staticmethod
    def lagrange_interpolation(x, y, x_new):
        """拉格朗日插值；节点 x 必须互异。"""
        x, y = InterpolationFitting._validate_xy(
            x, y, min_points=1, require_unique_x=True
        )
        x_new = InterpolationFitting._validate_x_new(x_new)
        original_shape = x_new.shape
        x_new = x_new.reshape(-1)
        n = len(x)
        y_new = np.zeros_like(x_new, dtype=float)

        for i in range(n):
            basis = np.ones_like(x_new, dtype=float)
            for j in range(n):
                if i != j:
                    basis *= (x_new - x[j]) / (x[i] - x[j])
            y_new += y[i] * basis
        return y_new.reshape(original_shape)

    @staticmethod
    def newton_interpolation(x, y, x_new):
        """牛顿插值；节点 x 必须互异。"""
        x, y = InterpolationFitting._validate_xy(
            x, y, min_points=1, require_unique_x=True
        )
        x_new = InterpolationFitting._validate_x_new(x_new)
        original_shape = x_new.shape
        x_new = x_new.reshape(-1)
        n = len(x)

        divided_diff = np.zeros((n, n))
        divided_diff[:, 0] = y
        for j in range(1, n):
            for i in range(n - j):
                divided_diff[i, j] = (
                    divided_diff[i + 1, j - 1] - divided_diff[i, j - 1]
                ) / (x[i + j] - x[i])

        y_new = np.zeros_like(x_new, dtype=float)
        for k, value in enumerate(x_new):
            result = divided_diff[0, 0]
            product = 1.0
            for i in range(1, n):
                product *= value - x[i - 1]
                result += divided_diff[0, i] * product
            y_new[k] = result
        return y_new.reshape(original_shape)

    @staticmethod
    def cubic_spline_interpolation(x, y, x_new, bc_type='natural'):
        """三次样条插值；内部按 x 排序并拒绝重复节点。"""
        x, y = InterpolationFitting._validate_xy(
            x, y, min_points=2, require_unique_x=True
        )
        x_new = InterpolationFitting._validate_x_new(x_new)
        order = np.argsort(x)
        x, y = x[order], y[order]
        cs = CubicSpline(x, y, bc_type=bc_type)
        return cs(x_new), cs

    @staticmethod
    def polynomial_fit(x, y, degree):
        """多项式最小二乘拟合；返回指标只描述训练内拟合。"""
        x, y = InterpolationFitting._validate_xy(
            x, y, min_points=2, require_unique_x=False
        )
        if (isinstance(degree, (bool, np.bool_))
                or not isinstance(degree, (int, np.integer)) or degree < 0
                or degree >= len(x) or np.unique(x).size <= degree):
            raise ValueError("degree 必须是非负整数，且小于样本数和不同 x 的数量")
        coeffs = np.polyfit(x, y, int(degree))
        poly = np.poly1d(coeffs)
        y_fit = poly(x)
        training_r2 = r2_score(y, y_fit)
        training_rmse = np.sqrt(mean_squared_error(y, y_fit))
        return poly, coeffs, training_r2, training_rmse

    @staticmethod
    def nonlinear_fit(x, y, func, p0=None):
        """非线性曲线拟合；返回指标只描述训练内拟合。"""
        x, y = InterpolationFitting._validate_xy(
            x, y, min_points=2, require_unique_x=False
        )
        if not callable(func):
            raise ValueError("func 必须可调用")
        params, covariance = curve_fit(func, x, y, p0=p0)
        y_fit = np.asarray(func(x, *params), dtype=float)
        if y_fit.shape != y.shape or np.any(~np.isfinite(y_fit)):
            raise ValueError("func(x, *params) 必须返回与 y 等形的有限数组")
        training_r2 = r2_score(y, y_fit)
        training_rmse = np.sqrt(mean_squared_error(y, y_fit))
        return params, covariance, training_r2, training_rmse
```

## 3. 线性回归 (Linear Regression)

### 算法介绍

线性回归用于建立自变量与因变量之间的线性关系模型。

#### 3.1 一元线性回归

**模型**：
$$
y = \beta_0 + \beta_1 x + \varepsilon
$$

**参数估计**（最小二乘）：
$$
\hat{\beta}_1 = \frac{\sum_{i=1}^{n}(x_i - \bar{x})(y_i - \bar{y})}{\sum_{i=1}^{n}(x_i - \bar{x})^2}
$$
$$
\hat{\beta}_0 = \bar{y} - \hat{\beta}_1 \bar{x}
$$

#### 3.2 多元线性回归

**模型**：
$$
y = \beta_0 + \beta_1 x_1 + \beta_2 x_2 + \cdots + \beta_p x_p + \varepsilon
$$

**矩阵形式**：
$$
Y = X\beta + \varepsilon
$$

**参数估计**：
$$
\hat{\beta} = (X^T X)^{-1} X^T Y
$$

上式只在设计矩阵满列秩时作为理论表达。数值实现优先使用 QR、SVD、`lstsq` 或带诊断的统计软件，不显式求逆；秩亏、强共线和高杠杆点必须单独检查。

#### 3.3 逐步回归

**前进法**：逐步引入重要变量
**后退法**：逐步剔除不重要变量
**逐步法**：结合前进和后退

**变量选择准则**：
- AIC准则：$AIC = n \ln(RSS/n) + 2p$
- BIC准则：$BIC = n \ln(RSS/n) + p \ln n$
- 调整$R^2$：$R^2_{adj} = 1 - \frac{(1-R^2)(n-1)}{n-p-1}$

### 适用范围

| 题型类型 | 典型问题 | 特征 |
|---------|---------|------|
| 经济预测 | GDP与投资关系 | 线性关系 |
| 市场分析 | 销量与广告投入 | 多因素影响 |
| 房价预测 | 房价与特征关系 | 多变量 |
| 医学研究 | 病情与指标关系 | 关联或调整分析；因果结论另需研究设计与可识别假设 |
| 生产预测 | 产量与要素投入 | 生产函数 |

### 可视化图表类型

- **散点图+回归线**：一元回归可视化
- **残差图**：残差与预测值关系
- **QQ图**：残差正态性检验
- **偏回归图**：各自变量的影响
- **置信区间图**：预测的置信区间

### 模型评估

| 评估指标 | 公式 | 说明 |
|---------|------|------|
| $R^2$ | $1 - \frac{RSS}{TSS}$ | 拟合优度 |
| 调整$R^2$ | $1 - \frac{(1-R^2)(n-1)}{n-p-1}$ | 考虑变量数 |
| RMSE | $\sqrt{\frac{1}{n}\sum_{i=1}^{n}(y_i - \hat{y}_i)^2}$ | 均方根误差 |
| MAE | $\frac{1}{n}\sum_{i=1}^{n}\|y_i - \hat{y}_i\|$ | 平均绝对误差 |
| MAPE | $\frac{100\%}{n}\sum_{i=1}^{n}\|\frac{y_i - \hat{y}_i}{y_i}\|$ | 平均绝对百分比误差 |

MAPE 在真实值为零时无定义，接近零时会被少数点支配，含负值时比例解释通常也不成立。不得用任意小常数修改分母后继续沿用原名称；应按题目量纲选择 MAE、RMSE、WAPE、MASE、分位数损失或明确掩码及覆盖率。

```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
from sklearn.linear_model import LinearRegression, Ridge, Lasso

import statsmodels.api as sm

# 不全局屏蔽数值或收敛警告；按具体类别诊断并记录。

# 设置中文字体 - 多字体备选防止渲染问题
plt.rcParams['font.sans-serif'] = ['SimHei', 'DejaVu Sans', 'Arial Unicode MS', 'Microsoft YaHei', 'Arial']
plt.rcParams['axes.unicode_minus'] = False

class LinearRegressionAnalysis:
    """线性回归拟合；训练内诊断不代表样本外预测性能。"""

    @staticmethod
    def _validate_supervised(X, y, min_samples):
        X = np.asarray(X, dtype=float)
        y = np.asarray(y, dtype=float)
        if X.ndim == 1:
            X = X.reshape(-1, 1)
        if (X.ndim != 2 or y.ndim != 1 or X.shape[0] != len(y)
                or X.shape[0] < min_samples or X.shape[1] < 1
                or np.any(~np.isfinite(X)) or np.any(~np.isfinite(y))):
            raise ValueError(
                f"X 与 y 必须样本数一致、有限，且至少含 {min_samples} 个样本"
            )
        return X, y
    
    @staticmethod
    def simple_linear_regression(x, y):
        """一元线性回归；返回键以 training_ 标识拟合内指标。"""
        X, y = LinearRegressionAnalysis._validate_supervised(x, y, min_samples=3)
        if X.shape[1] != 1 or np.ptp(X[:, 0]) == 0:
            raise ValueError("一元回归要求一个非常量自变量")
        
        model = LinearRegression()
        model.fit(X, y)
        y_pred = model.predict(X)
        
        # 计算统计量
        n = len(y)
        r2 = r2_score(y, y_pred)
        mse = mean_squared_error(y, y_pred)
        rmse = np.sqrt(mse)
        mae = np.mean(np.abs(y - y_pred))
        
        # 计算调整R²
        adj_r2 = 1 - (1 - r2) * (n - 1) / (n - 2)
        
        return {
            'model': model,
            'intercept': model.intercept_,
            'slope': model.coef_[0],
            'training_r2': r2,
            'training_adj_r2': adj_r2,
            'training_mse': mse,
            'training_rmse': rmse,
            'training_mae': mae,
            'training_predictions': y_pred,
            'metric_scope': 'in_sample_fit_only',
        }
    
    @staticmethod
    def multiple_linear_regression(X, y, feature_names=None):
        """多元 OLS；推断还需核对设计、误差结构和多重比较。"""
        X, y = LinearRegressionAnalysis._validate_supervised(X, y, min_samples=3)
        if X.shape[0] <= X.shape[1] + 1:
            raise ValueError("含截距 OLS 至少要求样本数大于参数数，才能报告本示例诊断")
        if feature_names is not None and len(feature_names) != X.shape[1]:
            raise ValueError("feature_names 长度必须等于特征数")
        
        # 添加常数项
        X_with_const = sm.add_constant(X)
        
        # 拟合模型
        model = sm.OLS(y, X_with_const).fit()
        
        # 创建结果字典
        results = {
            'model': model,
            'params': model.params,
            'pvalues': model.pvalues,
            'training_rsquared': model.rsquared,
            'training_rsquared_adj': model.rsquared_adj,
            'fvalue': model.fvalue,
            'f_pvalue': model.f_pvalue,
            'aic': model.aic,
            'bic': model.bic,
            'summary': model.summary(),
            'training_residuals': model.resid,
            'training_fittedvalues': model.fittedvalues,
            'metric_scope': 'in_sample_fit_and_inference_only',
        }
        
        if feature_names is not None:
            results['feature_names'] = feature_names
        
        return results
    
    @staticmethod
    def ridge_regression(X, y, alpha=1.0):
        """岭回归；alpha 必须在独立验证方案中选择。"""
        X, y = LinearRegressionAnalysis._validate_supervised(X, y, min_samples=2)
        if not np.isfinite(alpha) or alpha < 0:
            raise ValueError("alpha 必须是有限非负数")
        model = Ridge(alpha=alpha)
        model.fit(X, y)
        y_pred = model.predict(X)
        
        return {
            'model': model,
            'coef': model.coef_,
            'intercept': model.intercept_,
            'training_r2': r2_score(y, y_pred),
            'training_rmse': np.sqrt(mean_squared_error(y, y_pred)),
            'training_predictions': y_pred,
            'metric_scope': 'in_sample_fit_only',
        }
    
    @staticmethod
    def lasso_regression(X, y, alpha=1.0):
        """Lasso 回归；alpha 必须在独立验证方案中选择。"""
        X, y = LinearRegressionAnalysis._validate_supervised(X, y, min_samples=2)
        if not np.isfinite(alpha) or alpha <= 0:
            raise ValueError("Lasso alpha 必须是有限正数")
        model = Lasso(alpha=alpha)
        model.fit(X, y)
        y_pred = model.predict(X)
        
        return {
            'model': model,
            'coef': model.coef_,
            'intercept': model.intercept_,
            'training_r2': r2_score(y, y_pred),
            'training_rmse': np.sqrt(mean_squared_error(y, y_pred)),
            'training_predictions': y_pred,
            'metric_scope': 'in_sample_fit_only',
        }
```

## 4. 神经网络 (Neural Networks)

### 算法介绍

神经网络是一种模仿生物神经系统的计算模型，通过多层神经元进行非线性映射。

#### 4.1 前馈神经网络（BP网络）

**前向传播**：
$$
h_j = f(\sum_{i} w_{ij} x_i + b_j)
$$
$$
y_k = g(\sum_{j} v_{jk} h_j + c_k)
$$

**反向传播（BP算法）**：
输出层误差：$\delta_k = (y_k - t_k) \cdot g'(a_k)$
隐层误差：$\delta_j = \sum_{k} \delta_k v_{jk} \cdot f'(a_j)$

**权重更新**：
$$
\Delta w_{ij} = -\eta \frac{\partial E}{\partial w_{ij}} = \eta \delta_j x_i
$$

#### 4.2 RBF神经网络

**径向基函数**（高斯核）：
$$
\phi_j(x) = \exp\left(-\frac{\|x - c_j\|^2}{2\sigma_j^2}\right)
$$

**输出**：
$$
y = \sum_{j=1}^{m} w_j \phi_j(x)
$$

#### 4.3 LSTM网络（时间序列预测）

**遗忘门**：$f_t = \sigma(W_f \cdot [h_{t-1}, x_t] + b_f)$

**输入门**：$i_t = \sigma(W_i \cdot [h_{t-1}, x_t] + b_i)$

**候选值**：$\tilde{C}_t = \tanh(W_C \cdot [h_{t-1}, x_t] + b_C)$

**更新状态**：$C_t = f_t \odot C_{t-1} + i_t \odot \tilde{C}_t$

**输出门**：$o_t = \sigma(W_o \cdot [h_{t-1}, x_t] + b_o)$
$$h_t = o_t \odot \tanh(C_t)$$

### 适用范围

| 题型类型 | 典型问题 | 特征 |
|---------|---------|------|
| 非线性预测 | 股票价格预测 | 复杂非线性 |
| 时间序列 | 电力负荷预测 | 时序依赖 |
| 图像预测 | 图像生成 | 高维数据 |
| 语音预测 | 语音合成 | 序列数据 |
| 多变量预测 | 多维时间序列 | 多输入多输出 |

```python
def create_bpnn(input_dim, hidden_layers, output_dim, random_state):
    """创建 BP 网络；随机种子必须进入复现清单。"""
    if (not isinstance(input_dim, int) or isinstance(input_dim, bool) or input_dim < 1

    return model

def create_lstm(input_shape, lstm_units, output_dim, random_state):
    """创建两层 LSTM；lstm_units 至少为 2，避免第二层出现 0 单元。"""
    if (not isinstance(input_shape, tuple) or len(input_shape) != 2
            or any(not isinstance(value, int) or isinstance(value, bool) or value < 1

    if not isinstance(output_dim, int) or isinstance(output_dim, bool) or output_dim < 1:
        raise ValueError("output_dim 必须是正整数")
    keras.utils.set_random_seed(random_state)
    model = keras.Sequential([
        layers.Input(shape=input_shape),
        layers.LSTM(lstm_units, return_sequences=True),
        layers.Dropout(0.2),
        layers.LSTM(lstm_units // 2),
        layers.Dropout(0.2),
        layers.Dense(output_dim)
    ])

    return model

                       validation_data=(X_validation, y_validation),

                       verbose=0)

    return history, predictions
```

## 5. 支持向量机 (Support Vector Machine, SVM)

### 算法介绍

支持向量机是一种强大的监督学习算法，可用于分类和回归。SVR（支持向量回归）用于预测问题。

#### 5.1 线性SVR

**原始问题**：
$$
\min_{w,b,\xi,\xi^*} \frac{1}{2}\|w\|^2 + C\sum_{i=1}^{n}(\xi_i + \xi_i^*)
$$

**约束条件**：
$$
\begin{cases}
y_i - w^T x_i - b \leq \varepsilon + \xi_i \\
w^T x_i + b - y_i \leq \varepsilon + \xi_i^* \\
\xi_i, \xi_i^* \geq 0
\end{cases}
$$

#### 5.2 非线性SVR（核方法）

**对偶问题**：
$$
\max_{\alpha, \alpha^*} -\frac{1}{2}\sum_{i,j} (\alpha_i - \alpha_i^*)(\alpha_j - \alpha_j^*)K(x_i, x_j) - \varepsilon\sum_{i}(\alpha_i + \alpha_i^*) + \sum_{i} y_i(\alpha_i - \alpha_i^*)
$$

**决策函数**：
$$
f(x) = \sum_{i=1}^{n} (\alpha_i - \alpha_i^*) K(x_i, x) + b
$$

**常用核函数**：
- 线性核：$K(x, x') = x^T x'$
- 多项式核：$K(x, x') = (x^T x' + c)^d$
- RBF核：$K(x, x') = \exp(-\gamma \|x - x'\|^2)$
- Sigmoid核：$K(x, x') = \tanh(\gamma x^T x' + r)$

### 适用范围

| 题型类型 | 典型问题 | 特征 |
|---------|---------|------|
| 回归预测 | 股价预测、房价预测 | 非线性关系 |
| 时间序列 | 负荷预测、流量预测 | 小样本 |
| 函数逼近 | 复杂函数拟合 | 高维空间 |
| 异常检测 | 故障诊断 | 单类分类 |

### 可视化图表类型

- **支持向量图**：显示支持向量点
- **ε-带图**：ε不敏感带
- **决策边界图**：分类边界（分类问题）
- **核函数效果图**：不同核函数效果对比
- **参数敏感性图**：C和ε参数影响

```python
# SVR回归
def svr_predict(X_train, y_train, X_test, kernel='rbf', C=1.0, epsilon=0.1):
    """把特征和目标缩放封装在可复用估计器中，缩放器只在训练集拟合。"""

    ])

def svr_grid_search(X_train, y_train, param_grid, cv, scoring):
    """
    在每个交叉验证训练折内拟合缩放器。
    时序任务必须传 TimeSeriesSplit 或滚动窗口切分器，不能用随机 K 折替代。

        regressor=Pipeline([
            ('scale', StandardScaler()),
            ('svr', SVR()),

        transformer=StandardScaler(),
    )
    grid_search = GridSearchCV(
        estimator,
        param_grid=param_grid,
        cv=cv,
        scoring=scoring,
        refit=True,
    )
    grid_search.fit(X_train, y_train)
    return grid_search
```

## 6. ARIMA模型

### 算法介绍

ARIMA（自回归差分移动平均）模型是经典的时间序列预测模型。

**ARIMA(p, d, q)模型**：

**AR(p)部分**：$X_t = c + \sum_{i=1}^{p} \phi_i X_{t-i} + \varepsilon_t$

**I(d)部分**：差分$d$次实现平稳

**MA(q)部分**：$X_t = \mu + \sum_{i=1}^{q} \theta_i \varepsilon_{t-i} + \varepsilon_t$

**完整形式**（差分后）：
$$
(1 - \sum_{i=1}^{p} \phi_i L^i)(1 - L)^d X_t = (1 + \sum_{i=1}^{q} \theta_i L^i) \varepsilon_t
$$

其中$L$是滞后算子，$L X_t = X_{t-1}$。

### 适用范围

| 题型类型 | 典型问题 | 特征 |
|---------|---------|------|
| 时间序列 | 经济指标预测 | 单变量时序 |
| 销售预测 | 产品销量预测 | 趋势+季节性 |
| 金融预测 | 股价、利率预测 | 波动性 |
| 气象预测 | 气温、降雨量预测 | 周期性 |

### 可视化图表类型

- **时序图**：原始数据和预测值
- **ACF/PACF图**：自相关和偏自相关
- **残差图**：模型残差检验
- **预测区间图**：置信区间

```python
from statsmodels.tsa.arima.model import ARIMA
from statsmodels.tsa.stattools import adfuller
from statsmodels.graphics.tsaplots import plot_acf, plot_pacf
import numpy as np

# 平稳性检验
def test_stationarity(timeseries):
    """ADF平稳性检验"""
    result = adfuller(timeseries)
    return {'ADF Statistic': result[0], 'p-value': result[1]}

# ARIMA建模
def arima_forecast(train_data, test_steps, order=(1,1,1)):
    """在冻结阶数后拟合 ARIMA 并预测指定步数。"""
    train_data = np.asarray(train_data, dtype=float)
    if train_data.ndim != 1 or len(train_data) < 3 or np.any(~np.isfinite(train_data)):
        raise ValueError("train_data 必须是至少含 3 个有限值的一维序列")
    if not isinstance(test_steps, int) or isinstance(test_steps, bool) or test_steps < 1:
        raise ValueError("test_steps 必须是正整数")
    if (not isinstance(order, tuple) or len(order) != 3
            or any(not isinstance(value, int) or isinstance(value, bool) or value < 0
                   for value in order)):
        raise ValueError("order 必须是三个非负整数构成的元组")
    model = ARIMA(train_data, order=order)
    fitted_model = model.fit()
    forecast = fitted_model.forecast(steps=test_steps)
    return forecast, fitted_model

# 在声明的有限网格内按 AIC 选择候选阶数
def select_arima_order(train_data, max_p, max_d, max_q):
    """按 AIC 枚举有限候选网格；这不等于样本外预测最优。"""
    train_data = np.asarray(train_data, dtype=float)
    if train_data.ndim != 1 or len(train_data) < 3 or np.any(~np.isfinite(train_data)):
        raise ValueError("train_data 必须是至少含 3 个有限值的一维序列")
    for name, value in {"max_p": max_p, "max_d": max_d, "max_q": max_q}.items():
        if not isinstance(value, int) or isinstance(value, bool) or value < 0:
            raise ValueError(f"{name} 必须是非负整数")
    selected_aic = np.inf
    selected_order = None
    failures = []

    for p in range(max_p + 1):
        for d in range(max_d + 1):
            for q in range(max_q + 1):
                try:
                    model = ARIMA(train_data, order=(p, d, q))
                    results = model.fit()
                    converged = bool(getattr(results, "mle_retvals", {}).get("converged", True))
                    if not converged or not np.isfinite(results.aic):
                        failures.append({
                            "order": (p, d, q),
                            "error": "未收敛或 AIC 非有限数",
                        })
                        continue
                    if results.aic < selected_aic:
                        selected_aic = results.aic
                        selected_order = (p, d, q)
                except (ValueError, np.linalg.LinAlgError) as exc:
                    failures.append({"order": (p, d, q), "error": str(exc)})

    if selected_order is None:
        raise RuntimeError(f"所有 ARIMA 候选均拟合失败: {failures}")
    return {
        "selected_order": selected_order,
        "selected_aic": float(selected_aic),
        "selection_scope": "declared_candidate_grid_aic_only",
```

## 7. 指数平滑法 (Exponential Smoothing)

### 算法介绍

指数平滑法通过对历史数据加权平均进行预测，近期数据权重更大。

#### 7.1 简单指数平滑

适用于无趋势、无季节性的数据。

$$
F_{t+1} = \alpha y_t + (1 - \alpha) F_t
$$

其中$\alpha \in (0, 1)$是平滑系数。

#### 7.2 Holt线性趋势法

适用于有趋势、无季节性的数据。

**水平方程**：$L_t = \alpha y_t + (1 - \alpha)(L_{t-1} + T_{t-1})$

**趋势方程**：$T_t = \beta(L_t - L_{t-1}) + (1 - \beta)T_{t-1}$

**预测**：$F_{t+m} = L_t + m T_t$

#### 7.3 Holt-Winters季节性方法

适用于有趋势和季节性的数据。

**水平方程**：$L_t = \alpha \frac{y_t}{S_{t-s}} + (1 - \alpha)(L_{t-1} + T_{t-1})$

**趋势方程**：$T_t = \beta(L_t - L_{t-1}) + (1 - \beta)T_{t-1}$

**季节方程**：$S_t = \gamma \frac{y_t}{L_t} + (1 - \gamma)S_{t-s}$

**预测**：$F_{t+m} = (L_t + m T_t) S_{t-s+m}$

### 适用范围

| 题型类型 | 典型问题 | 特征 |
|---------|---------|------|
| 短期预测 | 销售预测 | 短期趋势 |
| 库存预测 | 需求预测 | 平稳变化 |
| 季节性预测 | 季节性商品销售 | 季节波动 |
| 平稳序列 | 指标监测 | 无明显趋势 |

### 可视化图表类型

- **时序预测图**：历史数据+预测值
- **分解图**：趋势、季节、残差分解
- **误差分析图**：预测误差分析

### 关键文献

| 论文名称 | 作者 | 年份 | 来源 |
|---------|------|------|------|
| Forecasting: principles and practice | Hyndman & Athanasopoulos | 2018 | OTexts |

```python
import numpy as np
from statsmodels.tsa.holtwinters import SimpleExpSmoothing, Holt, ExponentialSmoothing

def _validate_smoothing_data(data, minimum_length):
    data = np.asarray(data, dtype=float)
    if data.ndim != 1 or len(data) < minimum_length or np.any(~np.isfinite(data)):
        raise ValueError(f"data 必须是至少含 {minimum_length} 个有限值的一维序列")
    return data

def _validate_smoothing_rate(value, name):
    if not np.isfinite(value) or not 0 < value < 1:
        raise ValueError(f"{name} 必须位于 (0, 1)")

# 简单指数平滑
def simple_exponential_smoothing(data, alpha, forecast_steps):
    """简单指数平滑；预测步数必须由任务显式给出。"""
    if not isinstance(forecast_steps, int) or isinstance(forecast_steps, bool) or forecast_steps < 1:
        raise ValueError("forecast_steps 必须是正整数")
    data = _validate_smoothing_data(data, 2)
    _validate_smoothing_rate(alpha, "alpha")
    model = SimpleExpSmoothing(data)
    fit = model.fit(smoothing_level=alpha, optimized=False)
    forecast = fit.forecast(steps=forecast_steps)
    return forecast, fit

# Holt线性趋势法
def holt_linear_trend(data, alpha, beta, forecast_steps):
    """Holt 线性趋势法；预测步数必须由任务显式给出。"""
    if not isinstance(forecast_steps, int) or isinstance(forecast_steps, bool) or forecast_steps < 1:
        raise ValueError("forecast_steps 必须是正整数")
    data = _validate_smoothing_data(data, 3)
    _validate_smoothing_rate(alpha, "alpha")
    _validate_smoothing_rate(beta, "beta")
    model = Holt(data)
    fit = model.fit(smoothing_level=alpha, smoothing_trend=beta, optimized=False)
    forecast = fit.forecast(steps=forecast_steps)
    return forecast, fit

# Holt-Winters季节性方法
def holt_winters(data, seasonal_periods, forecast_steps,
                 trend='add', seasonal='add'):
    """Holt-Winters；季节长度和预测步数都必须来自数据频率与任务。"""
    if (not isinstance(seasonal_periods, int) or isinstance(seasonal_periods, bool)
            or seasonal_periods < 2):
        raise ValueError("seasonal_periods 必须是不小于 2 的整数")
    if not isinstance(forecast_steps, int) or isinstance(forecast_steps, bool) or forecast_steps < 1:
        raise ValueError("forecast_steps 必须是正整数")
    data = _validate_smoothing_data(data, 2 * seasonal_periods)
    model = ExponentialSmoothing(data, trend=trend, seasonal=seasonal,
                                 seasonal_periods=seasonal_periods)
    fit = model.fit()
    forecast = fit.forecast(steps=forecast_steps)
    return forecast, fit
```

## 8. Prophet预测模型

### 算法介绍

Prophet是Facebook开发的时间序列预测模型，适合具有季节性和节假日效应的商务时间序列。

**模型公式**：
$$
y(t) = g(t) + s(t) + h(t) + \varepsilon_t
$$

其中：
- $g(t)$：趋势项（线性或逻辑斯谛）
- $s(t)$：季节项（傅里叶级数）
- $h(t)$：节假日效应
- $\varepsilon_t$：误差项

**趋势项**（分段线性）：$g(t) = \left(k + \mathbf{a}(t)^T\boldsymbol{\delta}\right)t + \left(m + \mathbf{a}(t)^T\boldsymbol{\gamma}\right)$，其中变点修正 $\boldsymbol{\gamma}$ 用于保持趋势连续。

**季节项**：$s(t) = \sum_{n=1}^{N} [a_n \cos(\frac{2\pi n t}{P}) + b_n \sin(\frac{2\pi n t}{P})]$

### 适用范围

| 题型类型 | 典型问题 | 特征 |
|---------|---------|------|
| 商务预测 | 销售量预测 | 季节性强 |
| 流量预测 | 网站访问量 | 节假日效应 |
| 用户增长 | 用户数预测 | 趋势+周期 |
| 库存预测 | 商品需求 | 多种影响因素 |

### 可视化图表类型

- **预测分解图**：趋势、季节、节假日分解
- **预测区间图**：不确定性区间
- **组件影响图**：各组件贡献

### 关键文献

| 论文名称 | 作者 | 年份 | 来源 |
|---------|------|------|------|
| Forecasting at scale | Taylor & Letham | 2018 | arXiv |

```python
from prophet import Prophet
import pandas as pd

def prophet_forecast(df, periods, frequency, seasonality_mode,
                     yearly_seasonality, weekly_seasonality,
                     daily_seasonality, custom_seasonalities=None):
    """
    Prophet时间序列预测
    :param df: DataFrame with columns 'ds' (datetime) and 'y' (value)
    :param periods: 预测步数，必须由题目预测跨度确定
    :param frequency: 显式时间频率，如 'D'、'W' 或 'MS'
    :param custom_seasonalities: 有数据或领域依据的自定义季节项字典列表
    :return: 预测结果
    """
    required_columns = {'ds', 'y'}
    if not required_columns.issubset(df.columns):
        raise ValueError("df 必须包含 ds 和 y 两列")
    if not isinstance(periods, int) or periods < 1:
        raise ValueError("periods 必须是正整数")
    if seasonality_mode not in {'additive', 'multiplicative'}:
        raise ValueError("seasonality_mode 只能是 additive 或 multiplicative")
    # 创建模型
    model = Prophet(
        yearly_seasonality=yearly_seasonality,
        weekly_seasonality=weekly_seasonality,
        daily_seasonality=daily_seasonality,
        seasonality_mode=seasonality_mode,
    )

    for seasonal in custom_seasonalities or []:
        model.add_seasonality(**seasonal)

    # 拟合模型
    model.fit(df)

    # 创建未来日期
    future = model.make_future_dataframe(periods=periods, freq=frequency)

    # 预测
    forecast = model.predict(future)

    return forecast, model
```

## 9. XGBoost/LightGBM预测模型

### 算法介绍

XGBoost和LightGBM是两种高效的梯度提升决策树算法，广泛应用于各类预测问题。

#### 9.1 XGBoost (eXtreme Gradient Boosting)

**核心思想**：通过迭代添加弱学习器（决策树）来最小化目标函数。

**目标函数**：
$$
Obj(\Theta) = \sum_{i=1}^{n} L(y_i, \hat{y}_i) + \sum_{k=1}^{K} \Omega(f_k)
$$

其中：
- $L$：损失函数（如平方损失、逻辑损失）
- $\Omega$：正则化项（控制模型复杂度）

**二阶泰勒展开**：
$$
Obj^{(t)} \approx \sum_{i=1}^{n} [L(y_i, \hat{y}_i^{(t-1)}) + g_i f_t(x_i) + \frac{1}{2} h_i f_t^2(x_i)] + \Omega(f_t)
$$

其中 $g_i = \partial_{\hat{y}^{(t-1)}} L(y_i, \hat{y}^{(t-1)})$，$h_i = \partial_{\hat{y}^{(t-1)}}^2 L(y_i, \hat{y}^{(t-1)})$

**最优目标函数值**：
$$
\tilde{Obj}^{(t)} = -\frac{1}{2} \sum_{j=1}^{T}
\frac{\left(\sum_{i\in I_j} g_i\right)^2}{\sum_{i\in I_j} h_i + \lambda}
+ \gamma T
$$

其中 $I_j$ 是落入第 $j$ 个叶节点的样本集合，$T$ 是叶节点数；不能把逐样本梯度平方之和误写成逐叶聚合后的分子。

#### 9.2 LightGBM (Light Gradient Boosting Machine)

**核心改进**：
- **基于直方图的决策树**：将连续特征离散化为bins，加速训练
- **带深度限制的叶子增长（Leaf-wise）**：选择增益最大的叶子分裂
- **特征捆绑**：将互斥特征捆绑降低维度
- **单边梯度采样（GOSS）**：保留大梯度样本，随机采样小梯度样本

**目标函数**：
$$
Obj(\Theta) = \sum_{i=1}^{n} g_i f_t(x_i) + \frac{1}{2} \sum_{i=1}^{n} h_i f_t^2(x_i) + \Omega(f_t)
$$

### 适用范围

| 题型类型 | 典型问题 | 特征 |
|---------|---------|------|
| 表格数据预测 | 销量预测、用户行为 | 结构化数据 |
| 时间序列预测 | 股价、负荷预测 | 序列特征 |
| 分类预测 | 违约预测、疾病诊断 | 二分类/多分类 |
| 排序预测 | 搜索排名、推荐 | 排序任务 |
| 异常检测 | 欺诈检测 | 不平衡数据 |

### 可视化图表类型

- **特征重要性图**：特征贡献排序
- **SHAP值图**：特征对预测的影响
- **学习曲线**：训练/验证误差
- **残差图**：预测误差分析
- **树可视化**：决策树结构

```python
    prediction_iteration = model.best_iteration or n_estimators
    y_pred = model.predict(X_predict, num_iteration=prediction_iteration)
```

## 10. 时空预测模型

### 算法介绍

时空预测模型用于同时考虑时间和空间相关性的预测问题，如交通流量预测、空气质量预测、疫情传播等。

#### 10.1 时空数据特点

**时空相关性**：
- **时间依赖**：当前状态受历史状态影响
- **空间依赖**：当前位置受邻近位置影响
- **时空交互**：时间和空间相互影响

**时空数据表示**：
$$
X \in \mathbb{R}^{N \times T \times F}
$$

其中：$N$是空间节点数，$T$是时间步长，$F$是特征维度。

#### 10.2 经典时空预测模型

**ARIMA时空扩展**：STARIMA
$$
X_t = \sum_{k=1}^{p} \Phi_k X_{t-k} + \sum_{l=1}^{q} \Theta_l \epsilon_{t-l} + \epsilon_t
$$

**时空图卷积网络**：STGCN

结合图卷积网络(GCN)和时序卷积网络(TCN)。

**图卷积层**：
$$
H^{(l+1)} = \sigma(\tilde{D}^{-\frac{1}{2}}\tilde{A}\tilde{D}^{-\frac{1}{2}} H^{(l)} W^{(l)})
$$

其中$\tilde{A} = A + I$（加入自连接），$\tilde{D}_{ii} = \sum_j \tilde{A}_{ij}$

**时间卷积层**：使用1D卷积捕获时序模式。

#### 10.3 交通流量预测示例

**基于图神经网络的交通预测**：

1. **构建道路网络图**：$G = (V, E, W)$
   - $V$：道路节点
   - $E$：道路连接
   - $W$：连接权重（距离、相似度等）

2. **时空注意力机制**：
$$
\alpha_{ij}^t = \frac{\exp(score(s_i^t, s_j^t))}{\sum_{k \in \mathcal{N}(i)} \exp(score(s_i^t, s_k^t))}
$$

3. **预测输出**：
$$
\hat{X}_{t+1:t+H} = \text{Decoder}(\text{Encoder}(X_{t-T:t}, G))
$$

#### 10.4 评价指标

**RMSE**（均方根误差）：
$$
RMSE = \sqrt{\frac{1}{NTH} \sum_{n,t,h} (X_{n,t+h} - \hat{X}_{n,t+h})^2}
$$

**MAE**（平均绝对误差）：
$$
MAE = \frac{1}{NTH} \sum_{n,t,h} |X_{n,t+h} - \hat{X}_{n,t+h}|
$$

**MAPE**（平均绝对百分比误差）：
$$
MAPE = \frac{100\%}{NTH} \sum_{n,t,h} \left|\frac{X_{n,t+h} - \hat{X}_{n,t+h}}{X_{n,t+h}}\right|
$$

### 适用范围

| 题型类型 | 典型问题 | 特征 |
|---------|---------|------|
| 交通预测 | 道路流量、地铁客流 | 路网结构 |
| 环境预测 | 空气质量、温度场 | 空间扩散 |
| 疫情预测 | 疾病传播 | 区域传播 |
| 能源预测 | 区域电力负荷 | 电网结构 |
| 经济预测 | 区域经济指标 | 空间溢出 |

- **时空热力图**：预测值在时空上的分布

### 代码实现要点

下面代码是用于说明“时间卷积＋一次归一化图传播”的教学基线，不是 Yu 等（2018）STGCN 架构的复现，也不能沿用原论文名称声称同等机制或性能。若要复现论文，必须按原文实现时空卷积块、图卷积参数化、数据切分和训练协议，并用可信实现或基准数据作 oracle。

```python
import numpy as np
import torch
import torch.nn as nn
import networkx as nx
import matplotlib.pyplot as plt

# 构建时空图
def build_spatial_graph(matrix, threshold, mode):
    """
    构建空间图
    :param matrix: 对称的相似度矩阵或距离矩阵
    :param threshold: 由领域尺度或验证方案预先声明的连接阈值
    :param mode: 'similarity'（值大于等于阈值连边）或 'distance'（值小于等于阈值连边）
    :return: NetworkX图
    """
    matrix = np.asarray(matrix, dtype=float)
    if matrix.ndim != 2 or matrix.shape[0] != matrix.shape[1]:
        raise ValueError("空间矩阵必须是方阵")
    if not np.all(np.isfinite(matrix)) or not np.allclose(matrix, matrix.T):
        raise ValueError("此无向图示例要求有限对称矩阵；有向关系须另建有向模型")
    if mode not in {'similarity', 'distance'}:
        raise ValueError("mode 必须为 'similarity' 或 'distance'")
    if mode == 'distance' and np.any(matrix < 0):
        raise ValueError("距离不能为负")

    G = nx.Graph()
    n = matrix.shape[0]
    G.add_nodes_from(range(n))

    for i in range(n):
        for j in range(i+1, n):
            value = matrix[i, j]
            connected = value >= threshold if mode == 'similarity' else value <= threshold
            if connected:
                G.add_edge(i, j, weight=value)

    return G

def compute_normalized_adjacency(adj_matrix, add_self_loops=True):
    """
    计算对称归一化邻接矩阵
    :param adj_matrix: 邻接矩阵
    :return: 归一化拉普拉斯矩阵
    """
    A = np.asarray(adj_matrix, dtype=float)
    if A.ndim != 2 or A.shape[0] != A.shape[1]:
        raise ValueError("邻接矩阵必须是方阵")
    if not np.all(np.isfinite(A)) or np.any(A < 0) or not np.allclose(A, A.T):
        raise ValueError("此无向归一化拉普拉斯示例要求有限、非负、对称邻接矩阵")
    A = A.copy()
    if add_self_loops:
        A += np.eye(A.shape[0])
    degrees = A.sum(axis=1)
    inverse_sqrt = np.zeros_like(degrees)
    positive = degrees > 0
    inverse_sqrt[positive] = 1.0 / np.sqrt(degrees[positive])
    normalized_adjacency = inverse_sqrt[:, None] * A * inverse_sqrt[None, :]
    return torch.FloatTensor(normalized_adjacency)

# 教学用“时间卷积＋线性图传播”块
class SimplifiedGraphTemporalBlock(nn.Module):
    """自定义简化块；不是原论文 STGCNBlock。"""
    def __init__(self, in_channels, out_channels):
        super().__init__()
        self.temporal_conv = nn.Conv2d(in_channels, out_channels, kernel_size=(1, 3), padding=(0, 1))
        self.graph_conv = GraphLinearPropagation(out_channels, out_channels)
        self.bn = nn.BatchNorm2d(out_channels)
        self.relu = nn.ReLU()

    def forward(self, x, normalized_adjacency):
        # x: (batch, channels, time, nodes)
        x = self.temporal_conv(x)
        x = self.graph_conv(x, normalized_adjacency)
        x = self.bn(x)
        x = self.relu(x)
        return x

class GraphLinearPropagation(nn.Module):
    """一次归一化邻接传播后做通道线性变换。"""
    def __init__(self, in_channels, out_channels):
        super().__init__()
        self.theta = nn.Parameter(torch.FloatTensor(in_channels, out_channels))
        nn.init.xavier_uniform_(self.theta)

    def forward(self, x, normalized_adjacency):
        # x: (batch, channels, time, nodes)
        batch, channels, time, nodes = x.shape
        x = x.permute(0, 2, 3, 1)  # (batch, time, nodes, channels)
        x = torch.matmul(x, self.theta)  # (batch, time, nodes, out_channels)
        x = torch.matmul(normalized_adjacency, x)
        x = x.permute(0, 3, 1, 2)  # (batch, out_channels, time, nodes)
        return x

# 简化的图时序预测基线
class SimplifiedGraphTemporalPredictor(nn.Module):
    """教学基线；禁止称为原论文 STGCN 复现。"""
    def __init__(self, input_dim, hidden_dim, output_dim, seq_len, pred_len):
        super().__init__()
        self.seq_len = seq_len
        self.pred_len = pred_len

        self.block1 = SimplifiedGraphTemporalBlock(input_dim, hidden_dim)
        self.block2 = SimplifiedGraphTemporalBlock(hidden_dim, hidden_dim)
        self.block3 = SimplifiedGraphTemporalBlock(hidden_dim, output_dim)

        # 输出层
        self.fc = nn.Linear(seq_len, pred_len)

    def forward(self, x, normalized_adjacency):
        # x: (batch, features, time, nodes)
        x = self.block1(x, normalized_adjacency)
        x = self.block2(x, normalized_adjacency)
        x = self.block3(x, normalized_adjacency)

        # 时间维度映射
        batch, channels, time, nodes = x.shape
        x = x.permute(0, 3, 2, 1)  # (batch, nodes, time, channels)
        x = x.reshape(batch * nodes, time, channels)
        x = x.permute(0, 2, 1)  # (batch*nodes, channels, time)
        x = self.fc(x)  # (batch*nodes, channels, pred_len)
        x = x.permute(0, 2, 1)  # (batch*nodes, pred_len, channels)
        x = x.reshape(batch, nodes, self.pred_len, -1)
        x = x.permute(0, 3, 2, 1)  # (batch, channels, pred_len, nodes)

        return x

def train_simplified_graph_temporal_model(
        X_train, y_train, X_validation, y_validation, adj_matrix,
        hidden_dim, epochs, lr, random_state, device_name):
    """
    训练教学用简化图时序基线，并以显式验证损失选择 epoch
    :param X_train: (samples, features, time, nodes)
    :param y_train: (samples, features, pred_time, nodes)
    :param X_validation/y_validation: 按时间或组别隔离的验证集
    :param adj_matrix: 邻接矩阵
    :return: 恢复到最小验证损失 epoch 的模型与训练记录
    """
    arrays = [
        np.asarray(value, dtype=np.float32)
        for value in (X_train, y_train, X_validation, y_validation)
    ]
    X_train, y_train, X_validation, y_validation = arrays
    if any(value.ndim != 4 or np.any(~np.isfinite(value)) for value in arrays):
        raise ValueError("训练与验证输入输出必须是有限四维数组")
    if (X_train.shape[0] != y_train.shape[0]
            or X_validation.shape[0] != y_validation.shape[0]
            or X_train.shape[1] != X_validation.shape[1]
            or X_train.shape[2:] != X_validation.shape[2:]
            or y_train.shape[1:] != y_validation.shape[1:]
            or X_train.shape[3] != y_train.shape[3]):
        raise ValueError("训练/验证的样本、特征、时间和节点维合同不一致")
    if (not isinstance(hidden_dim, int) or isinstance(hidden_dim, bool) or hidden_dim < 1
            or not isinstance(epochs, int) or isinstance(epochs, bool) or epochs < 1
            or not np.isfinite(lr) or lr <= 0
            or not isinstance(random_state, int) or isinstance(random_state, bool)):
        raise ValueError("hidden_dim/epochs 必须为正整数，lr 为有限正数，random_state 为整数")
    if device_name not in {'cpu', 'cuda'}:
        raise ValueError("device_name 必须显式取 'cpu' 或 'cuda'")
    if device_name == 'cuda' and not torch.cuda.is_available():
        raise RuntimeError("请求 cuda，但当前环境不可用")
    device = torch.device(device_name)
    torch.manual_seed(random_state)
    if device.type == 'cuda':
        torch.cuda.manual_seed_all(random_state)

    normalized_adjacency = compute_normalized_adjacency(adj_matrix).to(device)
    if normalized_adjacency.shape != (X_train.shape[3], X_train.shape[3]):
        raise ValueError("adj_matrix 的节点数必须与样本节点维一致")

    X_train_tensor = torch.from_numpy(X_train).to(device)
    y_train_tensor = torch.from_numpy(y_train).to(device)
    X_validation_tensor = torch.from_numpy(X_validation).to(device)
    y_validation_tensor = torch.from_numpy(y_validation).to(device)

    # 初始化模型
    model = SimplifiedGraphTemporalPredictor(
        input_dim=X_train_tensor.shape[1],
        hidden_dim=hidden_dim,
        output_dim=y_train_tensor.shape[1],
        seq_len=X_train_tensor.shape[2],
        pred_len=y_train_tensor.shape[2]
    ).to(device)

    optimizer = torch.optim.Adam(model.parameters(), lr=lr)
    criterion = nn.MSELoss()

    training_losses = []
    validation_losses = []
    best_validation_loss = float('inf')
    best_epoch = None
    best_state = None
    for epoch in range(epochs):
        model.train()
        optimizer.zero_grad()

        outputs = model(X_train_tensor, normalized_adjacency)
        loss = criterion(outputs, y_train_tensor)

        loss.backward()
        optimizer.step()

        training_losses.append(float(loss.item()))

        model.eval()
        with torch.no_grad():
            validation_outputs = model(X_validation_tensor, normalized_adjacency)
            validation_loss = criterion(validation_outputs, y_validation_tensor)
        validation_value = float(validation_loss.item())
        validation_losses.append(validation_value)
        if validation_value < best_validation_loss:
            best_validation_loss = validation_value
            best_epoch = epoch + 1
            best_state = {
                name: value.detach().cpu().clone()
                for name, value in model.state_dict().items()
            }

        if (epoch + 1) % 10 == 0:
            print(
                f'Epoch [{epoch+1}/{epochs}], train={loss.item():.4f}, '
                f'validation={validation_value:.4f}'
            )

    if best_state is None:
        raise RuntimeError("未得到有限的验证损失，无法选择模型")
    model.load_state_dict(best_state)
    return model, {
        "training_loss": training_losses,
        "validation_loss": validation_losses,
        "best_epoch_by_validation_loss": best_epoch,
        "best_validation_loss": best_validation_loss,
        "random_state": random_state,
        "device": device_name,
        "model_scope": "simplified_graph_temporal_baseline_not_original_stgcn",
        "reproducibility_note": "跨硬件与库版本仍须按复现清单重新核验",
    }

# 绘制时空预测结果
def plot_spatiotemporal_prediction(true_values, pred_values, node_ids, times, title="时空预测结果"):
    """
    绘制时空预测结果
    :param true_values: 真实值 (time, nodes)
    :param pred_values: 预测值 (time, nodes)
    :param node_ids: 节点ID列表
    :param times: 时间点列表
    :param title: 图标题
    """
    fig, axes = plt.subplots(1, 2, figsize=(14, 5))

    # 真实值热力图
    im1 = axes[0].imshow(true_values.T, aspect='auto', cmap='YlOrRd', origin='lower')
    axes[0].set_xlabel('Time Step')
    axes[0].set_ylabel('Node')
    axes[0].set_title('True Values')
    axes[0].set_yticks(range(len(node_ids)))
    axes[0].set_yticklabels(node_ids)
    plt.colorbar(im1, ax=axes[0])

    # 预测值热力图
    im2 = axes[1].imshow(pred_values.T, aspect='auto', cmap='YlOrRd', origin='lower')
    axes[1].set_xlabel('Time Step')
    axes[1].set_ylabel('Node')
    axes[1].set_title('Predicted Values')
    axes[1].set_yticks(range(len(node_ids)))
    axes[1].set_yticklabels(node_ids)
    plt.colorbar(im2, ax=axes[1])

    plt.suptitle(title)
    plt.tight_layout()
    plt.show()

def evaluate_st_model(y_true, y_pred):
    """
    评估时空预测模型
    :param y_true: 真实值 (samples, features, time, nodes)
    :param y_pred: 预测值 (samples, features, time, nodes)
    :return: 评估指标字典
    """
    y_true = np.asarray(y_true, dtype=float)
    y_pred = np.asarray(y_pred, dtype=float)
    if y_true.shape != y_pred.shape:
        raise ValueError("y_true 与 y_pred 形状必须相同")
    if not np.all(np.isfinite(y_true)) or not np.all(np.isfinite(y_pred)):
        raise ValueError("评价输入必须为有限数")

    y_true = y_true.reshape(-1)
    y_pred = y_pred.reshape(-1)

    rmse = np.sqrt(np.mean((y_true - y_pred) ** 2))
    mae = np.mean(np.abs(y_true - y_pred))
    abs_sum = np.sum(np.abs(y_true))
    wape = np.sum(np.abs(y_true - y_pred)) / abs_sum * 100 if abs_sum > 0 else None

    # 不用任意 epsilon 掩盖零分母。MAPE 只在真实值严格为正且其比例含义合理时给出。
    mape_applicable = bool(np.all(y_true > 0))
    mape = (
        np.mean(np.abs((y_true - y_pred) / y_true)) * 100
        if mape_applicable else None
    )

    return {
        'RMSE': rmse,
        'MAE': mae,
        'WAPE': wape,
        'MAPE': mape,
        'MAPE_applicable': mape_applicable,
        'MAPE_note': (
            '真实值均为正；仍需检查近零值是否使比例误差失真'
            if mape_applicable else '含零值或负值，未计算 MAPE'
        ),
    }
```

## 预测算法筛选原则

下列方法只用于生成候选，不能按样本量或预测跨度自动路由。小样本本身不推出灰色预测，大样本也不自动证明深度学习更优；必须同时核对数据生成机制、模型容量、验证设计和不确定性。

| 决策维度 | 必查问题 | 可形成的候选 |
|---|---|---|
| 时间结构 | 是否有趋势、季节、结构突变、自相关和不规则采样 | 朴素/季节朴素基线、指数平滑、ARIMA、状态空间、分解模型 |
| 外生信息 | 协变量在预测时是否真实可得，是否存在滞后或因果方向问题 | 动态回归、VAR、树模型、带外生变量的状态空间或机器学习模型 |
| 样本与容量 | 有效独立样本数能否支撑参数量，组别和时间相关是否降低有效样本量 | 正则化回归、层次模型、核方法、树模型或神经网络；容量由验证控制 |
| 预测跨度 | 递推误差、长期均值回归和情景假设是否可解释 | 直接多步、递归、多输出或情景模拟；“天/月”不是跨领域通用阈值 |
| 输出口径 | 题目需要点、区间、分位数、概率还是决策损失 | 与口径匹配的概率模型、分位数回归、Bootstrap 或共形预测 |
| 机制约束 | 非负、守恒、单调、容量或状态转移约束是否必须满足 | 机理模型、受约束回归、混合模型或投影后处理，并检查约束偏差 |

所有候选在严格时间顺序、组别隔离和相同调参预算下与朴素基线比较。模型选择指标须与题目最终评价口径一致；报告样本外误差、区间覆盖、稳定性和失败区间，不能用拟合内残差或单次切分替代。
