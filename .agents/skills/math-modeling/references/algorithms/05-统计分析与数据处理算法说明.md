## 1. 数据预处理 (Data Preprocessing)

### 算法介绍

数据预处理是数据分析的第一步，包括数据清洗、变换、归约等操作。

#### 1.1 缺失值处理

**删除法**：删除含有缺失值的样本或特征
- 删除样本：适用于缺失比例小的样本
- 删除特征：适用于缺失比例大的特征

**填充法**：
- 均值填充：$x_{ij} = \bar{x}_j$（数值型）
- 中位数填充：$x_{ij} = \tilde{x}_j$（数值型，有异常值）
- 众数填充：$x_{ij} = \text{mode}(x_j)$（分类型）
- KNN填充：用K近邻的均值填充
- 回归填充：用回归模型预测缺失值

**插值法**：
- 线性插值：$x_t = \frac{x_{t-1} + x_{t+1}}{2}$
- 多项式插值
- 样条插值

#### 1.2 异常值检测与处理

**统计方法**：
- $3\sigma$原则：$|x_i - \bar{x}| > 3\sigma$
- 箱线图：$x_i < Q_1 - 1.5 \times IQR$ 或 $x_i > Q_3 + 1.5 \times IQR$
- Z-score：$|Z| > 3$ 为异常值

$$
Z_i = \frac{x_i - \bar{x}}{\sigma}
$$

**距离方法**：
- K近邻距离
- LOF（局部异常因子）

**处理方法**：
- 删除异常值
- 替换为边界值
- 对数变换
- 分箱处理

上述阈值只能产生“待核验异常候选”，不能自动证明数据错误。删除、截尾或替换前必须结合采集机制、题目语义和敏感性分析；在预测任务中，填补器、标准化器和异常阈值只能在训练折拟合，再原样应用到验证/测试折，禁止先用全数据拟合预处理器。

#### 1.3 数据标准化/归一化

**Min-Max归一化**：
$$
x'_i = \frac{x_i - \min(x)}{\max(x) - \min(x)}
$$

**Z-score标准化**：
$$
x'_i = \frac{x_i - \bar{x}}{\sigma}
$$

**小数定标标准化**：
$$
x'_i = \frac{x_i}{10^j}
$$

其中$j$是使$\max(|x'_i|) < 1$的最小整数。

#### 1.4 特征变换

**对数变换**：$x'_i = \log(x_i + c)$

**Box-Cox变换**：
$$
x'_i = \begin{cases}
\frac{x_i^\lambda - 1}{\lambda}, & \lambda \neq 0 \\
\ln(x_i), & \lambda = 0
\end{cases}
$$

**Yeo-Johnson变换**：可处理负值
$$
x'_i = \begin{cases}
\frac{(x_i + 1)^\lambda - 1}{\lambda}, & \lambda \neq 0, x_i \geq 0 \\
\ln(x_i + 1), & \lambda = 0, x_i \geq 0 \\
\frac{(-x_i + 1)^{2-\lambda} - 1}{2 - \lambda}, & \lambda \neq 2, x_i < 0 \\
-\ln(-x_i + 1), & \lambda = 2, x_i < 0
\end{cases}
$$

```python
import pandas as pd
import matplotlib.pyplot as plt
from sklearn.preprocessing import StandardScaler, MinMaxScaler, RobustScaler
from sklearn.impute import SimpleImputer, KNNImputer
from scipy import stats
import warnings
# 不全局屏蔽数值或收敛警告；按具体类别诊断并记录。

# 设置中文字体 - 多字体备选防止渲染问题
plt.rcParams['font.sans-serif'] = ['SimHei', 'DejaVu Sans', 'Arial Unicode MS', 'Microsoft YaHei', 'Arial']

class DataPreprocessor:
    """
    数据预处理类 - 包含缺失值处理、异常值检测、数据标准化等功能
    """
    
    @staticmethod
    def handle_missing_values(df, strategy='mean', columns=None,
                              fill_value=None, knn_neighbors=None):
        """
        缺失值处理
        :param df: DataFrame
        :param strategy: 填充策略 ('mean', 'median', 'most_frequent', 'constant', 'knn')
        :param columns: 要处理的列名列表，None表示全部数值列
        :param fill_value: 当strategy='constant'时的填充值
        :return: 处理后的DataFrame, 缺失值统计, 已拟合填补器
        """
        df_processed = df.copy()
        
        # 自动选择数值列
        if columns is None:
            columns = df.select_dtypes(include=[np.number]).columns.tolist()
        
        # 记录缺失值统计
        missing_stats = df[columns].isnull().sum()
        missing_stats = missing_stats[missing_stats > 0]
        
        if not columns:
            raise ValueError("没有可处理的列")
        if strategy == 'knn':
            if not isinstance(knn_neighbors, int) or knn_neighbors < 1:
                raise ValueError("KNN 填补必须显式给出正整数 knn_neighbors")
            imputer = KNNImputer(n_neighbors=knn_neighbors)
            df_processed[columns] = imputer.fit_transform(df[columns])
        elif strategy == 'constant':
            imputer = SimpleImputer(strategy='constant', fill_value=fill_value)
            df_processed[columns] = imputer.fit_transform(df[columns])
        else:
            imputer = SimpleImputer(strategy=strategy)
            df_processed[columns] = imputer.fit_transform(df[columns])
        
        return df_processed, missing_stats, imputer
    
    @staticmethod
    def detect_outliers_zscore(data, threshold):
        """
        使用Z-score检测异常值
        :param data: 数据数组
        :param threshold: Z-score阈值
        :return: 异常值索引, Z-score数组
        """
        data = np.asarray(data, dtype=float)
        if data.ndim != 1 or len(data) < 2 or np.any(~np.isfinite(data)):
            raise ValueError("data 必须是至少含两个有限值的一维数组")
        if threshold <= 0:
            raise ValueError("threshold 必须为正，且须记录选择依据")
        if np.ptp(data) == 0:
            return np.array([], dtype=int), np.zeros_like(data)
        z_scores = np.abs(stats.zscore(data, ddof=1))
        outlier_indices = np.where(z_scores > threshold)[0]
        return outlier_indices, z_scores
    
    @staticmethod
    def detect_outliers_iqr(data, k):
        """
        使用箱线图IQR方法检测异常值
        :param data: 数据数组
        :param k: 有依据的正 IQR 倍数
        :return: 异常值索引, 上下界
        """
        data = np.asarray(data, dtype=float)
        if data.ndim != 1 or len(data) < 2 or np.any(~np.isfinite(data)):
            raise ValueError("data 必须是至少含两个有限值的一维数组")
        if k <= 0:
            raise ValueError("k 必须为正，且须记录选择依据")
        Q1 = np.percentile(data, 25)
        Q3 = np.percentile(data, 75)
        IQR = Q3 - Q1
        lower_bound = Q1 - k * IQR
        upper_bound = Q3 + k * IQR
        outlier_indices = np.where((data < lower_bound) | (data > upper_bound))[0]
        return outlier_indices, (lower_bound, upper_bound)
    
    @staticmethod
    def detect_outliers_modified_zscore(data, threshold):
        """
        使用改进的Z-score（基于中位数绝对偏差MAD）检测异常值
        :param data: 数据数组
        :param threshold: 有依据的正阈值
        :return: 异常值索引
        """
        data = np.asarray(data, dtype=float)
        if data.ndim != 1 or len(data) < 2 or np.any(~np.isfinite(data)):
            raise ValueError("data 必须是至少含两个有限值的一维数组")
        if threshold <= 0:
            raise ValueError("threshold 必须为正，且须记录选择依据")
        median = np.median(data)
        mad = np.median(np.abs(data - median))
        if mad == 0:
            raise ValueError("MAD 为 0，改进 Z-score 无定义；应检查离散分布或换用适用规则")
        modified_z_scores = 0.6745 * (data - median) / mad
        outlier_indices = np.where(np.abs(modified_z_scores) > threshold)[0]
        return outlier_indices
    
    @staticmethod
    def standardize_data(data, method='zscore'):
        """
        数据标准化
        :param data: 用于拟合缩放器的训练数据矩阵 (样本×特征)
        :param method: 标准化方法 ('zscore', 'minmax', 'robust', 'maxabs')
        :return: 标准化后的数据, scaler对象
        """
        data = np.asarray(data, dtype=float)
        if data.ndim != 2 or data.shape[0] < 1 or data.shape[1] < 1 or np.any(~np.isfinite(data)):
            raise ValueError("data 必须是非空有限二维数组")
        if method == 'zscore':
            scaler = StandardScaler()
        elif method == 'minmax':
            scaler = MinMaxScaler()
        elif method == 'robust':
            scaler = RobustScaler()
        elif method == 'maxabs':
            from sklearn.preprocessing import MaxAbsScaler
            scaler = MaxAbsScaler()
        else:
            raise ValueError(f"Unknown method: {method}")
        
        standardized = scaler.fit_transform(data)
        return standardized, scaler
    
    @staticmethod
    def boxcox_transform(data, lmbda=None, shift=0.0):
        """
        Box-Cox变换（要求数据为正）
        :param data: 正数数据
        :param lmbda: 变换参数，None则自动选择
        :param shift: 有领域依据时显式声明的加性平移量
        :return: 变换后的数据, 使用的lambda, shift
        """
        data = np.asarray(data, dtype=float).reshape(-1)
        if not np.all(np.isfinite(data)) or not np.isfinite(shift):
            raise ValueError("data 与 shift 必须为有限数")
        adjusted = data + shift
        if np.any(adjusted <= 0):
            raise ValueError("Box-Cox 要求 data + shift 严格为正；不得自动平移而不记录")
        if lmbda is None:
            transformed, fitted_lambda = stats.boxcox(adjusted)
        else:
            fitted_lambda = float(lmbda)
            transformed = stats.boxcox(adjusted, lmbda=fitted_lambda)
        return transformed, fitted_lambda, float(shift)
    
    @staticmethod
    def yeo_johnson_transform(data, lmbda=None):
        """
        Yeo-Johnson变换（可处理负值）
        :param data: 数据
        :param lmbda: 变换参数，None则自动选择
        :return: 变换后的数据, 最优lambda
        """
        data = np.asarray(data, dtype=float).reshape(-1)
        if not np.all(np.isfinite(data)):
            raise ValueError("data 必须为有限数")
        if lmbda is None:
            transformed, fitted_lambda = stats.yeojohnson(data)
        else:
            fitted_lambda = float(lmbda)
            transformed = stats.yeojohnson(data, lmbda=fitted_lambda)
        return transformed, fitted_lambda
```

## 2. 聚类分析 (Cluster Analysis)

### 算法介绍

聚类分析是无监督学习方法，将相似样本归为一类。

#### 2.1 K-Means聚类

**目标函数**：
$$
J = \sum_{j=1}^{K} \sum_{x_i \in C_j} \|x_i - \mu_j\|^2
$$

其中$\mu_j$是簇$C_j$的质心。

**算法步骤**：
1. 随机选择$K$个初始质心
2. 将每个样本分配到最近的质心
3. 重新计算每个簇的质心
4. 重复2-3直到收敛

**时间复杂度**：$O(nKti)$（$n$样本数，$K$簇数，$t$迭代次数，$i$特征数）

**K值选择**：
- 肘部法则（Elbow Method）
- 轮廓系数（Silhouette Coefficient）
- Gap统计量

#### 2.2 层次聚类

**凝聚层次聚类**（自底向上）：
1. 每个样本作为一个簇
2. 合并最相似的两个簇
3. 重复直到只剩一个簇

**距离度量**：
- 单链接（Single Linkage）：$d(C_i, C_j) = \min_{x \in C_i, y \in C_j} d(x, y)$
- 全链接（Complete Linkage）：$d(C_i, C_j) = \max_{x \in C_i, y \in C_j} d(x, y)$
- 平均链接（Average Linkage）：$d(C_i, C_j) = \frac{1}{|C_i||C_j|} \sum_{x \in C_i, y \in C_j} d(x, y)$
- Ward方法：最小化合并后的方差增加

#### 2.3 DBSCAN聚类

基于密度的聚类算法，可以发现任意形状的簇。

**核心概念**：
- **核心点**：半径$\varepsilon$内至少有MinPts个点
- **边界点**：半径$\varepsilon$内点数少于MinPts，但可从核心点到达
- **噪声点**：既不是核心点也不是边界点

**算法步骤**：
1. 随机选择未访问的点$p$
2. 若$p$是核心点，创建新簇，添加所有密度可达点
3. 若$p$不是核心点，标记为噪声
4. 重复直到所有点被访问

#### 2.4 模糊C-Means聚类

每个样本以一定隶属度属于各个簇。

**目标函数**：
$$
J_m = \sum_{i=1}^{n} \sum_{j=1}^{c} u_{ij}^m \|x_i - c_j\|^2
$$

约束条件：$\sum_{j=1}^{c} u_{ij} = 1$, $u_{ij} \in [0, 1]$

其中$u_{ij}$是样本$i$对簇$j$的隶属度，$m > 1$是模糊系数。

#### 2.5 自组织映射 (Self-Organizing Maps, SOM)

**基本原理**：

SOM是一种基于竞争学习的神经网络，将高维数据映射到低维（通常是2D）网格上，同时保持拓扑结构。

**网络结构**：
- 输入层：$n$个神经元（对应$n$个特征）
- 输出层：$m \times m$的网格（竞争层）
- 每个输出神经元有一个权重向量$w_{ij} \in \mathbb{R}^n$

**学习算法**：

1. **初始化**：随机初始化权重向量$w_{ij}$

2. **竞争阶段**：对于输入样本$x$，找到最佳匹配单元（BMU）
$$
\text{BMU} = \arg\min_{i,j} \|x - w_{ij}\|
$$

3. **合作阶段**：确定邻域函数
$$
h_{ij,BMU}(t) = \exp\left(-\frac{d_{ij,BMU}^2}{2\sigma(t)^2}\right)
$$

其中$d_{ij,BMU}$是神经元$(i,j)$与BMU的网格距离，$\sigma(t)$是随时间衰减的邻域半径。

4. **适应阶段**：更新邻域内神经元的权重
$$
w_{ij}(t+1) = w_{ij}(t) + \eta(t) \cdot h_{ij,BMU}(t) \cdot (x - w_{ij}(t))
$$

其中$\eta(t)$是学习率，随时间递减。

5. **重复**：对所有样本迭代训练

**参数调整**：
- 学习率：$\eta(t) = \eta_0 \exp(-t/\tau)$
- 邻域半径：$\sigma(t) = \sigma_0 \exp(-t/\tau)$
- 训练轮数：通常需要数千次迭代

#### 2.6 高斯混合模型 (Gaussian Mixture Models, GMM)

**基本模型**：

GMM假设数据来自$K$个高斯分布的混合。

**概率密度函数**：
$$
p(x) = \sum_{k=1}^{K} \pi_k \mathcal{N}(x | \mu_k, \Sigma_k)
$$

其中：
- $\pi_k$是混合系数（权重），$\sum_{k=1}^{K} \pi_k = 1$
- $\mu_k$是第$k$个高斯分布的均值
- $\Sigma_k$是第$k$个高斯分布的协方差矩阵
- $\mathcal{N}(x | \mu_k, \Sigma_k) = \frac{1}{(2\pi)^{d/2}|\Sigma_k|^{1/2}} \exp\left(-\frac{1}{2}(x-\mu_k)^T\Sigma_k^{-1}(x-\mu_k)\right)$

**EM算法求解**：

**E步**：计算后验概率（责任度）
$$
\gamma(z_{nk}) = \frac{\pi_k \mathcal{N}(x_n | \mu_k, \Sigma_k)}{\sum_{j=1}^{K} \pi_j \mathcal{N}(x_n | \mu_j, \Sigma_j)}
$$

**M步**：更新参数
$$
\mu_k^{new} = \frac{\sum_{n=1}^{N} \gamma(z_{nk}) x_n}{\sum_{n=1}^{N} \gamma(z_{nk})}
$$

$$
\Sigma_k^{new} = \frac{\sum_{n=1}^{N} \gamma(z_{nk}) (x_n - \mu_k^{new})(x_n - \mu_k^{new})^T}{\sum_{n=1}^{N} \gamma(z_{nk})}
$$

$$
\pi_k^{new} = \frac{\sum_{n=1}^{N} \gamma(z_{nk})}{N}
$$

**协方差矩阵类型**：
- **full**：完全协方差矩阵（最灵活）
- **tied**：所有分量共享相同协方差
- **diag**：对角协方差
- **spherical**：球状协方差（各方向方差相同）

**模型选择**：
使用**贝叶斯信息准则（BIC）**或**赤池信息准则（AIC）**选择最优$K$值：

$$
\text{BIC} = -2 \log \mathcal{L} + p \log N
$$

$$
\text{AIC} = -2 \log \mathcal{L} + 2p
$$

其中$p$是参数数量，$N$是样本数。

```python
def kmeans_clustering(data, n_clusters=3, random_state=42):
    """
    K-Means聚类
    :param data: 数据矩阵 (样本×特征)
    :param n_clusters: 簇数
    :param random_state: 随机种子
    :return: 聚类标签, 质心, 模型
    """

            or not isinstance(n_clusters, (int, np.integer))
            or not 1 <= n_clusters <= data.shape[0]):

    kmeans = KMeans(n_clusters=int(n_clusters), random_state=random_state, n_init=10)
    labels = kmeans.fit_predict(data)
    return labels, kmeans.cluster_centers_, kmeans

def kmeans_inertia_curve(data, candidate_ks, random_state=42, plot=True):
    """
    计算预先声明的 K 候选的簇内平方和曲线
    :param data: 数据矩阵

    :param plot: 是否绘图
    :return: 候选 K 与对应 SSE；不声称自动确定最优 K
    """

    candidate_ks = list(candidate_ks)

# 自组织映射 (SOM)
def som_clustering(data, map_size=(10, 10), sigma=1.0, learning_rate=0.5,
                   num_iterations=1000, random_state=42):
    """
    自组织映射聚类
    :param data: 数据矩阵 (样本×特征)
    :param map_size: SOM网格大小 (行, 列)
    :param sigma: 初始邻域半径
    :param learning_rate: 初始学习率
    :param num_iterations: MiniSom 随机抽样更新次数，不是完整遍历数据的 epoch 数
    :param random_state: 随机种子
    :return: SOM模型, 聚类标签, U矩阵
    """
    try:
        from minisom import MiniSom
    except ImportError as exc:
        raise ImportError("som_clustering 需要可选依赖 minisom") from exc

    data = np.asarray(data, dtype=float)
    if data.ndim != 2 or data.shape[0] < 1 or data.shape[1] < 1 or np.any(~np.isfinite(data)):
        raise ValueError("data 必须是非空有限二维数组")
    if (not isinstance(map_size, tuple) or len(map_size) != 2
            or any(isinstance(value, bool) or not isinstance(value, int) or value < 1
                   for value in map_size)):
        raise ValueError("map_size 必须是两个正整数构成的元组")
    if not isinstance(num_iterations, int) or isinstance(num_iterations, bool) or num_iterations < 1:
        raise ValueError("num_iterations 必须是正整数")

    n_features = data.shape[1]
    som = MiniSom(x=map_size[0], y=map_size[1], input_len=n_features,
                  sigma=sigma, learning_rate=learning_rate,
                  random_state=random_state)

    som.random_weights_init(data)
    som.train_random(data, num_iterations, verbose=False)

    # 获取聚类标签（每个样本的BMU）
    labels = np.array([som.winner(x) for x in data])
    # 将二维坐标转换为一维标签
    labels_1d = labels[:, 0] * map_size[1] + labels[:, 1]

    # 计算U矩阵（统一距离矩阵）
    u_matrix = som.distance_map()

    return som, labels_1d, u_matrix

# 高斯混合模型
def gmm_clustering(data, n_components=3, covariance_type='full', random_state=42):
    """
    高斯混合模型聚类
    :param data: 数据矩阵 (样本×特征)
    :param n_components: 高斯分量数量
    :param covariance_type: 协方差类型 ('full', 'tied', 'diag', 'spherical')
    :param random_state: 随机种子
    :return: GMM模型, 聚类标签, 后验概率
    """
    from sklearn.mixture import GaussianMixture

    data = np.asarray(data, dtype=float)
    if data.ndim != 2 or data.shape[0] < 2 or data.shape[1] < 1 or np.any(~np.isfinite(data)):
        raise ValueError("data 必须是至少两个样本的有限二维数组")
    if (isinstance(n_components, (bool, np.bool_))
            or not isinstance(n_components, (int, np.integer))
            or not 1 <= n_components <= data.shape[0]):
        raise ValueError("n_components 必须是 1 到样本数之间的整数")
    if covariance_type not in {'full', 'tied', 'diag', 'spherical'}:
        raise ValueError("covariance_type 必须是 full/tied/diag/spherical")
    gmm = GaussianMixture(n_components=int(n_components),
                          covariance_type=covariance_type,
                          random_state=random_state,
                          max_iter=200)
    gmm.fit(data)

    labels = gmm.predict(data)
    posterior_probs = gmm.predict_proba(data)

    return gmm, labels, posterior_probs

def gmm_information_criterion_curve(data, component_candidates,
                                    covariance_type='full', random_state=42,
                                    plot=True):
    """
    在预先声明的候选集合内计算 GMM 的 BIC/AIC
    :param data: 数据矩阵
    :param component_candidates: 不重复且不超过样本数的正整数候选
    :param covariance_type: 协方差结构
    :param random_state: 随机种子
    :param plot: 是否绘制曲线
    :return: 各候选的 BIC/AIC 及候选集合内的最小值位置
    """
    from sklearn.mixture import GaussianMixture

    data = np.asarray(data, dtype=float)
    if data.ndim != 2 or data.shape[0] < 2 or data.shape[1] < 1 or np.any(~np.isfinite(data)):
        raise ValueError("data 必须是至少两个样本的有限二维数组")
    component_candidates = list(component_candidates)
    if (not component_candidates
            or len(set(component_candidates)) != len(component_candidates)
            or any(isinstance(value, (bool, np.bool_))
                   or not isinstance(value, (int, np.integer))
                   or value < 1 or value > data.shape[0]
                   for value in component_candidates)):
        raise ValueError("component_candidates 必须是不重复且不超过样本数的正整数")
    bic_scores = []
    aic_scores = []

    for n_components in component_candidates:
        gmm = GaussianMixture(n_components=int(n_components),
                              covariance_type=covariance_type,
                              random_state=random_state,
                              max_iter=200)
        gmm.fit(data)
        bic_scores.append(gmm.bic(data))
        aic_scores.append(gmm.aic(data))

    selected_by_bic = component_candidates[int(np.argmin(bic_scores))]
    selected_by_aic = component_candidates[int(np.argmin(aic_scores))]

    if plot:
        plt.figure(figsize=(10, 6))
        plt.plot(component_candidates, bic_scores, 'bo-', label='BIC')
        plt.plot(component_candidates, aic_scores, 'gs-', label='AIC')
        plt.axvline(x=selected_by_bic, color='b', linestyle='--',
                    label=f'Min BIC in candidates: {selected_by_bic}')
        plt.axvline(x=selected_by_aic, color='g', linestyle='--',
                    label=f'Min AIC in candidates: {selected_by_aic}')
        plt.xlabel('Number of Components')
        plt.ylabel('Information Criterion')
        plt.title('GMM: BIC and AIC for Different Component Numbers')
        plt.legend()
        plt.show()

    return {
        'bic': bic_scores,
        'aic': aic_scores,
        'component_candidates': component_candidates,
        'selected_by_bic': selected_by_bic,
        'selected_by_aic': selected_by_aic,
        'selection_scope': 'declared_candidates_only',
    }

def plot_gmm_results_2d(data, gmm, labels, confidence_levels=(0.5, 0.8, 0.95)):
    """
    绘制二维 GMM 分量及给定概率质量的模型椭圆
    :param data: 2D数据矩阵
    :param gmm: 拟合的GMM模型
    :param labels: 聚类标签
    :param confidence_levels: 二维高斯分量的概率质量水平
    """
    data = np.asarray(data, dtype=float)
    labels = np.asarray(labels)
    confidence_levels = tuple(float(level) for level in confidence_levels)
    if data.ndim != 2 or data.shape[1] != 2 or np.any(~np.isfinite(data)):
        raise ValueError("data 必须是有限二维坐标数组")
    if labels.shape != (data.shape[0],):
        raise ValueError("labels 长度必须等于样本数")
    if not confidence_levels or any(not 0 < level < 1 for level in confidence_levels):
        raise ValueError("confidence_levels 必须位于 (0, 1)")

    plt.figure(figsize=(12, 8))

    # 绘制数据点
    colors = plt.cm.tab10(np.linspace(0, 1, gmm.n_components))
    for k in range(gmm.n_components):
        mask = labels == k
        plt.scatter(data[mask, 0], data[mask, 1],
                   c=[colors[k]], label=f'Component {k}',
                   alpha=0.6, edgecolors='w', linewidth=0.5)

    # 绘制模型分量的概率质量椭圆
    from matplotlib.patches import Ellipse
    from scipy.stats import chi2
    for k in range(gmm.n_components):
        if gmm.covariance_type == 'full':
            cov = gmm.covariances_[k][:2, :2]
        elif gmm.covariance_type == 'tied':
            cov = gmm.covariances_[:2, :2]
        elif gmm.covariance_type == 'diag':
            cov = np.diag(gmm.covariances_[k][:2])
        elif gmm.covariance_type == 'spherical':
            cov = np.eye(2) * float(gmm.covariances_[k])
        else:
            raise ValueError(f"不支持的 covariance_type: {gmm.covariance_type}")

        # 计算椭圆参数
        eigenvalues, eigenvectors = np.linalg.eigh(cov)
        order = np.argsort(eigenvalues)[::-1]
        eigenvalues = eigenvalues[order]
        eigenvectors = eigenvectors[:, order]
        if np.any(eigenvalues <= 0):
            raise ValueError("协方差矩阵必须正定才能绘制概率椭圆")
        angle = np.degrees(np.arctan2(eigenvectors[1, 0], eigenvectors[0, 0]))

        for level in confidence_levels:
            radius = np.sqrt(chi2.ppf(level, df=2))
            ell = Ellipse(xy=gmm.means_[k, :2],
                         width=2 * radius * np.sqrt(eigenvalues[0]),
                         height=2 * radius * np.sqrt(eigenvalues[1]),
                         angle=angle,
                         edgecolor=colors[k],
                         facecolor='none',
                         linewidth=1.5,
                         alpha=0.7,
                         linestyle='--')
            plt.gca().add_patch(ell)

    plt.xlabel('Feature 1')
    plt.ylabel('Feature 2')
    plt.title('GMM Clustering with Confidence Ellipses')
    plt.legend()
    plt.show()
```

## 3. 假设检验 (Hypothesis Testing)

### 算法介绍

假设检验用于根据样本数据推断总体参数。

#### 3.1 参数检验

**t检验**：

| 类型 | 检验 | 统计量 |
|-----|------|--------|
| 单样本t检验 | 均值是否等于某值 | $t = \frac{\bar{x} - \mu_0}{s/\sqrt{n}}$ |
| 两独立样本t检验 | 两组均值是否相等 | $t = \frac{\bar{x}_1 - \bar{x}_2}{\sqrt{s_1^2/n_1 + s_2^2/n_2}}$ |
| 配对样本t检验 | 配对差异均值是否为0 | $t = \frac{\bar{d}}{s_d/\sqrt{n}}$ |

**方差分析（ANOVA）**：

**单因素方差分析**：检验多个组均值是否相等

$$
F = \frac{MS_{between}}{MS_{within}} = \frac{\sum_{j} n_j(\bar{x}_j - \bar{x})^2/(k-1)}{\sum_{j}\sum_{i}(x_{ij} - \bar{x}_j)^2/(n-k)}
$$

**卡方检验**：
- 适合性检验：观察分布是否符合理论分布
- 独立性检验：两个分类变量是否独立

$$
\chi^2 = \sum_{i,j} \frac{(O_{ij} - E_{ij})^2}{E_{ij}}
$$

#### 3.2 非参数检验

**Mann-Whitney U检验**：两独立样本比较（非参数）

**Wilcoxon符号秩检验**：配对样本比较（非参数）

**Kruskal-Wallis检验**：多组比较（非参数）

**Spearman秩相关**：单调相关性检验

$$
\rho = 1 - \frac{6\sum d_i^2}{n(n^2-1)}
$$

其中$d_i$是秩次差。

```python
from scipy import stats
import numpy as np
import matplotlib.pyplot as plt

def _validate_alpha(alpha):
    alpha = float(alpha)
    if not 0 < alpha < 1:
        raise ValueError("alpha 必须在 (0, 1) 内")
    return alpha

def _finite_1d(data, name, min_size=2):
    values = np.asarray(data, dtype=float)
    if values.ndim != 1 or values.size < min_size:
        raise ValueError(f"{name} 必须是一维且至少含 {min_size} 个观测")
    if not np.all(np.isfinite(values)):
        raise ValueError(f"{name} 含 NaN 或无穷大")
    return values

# 单样本 t 检验
def one_sample_t_test(data, mu0, alpha):
    """
    单样本t检验
    :param data: 样本数据
    :param mu0: 假设均值
    :param alpha: 显著性水平
    :return: 检验结果字典
    """
    alpha = _validate_alpha(alpha)
    data = _finite_1d(data, "data")
    sample_std = np.std(data, ddof=1)
    if sample_std == 0:
        raise ValueError("样本方差为零，无法用 t 分布估计均值不确定性")
    t_stat, p_value = stats.ttest_1samp(data, mu0)
    df = len(data) - 1
    ci = stats.t.interval(1 - alpha, df, loc=np.mean(data), scale=stats.sem(data))

    return {
        't_statistic': t_stat,
        'p_value': p_value,
        'reject_null': p_value < alpha,
        'confidence_interval': ci,
        'sample_mean': np.mean(data),
        'sample_std': sample_std,
        'alpha': alpha,
    }

# 两独立样本 t 检验；默认不替调用者猜测方差是否相等。
def two_sample_t_test(sample1, sample2, alpha, equal_var=False):
    """
    两独立样本t检验
    :param sample1: 样本1数据
    :param sample2: 样本2数据
    :param alpha: 显著性水平
    :param equal_var: 是否假设方差相等
    :return: 检验结果字典
    """
    alpha = _validate_alpha(alpha)
    sample1 = _finite_1d(sample1, "sample1")
    sample2 = _finite_1d(sample2, "sample2")
    t_stat, p_value = stats.ttest_ind(sample1, sample2, equal_var=equal_var)

    n1, n2 = len(sample1), len(sample2)
    var1, var2 = np.var(sample1, ddof=1), np.var(sample2, ddof=1)
    mean_diff = np.mean(sample1) - np.mean(sample2)

    if equal_var:
        df = n1 + n2 - 2
        pooled_var = ((n1 - 1) * var1 + (n2 - 1) * var2) / df
        standard_error = np.sqrt(pooled_var * (1 / n1 + 1 / n2))
    else:
        term1, term2 = var1 / n1, var2 / n2
        standard_error = np.sqrt(term1 + term2)
        denominator = term1**2 / (n1 - 1) + term2**2 / (n2 - 1)
        if denominator == 0:
            raise ValueError("两组标准误为零，Welch 自由度不可估计")
        df = (term1 + term2) ** 2 / denominator

    if standard_error == 0:
        raise ValueError("均值差标准误为零，无法构造 t 区间")
    me = stats.t.ppf(1 - alpha / 2, df) * standard_error
    ci = (mean_diff - me, mean_diff + me)

    return {
        't_statistic': t_stat,
        'p_value': p_value,
        'reject_null': p_value < alpha,
        'mean_difference': mean_diff,
        'confidence_interval': ci,
        'degrees_of_freedom': df,
        'equal_variance_assumed': bool(equal_var),
        'sample1_mean': np.mean(sample1),
        'sample2_mean': np.mean(sample2),
        'alpha': alpha,
    }

# 单因素方差分析
def one_way_anova(*samples, alpha):
    """
    单因素方差分析
    :param samples: 各组样本数据
    :param alpha: 显著性水平
    :return: 检验结果字典
    """
    alpha = _validate_alpha(alpha)
    if len(samples) < 2:
        raise ValueError("ANOVA 至少需要两组")
    samples = tuple(
        _finite_1d(sample, f"sample_{index}")
        for index, sample in enumerate(samples, start=1)
    )
    f_stat, p_value = stats.f_oneway(*samples)

    # 效应量（eta squared）
    all_data = np.concatenate(samples)
    grand_mean = np.mean(all_data)
    ss_between = sum(len(s) * (np.mean(s) - grand_mean)**2 for s in samples)
    ss_total = sum((x - grand_mean)**2 for x in all_data)
    eta_squared = ss_between / ss_total if ss_total > 0 else None

    return {
        'f_statistic': f_stat,
        'p_value': p_value,
        'reject_null': p_value < alpha,
        'eta_squared': eta_squared,
        'sample_means': [np.mean(s) for s in samples],
        'alpha': alpha,
    }

# 卡方检验（独立性）
def chi_square_test(contingency_table, alpha):
    """
    卡方检验（独立性检验）
    :param contingency_table: 列联表
    :param alpha: 显著性水平
    :return: 检验结果字典
    """
    alpha = _validate_alpha(alpha)
    contingency_table = np.asarray(contingency_table, dtype=float)
    if contingency_table.ndim != 2 or min(contingency_table.shape) < 2:
        raise ValueError("列联表必须是至少 2×2 的二维矩阵")
    if not np.all(np.isfinite(contingency_table)) or np.any(contingency_table < 0):
        raise ValueError("列联表必须由有限非负频数构成")
    if np.any(contingency_table.sum(axis=0) == 0) or np.any(contingency_table.sum(axis=1) == 0):
        raise ValueError("列联表不能含总频数为零的行或列")
    chi2, p_value, dof, expected = stats.chi2_contingency(contingency_table)

    # Phi系数（2×2表）或Cramer's V
    n = contingency_table.sum()
    min_dim = min(contingency_table.shape[0] - 1, contingency_table.shape[1] - 1)
    cramers_v = np.sqrt(chi2 / (n * min_dim))

    return {
        'chi2_statistic': chi2,
        'p_value': p_value,
        'reject_null': p_value < alpha,
        'degrees_of_freedom': dof,
        'expected_frequencies': expected,
        'cramers_v': cramers_v,
        'expected_count_warning': bool(np.any(expected < 5)),
        'alpha': alpha,
    }

# 正态性检验
def normality_test(data, alpha):
    """
    正态性检验（Shapiro-Wilk）
    :param data: 样本数据
    :param alpha: 显著性水平
    :return: 检验结果字典
    """
    alpha = _validate_alpha(alpha)
    data = _finite_1d(data, "data", min_size=3)
    statistic, p_value = stats.shapiro(data)

    return {
        'statistic': statistic,
        'p_value': p_value,
        'reject_null': p_value < alpha,
        'normality_not_rejected': p_value >= alpha,
        'interpretation': '不拒绝正态性不等于证明数据正态；须结合 Q-Q 图、设计与检验功效',
        'alpha': alpha,
    }

# 绘制QQ图
def plot_qq(data, title="Q-Q Plot"):
    """
    绘制Q-Q图
    :param data: 样本数据
    :param title: 图标题
    """
    plt.figure(figsize=(8, 6))
    stats.probplot(data, dist="norm", plot=plt)
    plt.title(title)
    plt.show()
```

## 4. 主成分分析 (Principal Component Analysis, PCA)

### 算法介绍

PCA是一种降维技术，通过线性变换将数据投影到低维空间，保留最大方差。

#### 4.1 基本原理

**目标**：找到正交的主成分方向，使数据投影后的方差最大。

**第一主成分**：最大化方差
$$
\max_{w_1} \frac{1}{n} \sum_{i=1}^{n} (w_1^T x_i)^2 \quad \text{s.t.} \quad \|w_1\| = 1
$$

**一般解**：协方差矩阵的特征向量。

**协方差矩阵**：
$$
\Sigma = \frac{1}{n} \sum_{i=1}^{n} (x_i - \bar{x})(x_i - \bar{x})^T
$$

**特征分解**：$\Sigma = W \Lambda W^T$

其中$W$是特征向量矩阵，$\Lambda$是特征值对角矩阵。

#### 4.2 PCA步骤

1. 数据标准化（中心化）
2. 计算协方差矩阵
3. 特征分解
4. 选择主成分（按特征值大小）
5. 数据转换

**解释方差比**：
$$
\text{Explained Variance Ratio}_k = \frac{\lambda_k}{\sum_{i=1}^{p} \lambda_i}
$$

**累计解释方差比**：
$$
\text{Cumulative Ratio}_k = \frac{\sum_{i=1}^{k} \lambda_i}{\sum_{i=1}^{p} \lambda_i}
$$

### 适用范围

| 题型类型 | 典型问题 | 特征 |
|---------|---------|------|
| 数据降维 | 高维数据压缩 | 减少特征数 |
| 特征提取 | 图像特征提取 | 保留主要信息 |
| 数据可视化 | 多维数据可视化 | 2D/3D投影 |
| 噪声去除 | 信号去噪 | 保留主要成分 |
| 多重共线性 | 回归变量选择 | 消除共线性 |

### 可视化图表类型

- **碎石图**：特征值/解释方差
- **累计方差图**：累计解释方差
- **主成分载荷图**：变量与主成分关系
- **得分图**：样本在主成分空间
- **双标图**：载荷和得分
- **热力图**：特征重要性

```python
from sklearn.decomposition import PCA
import numpy as np
import matplotlib.pyplot as plt

def perform_pca(data, n_components=None, standardize=True):
    """
    主成分分析
    :param data: 数据矩阵 (样本×特征)
    :param n_components: 主成分数量，None表示保留所有
    :param standardize: 是否标准化
    :return: PCA模型, 转换后数据, 已拟合缩放器（未标准化时为 None）
    """
    from sklearn.preprocessing import StandardScaler

    data = np.asarray(data, dtype=float)
    if data.ndim != 2 or data.shape[0] < 2 or data.shape[1] < 1 or np.any(~np.isfinite(data)):
        raise ValueError("data 必须至少含两个样本和一个有限特征")
    scaler = None
    if standardize:
        scaler = StandardScaler()
        data_scaled = scaler.fit_transform(data)
    else:
        data_scaled = data

    pca = PCA(n_components=n_components)
    transformed_data = pca.fit_transform(data_scaled)

    return pca, transformed_data, scaler

def plot_scree_plot(pca):
    """
    绘制碎石图
    :param pca: 拟合后的PCA模型
    """
    plt.figure(figsize=(10, 6))
    components = range(1, len(pca.explained_variance_ratio_) + 1)
    plt.bar(components, pca.explained_variance_ratio_, alpha=0.7, label='Individual')
    plt.plot(components, np.cumsum(pca.explained_variance_ratio_),
             'ro-', label='Cumulative')
    plt.xlabel('Principal Component')
    plt.ylabel('Explained Variance Ratio')
    plt.title('Scree Plot')
    plt.legend()
    plt.show()

def plot_pca_biplot(pca, transformed_data, feature_names, n_features=10):
    """
    绘制PCA双标图
    :param pca: PCA模型
    :param transformed_data: 转换后的数据
    :param feature_names: 特征名称列表
    :param n_features: 显示的特征数量
    """
    plt.figure(figsize=(12, 8))

    # 样本点
    plt.scatter(transformed_data[:, 0], transformed_data[:, 1],
               alpha=0.5, c='blue', label='Samples')

    # 特征向量（载荷）
    loadings = pca.components_.T * np.sqrt(pca.explained_variance_)

    for i in range(min(n_features, len(feature_names))):
        plt.arrow(0, 0, loadings[i, 0], loadings[i, 1],
                 color='r', alpha=0.8, head_width=0.05)
        plt.text(loadings[i, 0] * 1.1, loadings[i, 1] * 1.1,
                feature_names[i], color='r')

    plt.xlabel(f'PC1 ({pca.explained_variance_ratio_[0]:.2%})')
    plt.ylabel(f'PC2 ({pca.explained_variance_ratio_[1]:.2%})')
    plt.title('PCA Biplot')
    plt.axhline(y=0, color='k', linestyle='--', alpha=0.3)
    plt.axvline(x=0, color='k', linestyle='--', alpha=0.3)
    plt.show()

def components_for_variance_target(pca, threshold):
    """
    获取达到显式累计解释方差目标的最少主成分数量；“解释方差高”不等于预测或决策最优。
    :param pca: PCA模型
    :param threshold: 累计解释方差阈值
    :return: 达到目标的最少主成分数量
    """
    if not 0 < threshold <= 1:
        raise ValueError("threshold 必须位于 (0, 1]")
    cumulative = np.cumsum(pca.explained_variance_ratio_)
    tolerance = np.finfo(float).eps * max(1, len(cumulative))
    if threshold > cumulative[-1] + tolerance:
        raise ValueError("当前 PCA 分量未覆盖所需累计解释方差目标")
    index = int(np.searchsorted(cumulative, threshold - tolerance, side='left'))
    return min(index + 1, len(cumulative))
```

## 5. 因子分析 (Factor Analysis, FA)

### 算法介绍

因子分析是用少数潜在变量（因子）解释可观测变量之间的相关性。

#### 5.1 基本模型

**数学模型**：
$$
X = \mu + \Lambda F + \epsilon
$$

其中：
- $X$是可观测变量向量
- $\mu$是均值向量
- $\Lambda$是因子载荷矩阵
- $F$是公共因子向量
- $\epsilon$是特殊因子（误差）

#### 5.2 因子提取方法

**主成分法**：基于主成分分析

**主因子法**：基于公共因子方差

**最大似然法**：假设数据多元正态分布

#### 5.3 因子旋转

**目的**：使因子结构更易解释。

**正交旋转**：
- 方差最大化旋转（Varimax）
- 四次方最大旋转（Quartimax）
- 平方最大旋转（Equamax）

**斜交旋转**：
- Promax旋转
- Oblimin旋转

### 适用范围

| 题型类型 | 典型问题 | 特征 |
|---------|---------|------|
| 心理测量 | 问卷结构分析 | 潜在变量 |
| 市场研究 | 消费者偏好 | 因子识别 |
| 社会科学 | 社会指标分析 | 变量归类 |
| 金融分析 | 风险因子提取 | 公共风险 |
| 生物信息 | 基因表达分析 | 潜在模式 |

### 可视化图表类型

- **碎石图**：因子特征值
- **因子载荷图**：变量在因子上的载荷
- **因子得分图**：样本因子得分
- **路径图**：因子结构

### 关键文献

| 论文名称 | 作者 | 年份 | 来源 |
|---------|------|------|------|
| The Common Factor Model | Thurstone | 1947 | University of Chicago Press |
| Factor Analysis as a Statistical Method | Lawley & Maxwell | 1971 | Butterworths |

```python
from factor_analyzer import FactorAnalyzer
import numpy as np

def perform_factor_analysis(data, n_factors=3, rotation='varimax'):
    """
    因子分析
    :param data: 数据矩阵
    :param n_factors: 因子数量
    :param rotation: 旋转方法
    :return: 因子载荷, 因子得分, 方差解释
    """
    data = np.asarray(data, dtype=float)
    if (data.ndim != 2 or data.shape[0] < 2 or data.shape[1] < 2
            or np.any(~np.isfinite(data))):
        raise ValueError("data 必须是至少两个样本、两个变量的有限二维数组")
    if (isinstance(n_factors, (bool, np.bool_))
            or not isinstance(n_factors, (int, np.integer))
            or not 1 <= n_factors <= data.shape[1]):
        raise ValueError("n_factors 必须是 1 到变量数之间的整数")
    fa = FactorAnalyzer(n_factors=int(n_factors), rotation=rotation)
    fa.fit(data)

    # 因子载荷
    loadings = fa.loadings_

    # 因子方差
    communalities = fa.get_communalities()

    # 方差解释
    variance = fa.get_factor_variance()

    return {
        'loadings': loadings,
        'communalities': communalities,
        'variance': variance,  # (SS Loadings, Proportion Var, Cumulative Var)
        'factor_scores': fa.transform(data)
    }

def factor_count_diagnostics(data, max_candidates=10):
    """
    生成因子数量诊断；Kaiser 准则只是启发式候选，不是唯一最优解
    :param data: 数据矩阵
    :param max_candidates: 本次允许报告的最大候选因子数
    :return: 相关矩阵特征值、Kaiser 启发式计数和候选范围
    """
    data = np.asarray(data, dtype=float)
    if (data.ndim != 2 or data.shape[0] < 2 or data.shape[1] < 2
            or np.any(~np.isfinite(data))):
        raise ValueError("data 必须是至少两个样本、两个变量的有限二维数组")
    if np.any(np.ptp(data, axis=0) == 0):
        raise ValueError("存在常量变量，相关矩阵与 Kaiser 诊断无定义")
    if (isinstance(max_candidates, (bool, np.bool_))
            or not isinstance(max_candidates, (int, np.integer))
            or not 1 <= max_candidates <= data.shape[1]):
        raise ValueError("max_candidates 必须是 1 到变量数之间的整数")
    correlation = np.corrcoef(data, rowvar=False)
    eigenvalues = np.linalg.eigvalsh(correlation)[::-1]
    kaiser_count_all = int(np.count_nonzero(eigenvalues > 1.0))
    return {
        "eigenvalues": eigenvalues,
        "candidate_range": list(range(1, int(max_candidates) + 1)),
        "kaiser_count_all": kaiser_count_all,
        "kaiser_count_within_cap": min(kaiser_count_all, int(max_candidates)),
        "criterion_status": "heuristic_only",
        "selection_note": (
            "结合平行分析、拟合残差、稳定性和领域可解释性选择；"
            "Kaiser 计数不等于已确定的最优因子数"
        ),
    }

                yticklabels=feature_names,
                center=0, cbar_kws={'label': 'Loading'})
    plt.title('Factor Loadings')
    plt.xlabel('Factors')
    plt.ylabel('Variables')
    plt.tight_layout()
    plt.show()
```

## 6. 典型相关分析 (Canonical Correlation Analysis, CCA)

### 算法介绍

典型相关分析用于研究两组变量之间的整体相关性，通过线性组合找到两组变量之间的最大相关关系。

#### 6.1 基本原理

**问题设定**：
- 第一组变量：$X = (x_1, x_2, \ldots, x_p)^T$
- 第二组变量：$Y = (y_1, y_2, \ldots, y_q)^T$

**目标**：寻找线性组合
$$
U = a_1 x_1 + a_2 x_2 + \cdots + a_p x_p = a^T X
$$
$$
V = b_1 y_1 + b_2 y_2 + \cdots + b_q y_q = b^T Y
$$

使得$U$和$V$的相关系数$\rho(U, V)$最大化。

#### 6.2 数学推导

**相关系数**：
$$
\rho = \frac{\text{Cov}(U, V)}{\sqrt{\text{Var}(U)\text{Var}(V)}} = \frac{a^T \Sigma_{XY} b}{\sqrt{a^T \Sigma_{XX} a \cdot b^T \Sigma_{YY} b}}
$$

其中$\Sigma_{XX}$、$\Sigma_{YY}$、$\Sigma_{XY}$分别为协方差矩阵。

**优化问题**：
$$
\max_{a, b} a^T \Sigma_{XY} b
$$
$$
\text{s.t. } a^T \Sigma_{XX} a = 1, b^T \Sigma_{YY} b = 1
$$

**拉格朗日乘数法**得到特征值问题：
$$
\Sigma_{XY} \Sigma_{YY}^{-1} \Sigma_{YX} a = \lambda^2 \Sigma_{XX} a
$$
$$
\Sigma_{YX} \Sigma_{XX}^{-1} \Sigma_{XY} b = \lambda^2 \Sigma_{YY} b
$$

$\lambda^2$为典型相关系数的平方。

#### 6.3 典型变量

第$k$对典型变量：
$$
U_k = a_k^T X, \quad V_k = b_k^T Y
$$

典型相关系数按递减顺序排列：$\lambda_1 \geq \lambda_2 \geq \cdots \geq \lambda_m$

其中$m = \min(p, q)$

#### 6.4 显著性检验

**Wilks' Lambda统计量**（从第 $r$ 对开始检验，$r$ 为 1 基）：
$$
\Lambda_r = \prod_{i=r}^{m} (1 - \lambda_i^2)
$$

**Bartlett卡方近似**：
$$
\chi^2 = -[n - 1 - \frac{p + q + 1}{2}] \ln \Lambda_r
$$

自由度：$df = (p - r + 1)(q - r + 1)$。该近似依赖独立观测、合适的分布条件和足够样本量；高维或病态协方差时应使用经验证的正则化、置换或重采样方案。

```python
import numpy as np
import pandas as pd
from scipy import stats
import matplotlib.pyplot as plt

def canonical_correlation_analysis(X, Y, ridge=0.0):
    """
    典型相关分析
    :param X: 第一组变量 (n_samples, p)
    :param Y: 第二组变量 (n_samples, q)
    :return: 典型相关系数, 典型权重, 典型变量得分
    """
    X = np.asarray(X, dtype=float)
    Y = np.asarray(Y, dtype=float)
    if X.ndim != 2 or Y.ndim != 2 or X.shape[0] != Y.shape[0]:
        raise ValueError("X、Y 必须是样本数相同的二维矩阵")
    if not np.all(np.isfinite(X)) or not np.all(np.isfinite(Y)):
        raise ValueError("X、Y 必须为有限数")
    if ridge < 0:
        raise ValueError("ridge 不能为负")

    n, p = X.shape
    q = Y.shape[1]
    if n < 3 or p < 1 or q < 1:
        raise ValueError("CCA 至少需要 3 个样本且两组变量均非空")

    # 中心化
    X = X - X.mean(axis=0, keepdims=True)
    Y = Y - Y.mean(axis=0, keepdims=True)

    # 计算协方差块；ridge 必须由验证或预先声明的正则化方案确定。
    Cxx = X.T @ X / (n - 1) + ridge * np.eye(p)
    Cyy = Y.T @ Y / (n - 1) + ridge * np.eye(q)
    Cxy = X.T @ Y / (n - 1)

    from scipy.linalg import eigh

    def inverse_square_root(matrix, name):
        eigenvalues, eigenvectors = eigh(matrix)
        tolerance = np.finfo(float).eps * max(matrix.shape) * max(eigenvalues[-1], 1.0)
        if np.any(eigenvalues <= tolerance):
            raise ValueError(f"{name} 奇异或近奇异；增加样本、删减共线变量或经验证后设置 ridge")
        return (eigenvectors / np.sqrt(eigenvalues)) @ eigenvectors.T

    whiten_x = inverse_square_root(Cxx, "Cxx")
    whiten_y = inverse_square_root(Cyy, "Cyy")
    left, singular_values, right_t = np.linalg.svd(
        whiten_x @ Cxy @ whiten_y,
        full_matrices=False,
    )
    component_count = min(p, q)
    coefficients_x = whiten_x @ left[:, :component_count]
    coefficients_y = whiten_y @ right_t.T[:, :component_count]

    # 计算典型变量得分
    canonical_scores_X = X @ coefficients_x
    canonical_scores_Y = Y @ coefficients_y
    canonical_correlations = np.array([
        np.corrcoef(canonical_scores_X[:, k], canonical_scores_Y[:, k])[0, 1]
        for k in range(component_count)
    ])
    canonical_correlations = np.clip(np.abs(canonical_correlations), 0.0, 1.0)

    return {
        'canonical_correlations': canonical_correlations,
        'coefficients_x': coefficients_x,
        'coefficients_y': coefficients_y,
        'scores_x': canonical_scores_X,
        'scores_y': canonical_scores_Y,
        'whitened_singular_values': singular_values[:component_count],
        'ridge': ridge,
    }

def cca_significance_test(canonical_corrs, n, p, q, alpha):
    """
    CCA显著性检验（Wilks' Lambda）
    :param canonical_corrs: 典型相关系数数组
    :param n: 样本量
    :param p: 第一组变量数
    :param q: 第二组变量数
    :param alpha: 显著性水平
    :return: 各对典型变量的显著性
    """
    alpha = float(alpha)
    if not 0 < alpha < 1:
        raise ValueError("alpha 必须在 (0, 1) 内")
    canonical_corrs = np.asarray(canonical_corrs, dtype=float)
    m = min(p, q)
    if canonical_corrs.ndim != 1 or len(canonical_corrs) != m:
        raise ValueError("canonical_corrs 长度必须等于 min(p, q)")
    if np.any(~np.isfinite(canonical_corrs)) or np.any((canonical_corrs < 0) | (canonical_corrs > 1)):
        raise ValueError("典型相关系数必须是 [0, 1] 内的有限数")
    bartlett_factor = n - 1 - (p + q + 1) / 2
    if bartlett_factor <= 0:
        raise ValueError("样本量不足以使用 Bartlett 卡方近似")
    results = []

    for k in range(m):
        # Wilks' Lambda
        wilks_lambda = np.prod(1 - canonical_corrs[k:]**2)
        wilks_lambda = np.clip(wilks_lambda, np.finfo(float).tiny, 1.0)

        # Bartlett 卡方近似：检验从第 k+1 个根开始的剩余相关。
        df = (p - k) * (q - k)
        chi2 = -bartlett_factor * np.log(wilks_lambda)

        p_value = 1 - stats.chi2.cdf(chi2, df)
        significant = p_value < alpha

        results.append({
            'pair': k + 1,
            'canonical_corr': canonical_corrs[k],
            'wilks_lambda': wilks_lambda,
            'chi2': chi2,
            'df': df,
            'p_value': p_value,
            'significant': significant,
            'alpha': alpha,
            'approximation': 'Bartlett chi-square; requires independent observations and suitable distributional conditions',
        })

    return pd.DataFrame(results)
```

## 7. 非负矩阵分解 (Non-negative Matrix Factorization, NMF)

### 算法介绍

非负矩阵分解是一种降维和特征提取方法，将非负矩阵分解为两个非负矩阵的乘积。

#### 7.1 基本原理

**分解形式**：
$$
V \approx W H
$$

其中：
- $V \in \mathbb{R}^{n \times m}$：非负数据矩阵
- $W \in \mathbb{R}^{n \times r}$：样本在各成分上的非负系数矩阵
- $H \in \mathbb{R}^{r \times m}$：各行位于特征空间中的成分基矩阵
- $r$：分解秩（$1\le r\le \min(n, m)$；是否取边界值由目的与验证决定）

**约束条件**：
$$
W_{ij} \geq 0, \quad H_{ij} \geq 0
$$

#### 7.2 损失函数

**Frobenius范数损失**：
$$
\|V - WH\|_F^2 = \sum_{i,j} (V_{ij} - (WH)_{ij})^2
$$

**KL散度损失**：
$$
D_{KL}(V \| WH) = \sum_{i,j} \left( V_{ij} \log\frac{V_{ij}}{(WH)_{ij}} - V_{ij} + (WH)_{ij} \right)
$$

#### 7.3 乘法更新规则

**基于Frobenius范数的更新**：

对 $V\approx WH$，$W$ 表示样本在各成分上的非负系数，$H$ 的各行表示特征空间中的成分基。可从非负初值迭代更新：

$$
H_{kj} \leftarrow H_{kj} \frac{(W^T V)_{kj}}{(W^T W H)_{kj} + \epsilon}
$$

$$
W_{ik} \leftarrow W_{ik} \frac{(V H^T)_{ik}}{(W H H^T)_{ik} + \epsilon}
$$

分母为零是零锁定或退化结构信号。实现应使用算法库明确的数值策略并检查收敛状态，不应随意添加常数后把退化静默掩盖。

**可选尺度归一化**：若对 $W$ 的列归一化，必须对 $H$ 的对应行做逆向缩放，才能保持 $WH$ 不变：
$$
s_k=\sum_i W_{ik},\quad W_{:k}\leftarrow W_{:k}/s_k,\quad H_{k:}\leftarrow s_kH_{k:}
$$

#### 7.4 NMF与PCA对比

| 特性 | NMF | PCA |
|-----|-----|-----|
| 约束 | 非负 | 正交 |
| 可解释性 | 部分整体结构 | 全局结构 |
| 稀疏性 | 不自动保证；需由数据、初始化与正则化决定 | 载荷通常稠密，也可另作稀疏化 |
| 适用数据 | 非负数据 | 任意数据 |

```python
import numpy as np
import matplotlib.pyplot as plt
from sklearn.decomposition import NMF

def nmf_decomposition(V, n_components, max_iter=200, tol=1e-4, random_state=42):
    """
    非负矩阵分解
    :param V: 非负数据矩阵 (n_samples, n_features)
    :param n_components: 分解秩
    :param max_iter: 最大迭代次数
    :param tol: 收敛容忍度
    :param random_state: 随机种子
    :return: W, H, 最终 Frobenius 重构误差
    """
    V = np.asarray(V, dtype=float)
    if V.ndim != 2 or V.shape[0] < 1 or V.shape[1] < 1 or np.any(~np.isfinite(V)):
        raise ValueError("V 必须是非空有限二维数组")
    if np.any(V < 0):
        raise ValueError("NMF 要求 V 非负")
    if not isinstance(n_components, int) or not 1 <= n_components <= min(V.shape):
        raise ValueError("n_components 必须是 1 到 min(V.shape) 的整数")
    if isinstance(n_components, bool):
        raise ValueError("n_components 必须是整数而非布尔值")
    if not isinstance(max_iter, int) or isinstance(max_iter, bool) or max_iter < 1:
        raise ValueError("max_iter 必须是正整数")
    if not np.isfinite(tol) or tol <= 0:
        raise ValueError("tol 必须是有限正数")
    model = NMF(n_components=n_components, init='random', random_state=random_state,
                max_iter=max_iter, tol=tol, verbose=False)

    W = model.fit_transform(V)
    H = model.components_

    return W, H, model.reconstruction_err_

def nmf_reconstruction_curve(V, component_candidates,
                             max_iter, tol, random_state, plot=True):
    """
    计算候选成分数的重构误差曲线；误差通常随成分数下降，不能单独定义“最优”。
    :param V: 数据矩阵
    :param component_candidates: 预先声明的正整数候选
    :param plot: 是否绘制曲线
    :return: 各组件数的重构误差
    """
    V = np.asarray(V, dtype=float)
    if V.ndim != 2 or np.any(~np.isfinite(V)) or np.any(V < 0):
        raise ValueError("V 必须是非负有限二维数组")
    components_range = [int(value) for value in component_candidates]
    if (not components_range or len(set(components_range)) != len(components_range)
            or any(value < 1 or value > min(V.shape) for value in components_range)):
        raise ValueError("component_candidates 必须是不重复且不超过矩阵最小维的正整数")
    errors = []

    for n_comp in components_range:
        model = NMF(
            n_components=n_comp,
            init='random',
            random_state=random_state,
            max_iter=max_iter,
            tol=tol,
        )
        model.fit_transform(V)
        error = model.reconstruction_err_
        errors.append(error)

    if plot:
        plt.figure(figsize=(10, 6))
        plt.plot(components_range, errors, 'bo-')
        plt.xlabel('Number of Components')
        plt.ylabel('Reconstruction Error')
        plt.title('NMF Reconstruction Error by Candidate Rank')
        plt.show()

    return {"components": components_range, "reconstruction_error": errors}

def nmf_topic_modeling(document_term_matrix, n_topics, feature_names, n_top_words=10):
    """
    基于NMF的主题建模
    :param document_term_matrix: 文档-词频矩阵
    :param n_topics: 主题数量
    :param feature_names: 词列表
    :param n_top_words: 每个主题显示的词数
    :return: 主题词分布
    """
    model = NMF(n_components=n_topics, init='random', random_state=42, max_iter=300)
    W = model.fit_transform(document_term_matrix)
    H = model.components_

    # 提取每个主题的高频词
    topics = []
    for topic_idx, topic in enumerate(H):
        top_word_indices = topic.argsort()[:-n_top_words - 1:-1]
        top_words = [feature_names[i] for i in top_word_indices]
        topics.append(top_words)

        print(f"Topic {topic_idx + 1}:")
        print(", ".join(top_words))
        print()

    return W, H, topics

def compare_nmf_pca(V, n_components):
    """
    比较NMF和PCA
    :param V: 数据矩阵（非负）
    :param n_components: 组件数
    :return: NMF和PCA的重构误差
    """
    from sklearn.decomposition import PCA

    # NMF
    nmf_model = NMF(n_components=n_components, init='random', random_state=42)
    W_nmf = nmf_model.fit_transform(V)
    V_recon_nmf = W_nmf @ nmf_model.components_
    nmf_error = np.linalg.norm(V - V_recon_nmf, 'fro')

    # PCA (中心化后)
    V_centered = V - V.mean(axis=0)
    pca_model = PCA(n_components=n_components)
    W_pca = pca_model.fit_transform(V)
    V_recon_pca = W_pca @ pca_model.components_ + V.mean(axis=0)
    pca_error = np.linalg.norm(V - V_recon_pca, 'fro')

    print(f"NMF Reconstruction Error: {nmf_error:.4f}")
    print(f"PCA Reconstruction Error: {pca_error:.4f}")

    return nmf_error, pca_error
```

## 统计分析算法选择指南

不能按“样本数小于 30”之类阈值自动选择参数或非参数方法。有效样本量取决于研究设计、组内相关、时间/空间依赖、缺失和重复测量；大样本也不会消除偏倚、混杂、错误模型或数据泄漏。

| 决策维度 | 必查问题 | 方法选择含义 |
|---|---|---|
| 分析目标 | 要估计效应、检验假设、预测、聚类还是描述结构 | 先定义 estimand、损失或距离；检验、预测与探索性降维不能互相替代 |
| 研究设计 | 独立、配对、重复测量、分层、群组或时空结构是什么 | 使用与设计相符的配对/分层检验、混合模型、GEE、时间序列或空间模型 |
| 分布与尺度 | 变量类型、尾部、异方差、零膨胀和异常机制如何 | 选择合适似然、稳健方法、变换或重抽样；“非正态”不自动推出某一检验 |
| 缺失机制 | MCAR、MAR、MNAR 哪一种可辩护；缺失发生在何阶段 | 完整案例、插补、加权或敏感性分析必须在训练/验证隔离内实施，单次均值/KNN 填充不是通用答案 |
| 维数与相关 | 样本—特征关系、共线性和潜变量解释是否成立 | PCA、因子、正则化或稀疏方法回答不同问题；方差最大不等于因果或价值重要 |
| 多重选择 | 做了多少检验、模型和亚组探索 | 预注册主比较，控制 FWER/FDR 或用独立验证；不得只报告显著结果 |
| 精度与功效 | 最小有意义效应、方差、置信区间宽度和检验功效如何 | 用功效/精度分析与重抽样评估信息量，不用固定样本量档位替代 |
| 验证与稳健性 | 结论是否依赖单一分布、异常点或划分 | 报告效应量与区间，做残差诊断、稳健/敏感性分析及适用的样本外验证 |

聚类和降维属于探索性分析时，要报告距离、缩放、簇数/维数选择、初始化稳定性和外部解释，不能因样本量大就自动采用。统计显著不等于实际重要，非显著也不证明“无效”。
