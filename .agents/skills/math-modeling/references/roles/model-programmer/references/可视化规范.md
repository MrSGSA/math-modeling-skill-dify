## 三类图

1. 原始数据图：分布、时间趋势、空间结构、相关性和异常点。
2. 模型运行过程图：收敛、训练、残差、灵敏度、消融和约束状态。
3. 模型最终结果图：方案、预测、排名、误差和不确定性。

按主张—证据映射生成最少充分的图。每幅图必须回答明确问题或承担诊断作用；不得为数量重复展示同一信息，也不预设固定最多图数。

## 通用要求

- 网格线和参考线按读图任务决定：需要精确比较数值时可使用低对比度主网格；类别图、结构图或网格造成拥挤时省略。阈值、零线等有业务含义的参考线须说明。
- 标题、坐标轴、图例、单位和数据范围必须正确。
- 颜色语义在全项目一致，并兼顾色觉可达性。
- 保留可复现的绘图代码和至少一种满足最终媒介的输出。线稿优先矢量格式，照片、热力图或不支持矢量的媒介使用足够分辨率的栅格图；只有官方规则、出版要求或后续编辑流程需要时才同时输出 SVG 与指定 DPI 的 PNG。不要只调用 `show()`。
- 统计量、置信区间和 p 值必须由代码从当前数据计算，禁止硬编码。
- 置信区间不能用标准差冒充；函数应接收已计算的上下界，或根据明确的统计模型计算。
- HTML 面板位于 `figures/` 时，图路径写 `figure.svg`，不能写 `figures/figure.svg`。

## 过程证据图与“留痕”要求

对时间演化、迭代优化、空间运动、临界事件或约束状态等过程型结论，图片应保留可核验的计算或变化痕迹，不能只给无标注的静态终态图。静态比较、结构关系或分布结论则选择与任务匹配的证据表达。可借鉴优秀案例的表达结构，但每组核心结论只配置适用的一种或多种证据层：

1. **过程轨迹层**：同时呈现起点、终点、中间轨迹或多个代表时刻；用箭头表示运动方向，用颜色渐变、透明度或分段线型表示时间/状态变化。
2. **关键事件层**：直接标出峰值、谷值、首次越界、进入/离开区间、碰撞/相切、切换点、最优点等事件；标注必须包含实际时刻、位置、速度、裕度或目标值及单位。
3. **约束证据层**：画出有明确数值意义的阈值线、允许区间、边界面、误差带或可行域；用阴影或颜色区分可行/不可行、遮蔽/未遮蔽等状态。
4. **几何解释层**：对复杂几何关系画出对象真实外形或合理简化外形，并标注关键点、向量、角度、半径、法向/切向和区域编号；解释图必须与最终公式和代码符号一致。
5. **数值回写层**：图中的坐标、文本框、峰值标签、持续时长和百分比由当前运行数据自动计算；不得凭论文结果手工硬编码，也不得在换数据后保留旧标注。

### 推荐图组

当一个重要结论同时包含机制、过程、临界值和可靠性且单图无法清楚表达时，可用“小型证据图组”：

- **为什么这样算**：几何关系图、算法结构图或状态转移图；
- **过程发生了什么**：运动快照、时空曲线、热力图或轨迹渐变图；
- **临界值在哪里**：带阈值线、关键点和数值框的局部放大图；
- **结论是否可靠**：残差、灵敏度、网格收敛或扰动前后对比图。

数值结果图负责证明“算出了什么”，解释图负责说明“为什么这样算”。两类图不能互相替代。

### 标注与版式

- 每幅过程图通常标注 3～7 个最关键事件，避免标签密集遮挡曲线；必要时使用局部放大子图或引线。
- 数值精度与计算分辨率一致，例如时间步长为 0.005 s 时，不标注无法支撑的更多小数。
- 颜色在全文保持语义一致，例如蓝色表示正常过程、绿色表示可行/有效、橙色表示临界、红色表示越界/风险；只靠颜色不足以区分时，再配合线型和标记形状。
- 关键点优先使用圆点、星号、方框或带箭头文本框；阈值参考线必须在图例或图注说明数值意义。
- 三维图若遮挡关键标注，应补充二维投影、时间剖面或局部放大，不以旋转角度掩盖信息。
- 不复制优秀案例的具体图片、数据、配色或原句；只迁移“轨迹—事件—数值—解释—验证”的证据结构，并针对当前题重新生成。

## 两个子图示例（Python）

```python
from pathlib import Path

import matplotlib.pyplot as plt
import numpy as np

def save_prediction_figure(x, raw_values, predicted, lower_ci, upper_ci,
                           output_dir, interval_label):
    arrays = [np.asarray(value, dtype=float) for value in
              (x, raw_values, predicted, lower_ci, upper_ci)]
    if (any(value.ndim != 1 or np.any(~np.isfinite(value)) for value in arrays)
            or len({len(value) for value in arrays}) != 1
            or np.any(arrays[3] > arrays[4])):
        raise ValueError("曲线及区间必须是等长有限一维数组，且下界不大于上界")
    output_dir = Path(output_dir)
    output_dir.mkdir(parents=True, exist_ok=True)
    x, raw_values, predicted, lower_ci, upper_ci = arrays
    fig, axes = plt.subplots(1, 2, figsize=(10, 4), constrained_layout=True)
    axes[0].plot(x, raw_values, color="#0F4D92")
    axes[0].set(title="原始数据", xlabel="时间", ylabel="观测值")
    axes[1].plot(x, predicted, color="#D1495B", label="预测")
    axes[1].fill_between(
        x, lower_ci, upper_ci, color="#D1495B", alpha=0.16,
        label=interval_label,
    )
    axes[1].set(title="预测结果", xlabel="时间", ylabel="预测值")
    axes[1].legend(frameon=False)
    fig.savefig(output_dir / "result_prediction.svg", bbox_inches="tight")
    fig.savefig(output_dir / "result_prediction.png", dpi=300, bbox_inches="tight")
    plt.close(fig)
```

## 统计标注示例（Python）

```python
import numpy as np
from scipy import stats

def annotate_welch_test(ax, group_a, group_b):
    group_a = np.asarray(group_a, dtype=float)
    group_b = np.asarray(group_b, dtype=float)
    if (group_a.ndim != 1 or group_b.ndim != 1
            or len(group_a) < 2 or len(group_b) < 2
            or np.any(~np.isfinite(group_a)) or np.any(~np.isfinite(group_b))):
        raise ValueError("Welch 检验要求两组至少各含两个有限观测")
    statistic, p_value = stats.ttest_ind(group_a, group_b, equal_var=False)
    label = f"Welch t-test: t={statistic:.3g}, p={p_value:.3g}"
    ax.text(0.98, 0.98, label, transform=ax.transAxes,
            ha="right", va="top")
    return statistic, p_value
```

```matlab
layout = tiledlayout(1, 2, "TileSpacing", "compact", "Padding", "compact");

nexttile;

```

MATLAB 中是否调用 `grid on` 由读图任务决定；使用时降低视觉权重并避免次网格造成拥挤。业务阈值或零线优先用 `xline`、`yline` 等单独表达，并在图例或图注解释。
