# 编程手工作流程

## 一、读取输入

从 `PROJECT_ROOT` 读取题目附件、`题目分析报告.md` 和 `术语表格.md`。输入文件只读；输出写入新文件。

## 二、选择语言并动态检查依赖

根据用户要求、竞赛许可、现有代码、模型结构和可用依赖选择运行环境，并在开始编码前记录一句选择依据。不得仅因代理熟悉某种语言就默认选择它。

| 情形 | 优先考虑 | 主要理由 |
|---|---|---|
| 矩阵密集型数值计算、非线性方程、连续/整数优化、ODE/PDE、符号推导、控制与仿真 | MATLAB | 数值函数和工具箱集成紧密，交互调参与竞赛复现方便 |
| 数据清洗、机器学习、地理空间/网络数据、批处理与开放生态协作 | Python | 数据与算法生态丰富，自动化和跨平台复现成本较低 |
| 已有代码、模板或队员工作流明确采用一种语言 | 沿用现有语言 | 降低接口转换与复现风险 |
| 统计分析已有 R 工作流，或高性能数值项目已有 Julia/C++ 工程 | 沿用经验证环境 | 避免无收益重写，并保留原有测试与性能证据 |

用户明确偏好在不违反竞赛规则和可复现要求时优先于上表。运行时或必要依赖不可用时，不得假装运行；应说明依赖情况后选择可真实复现的语言。只有需要独立数值交叉验证或用户明确要求时才多语言实现；语言选择不能替代算法正确性、误差验证和边界检查。

Python：

```powershell
python ../scripts/check_env.py --features data visualization optimization
```

可选功能包括 `data`、`visualization`、`excel`、`optimization`、`integer-optimization`、`statistics`、`machine-learning`、`time-series`、`graph` 和 `image`。

MATLAB：

```matlab
addpath("../scripts");
report = check_matlab_env(["data", "visualization", "optimization"]);
assert(report.ok, "缺少所选模型需要的 MATLAB 工具箱");
```

缺少依赖时报告精确名称，不自动改用另一个模型或语言。

## 三、实现与运行

1. 把数据读取、预处理、模型、验证、可视化和输出拆成清晰函数。
2. 随机算法显式设置种子。
3. 所有关键参数集中定义并写入复现清单。
4. 实际运行代码；禁止手写或伪造结果。
5. 检查约束可行性、数值范围、边界条件和验证指标。
6. 若模型本身矛盾，把实际报错和最小复现反馈给建模手。

## 四、文件结构

```text
PROJECT_ROOT/
├── data/                         # 输入，只读
├── 题目分析报告.md               # 建模手产物，只读
├── 术语表格.md                   # 建模手产物，只读
├── 问题1_求解.py 或 问题1_求解.m
├── results/
│   ├── 问题1_结果.csv
│   ├── 题目指定结果.xlsx         # 仅题目要求或需保留模板时
│   └── 复现清单.json
└── figures/
    ├── raw_*.svg / raw_*.png     # 原始数据图
    ├── process_*.svg / *.png     # 模型运行过程图
    ├── result_*.svg / *.png      # 最终结果图
    └── 图表面板.html
```

图由主张—证据映射驱动；只有设计方案或媒介需求不同且确有比较价值时才保留候选版本，每张图都须数据正确、标题和坐标含义清楚。

## 五、Excel

- 普通结果表优先 CSV。
- 题目要求 `.xlsx`、多工作表、公式或既有模板时使用 Excel。
- 读取 XLSX 时显式声明是否有表头；第一行就是数据时使用 `pandas.read_excel(..., header=None)` 或 `read_excel_rows(..., header=False)`，并核对首行、末行与预期行数。
- 模板结构和公式不随意修改，另存到 `PROJECT_ROOT/results/`。
- 公式工作簿使用 `../../../../tools/xlsx/scripts/recalc.py` 重算；失败或超时时原文件不应被覆盖。

## 六、复现清单

示例：

```powershell
python ../scripts/repro_manifest.py `
  --project-root "<PROJECT_ROOT>" `
  --input "<PROJECT_ROOT>/data/input.csv" `
  --seed 42 `
  --parameters '{"alpha":0.1,"max_iter":1000}' `
  --command "python 问题1_求解.py --seed 42" `
  --package numpy --package scipy
```

唯一复现命令必须从 `PROJECT_ROOT` 可直接执行，并生成与论文引用一致的表格和图。
清单中的输入路径记录为相对 `PROJECT_ROOT` 的可移植路径；输入文件必须位于项目内，外部附件先只读复制到项目数据目录并核对 SHA-256。非 Python 运行时必须显式记录实际版本。
