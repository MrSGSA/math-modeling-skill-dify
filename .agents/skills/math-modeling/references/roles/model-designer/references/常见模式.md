# 建模常见模式

数学建模中反复出现的模型组合模式，按问题类型分类整理。

## 一、优化类问题常见模式

### 模式 1：线性/整数规划 → 稳健性与参数分析

| 要素 | 说明 |
|------|------|
| **适用场景** | 资源分配、生产调度、投资组合 |
| **主模型** | 线性规划 / 整数规划 |
| **辅助分析** | 连续线性规划可分析对偶值与允许范围；整数规划采用参数重求解、情景分析、最优性间隙和替代最优解，不能直接把 LP 影子价格解释为整数决策边际 |
| **输出** | 可行/最优解、求解界或间隙、关键参数扰动下的方案与目标变化 |
| **证据链** | 可行性与最优性证据 + 与模型类型相符的参数稳定性证据 |
| **备选方案** | 目标规划（多目标时）、动态规划（分阶段时） |

### 模式 2：启发式算法 → 对比验证

| 要素 | 说明 |
|------|------|
| **适用场景** | 大规模 NP-hard 问题（TSP、VRP、调度） |
| **主模型** | 遗传算法 / 模拟退火 / 粒子群 |
| **辅助分析** | 小规模精确解/下界、公开基准或同预算基线对比，并运行多随机种子 |
| **输出** | 当前预算下的候选解、最优性间隙或基准差距、稳定性与收敛证据 |
| **证据链** | 启发式产生可行解 + 明确基准和预算下量化质量；普通对比不能证明全局有效性 |
| **备选方案** | 只有机制或证据价值不同且能公平比较时，才增加其他启发式 |

### 模式 3：多目标优化 → Pareto 分析

| 要素 | 说明 |
|------|------|
| **适用场景** | 成本 vs 质量、效率 vs 公平等多目标权衡 |
| **主模型** | NSGA-II / MOEA / 加权和法 |
| **辅助分析** | Pareto 前沿、目标缩放与偏好/权重敏感性；仅在决策偏好和距离度量有依据时使用 TOPSIS 等折衷规则 |
| **输出** | 非支配方案集 + 偏好条件明确的推荐方案或情景化选择 |
| **证据链** | 搜索覆盖与支配关系证据 + 推荐规则的价值判断、尺度和稳健性依据 |

## 二、预测类问题常见模式

### 模式 4：单一预测 → 误差检验

| 要素 | 说明 |
|------|------|
| **适用场景** | 数据生成机制、时序长度、频率、趋势/季节性和预测跨度允许建立可验证基线 |
| **主模型** | 根据数据机制从朴素基线、回归、指数平滑、ARIMA、灰色模型等选择；小样本本身不自动推出灰色预测 |
| **辅助分析** | 严格时间顺序的滚动/留后验证、残差诊断、区间覆盖率与基线比较 |
| **输出** | 预测值 + 有统计依据的不确定区间 + 样本外误差指标 |
| **证据链** | 模型适用条件 + 无泄漏的样本外表现 + 不确定性校准 |
| **备选方案** | 残差结构、机制冲突或基线劣化时，重新选择模型族并复验 |

### 模式 5：多候选对比或集成预测

| 要素 | 说明 |
|------|------|
| **适用场景** | 数据量充足、需要提高精度 |
| **主模型** | 从与数据规模、结构和预测目标相符的候选中选择最少充分的一种或数种 |
| **辅助分析** | 在相同数据切分、调参预算和指标下比较；仅当误差互补且样本外增益稳定时集成 |
| **输出** | 被选模型或集成结果、权重依据、样本外比较与不确定性 |
| **证据链** | 公平验证显示新增模型提供独立增益，而非模型数量本身 |
| **注意** | 确保模型间有差异才有集成价值 |

### 模式 6：组合预测（串联）

| 要素 | 说明 |
|------|------|
| **适用场景** | 先分类再预测、先分解再预测 |
| **结构** | 模型A 输出 → 模型B 输入 |
| **典型组合** | 聚类→回归（先分群再分别预测）、STL 分解→ARIMA（先分解趋势+季节+残差再分别预测） |
| **证据链** | 每一串联步骤只使用预测时可得信息，并通过端到端样本外验证证明相对基线的增益；分解本身不等于更准确 |

## 三、评价类问题常见模式

### 模式 7：赋权 + 综合评价

| 要素 | 说明 |
|------|------|
| **适用场景** | 需要确定指标权重并完成方案排序 |
| **赋权模型** | 先判断权重代表价值偏好、信息变异还是可估计效用，再选择专家判断、数据驱动、混合或不赋权方法；有数据不自动推出熵权，无数据不自动推出 AHP |
| **评价模型** | 依据可补偿性、尺度、理想点含义、不确定性和排序目的选择；TOPSIS、灰色关联或模糊评价只是候选，不是固定搭配 |
| **输出** | 权重或偏好条件、方案得分/分档/支配关系，以及合理扰动下的稳定性 |
| **证据链** | 权重依据 + 综合评价结果 |
| **检查** | 权重扰动或数据变化下的排名稳定性 |

### 模式 8：DEA 效率评价

| 要素 | 说明 |
|------|------|
| **适用场景** | 多个可比决策单元以同类投入产生同类产出，且样本规模、方向性与自由处置等 DEA 假设可辩护 |
| **主模型** | DEA（CCR / BCC 模型） |
| **辅助分析** | 投影分析 + 规模收益分析 |
| **输出** | 效率值 + 无效单元的改进目标 |
| **证据链** | 同质性与投入产出定义 + 模型方向/规模收益选择 + Bootstrap 或扰动稳定性；投影是模型目标，不自动等于现实可行改进 |

## 四、综合类问题常见模式

### 模式 9：优化 + 模拟

| 要素 | 说明 |
|------|------|
| **适用场景** | 不确定性环境下的决策 |
| **结构** | 由有依据的分布或情景生成不确定输入 → 在信息可得性与非预见性约束下优化共同决策/分阶段策略 → 用独立情景评估风险。逐场景各自求最优只给出“完全信息”基准，不能冒充可实施策略 |
| **典型应用** | 随机规划、鲁棒优化、风险评估 |
| **输出** | 可实施策略、样本外成本/收益分布、风险指标和相对确定性或完全信息基准的差距 |
| **证据链** | 分布/情景依据 + 非预见性与约束可行性 + 独立情景表现；有限模拟不能声称覆盖全部不确定性 |

### 模式 10：评价 + 优化（先评后优）

| 要素 | 说明 |
|------|------|
| **适用场景** | 先评估现状再寻找改进方案 |
| **结构** | 评价模型识别薄弱环节 → 优化模型给出改进方案 |
| **典型应用** | 先用有依据的诊断或评价识别可干预环节，再把因果关系、资源和业务约束写入优化模型；高权重不等于可优化性或因果影响 |
| **输出** | 评价结果 + 针对性优化方案 |
| **证据链** | 评价结果在扰动下稳定且对应可干预变量 + 优化方案满足因果、资源和业务约束；评分高低本身不证明干预有效 |

### 模式 11：预测 + 决策

| 要素 | 说明 |
|------|------|
| **适用场景** | 先预测趋势再做决策 |
| **结构** | 预测模型给出与决策口径一致的分布、区间或情景 → 决策模型传播预测不确定性并按真实决策损失优化 |
| **典型应用** | 需求预测→库存优化、交通流量预测→信号灯优化 |
| **输出** | 预测与校准证据、可实施决策、样本外决策损失及对预测误差的敏感性 |
| **证据链** | 无泄漏样本外预测 + 与题目目标对齐的决策回测；预测指标改善不自动推出决策收益改善 |

## 五、模型组合筛选清单

以上模式只用于生成候选，不是按题型自动套用的决策树。确定方案前至少回答：

1. 题目真正要求的是解释、估计、预测、评价、优化还是多阶段决策？评价指标是否与该目标一致？
2. 数据的生成机制、样本量、时空顺序、缺失与测量误差支持哪些假设？训练、调参和最终验证是否隔离？
3. 决策变量、约束、偏好权重和不确定性分别来自哪里？“客观权重”是否实际上只反映样本离散程度？
4. 是否存在解析解、精确算法、朴素基线、下界或小规模真值，可作为校验器而不是再堆一个相似模型？
5. 新增模型是否改变机制、假设、任务阶段或验证证据；若删去它，核心结论会损失什么？
6. 结论在边界、扰动、不同随机种子、网格/时间步和合理替代指标下是否保持？证据最多支持“可行”“样本外较优”还是某种严格最优性？

只有这些问题的答案支持某个组合时才采用，并在当前题上重新推导、实现和验证。
