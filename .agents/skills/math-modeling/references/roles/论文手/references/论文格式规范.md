# 论文格式规范

## 唯一权威来源

论文内容结构与格式必须遵循目标竞赛当届官方规则和官方模板。常用官方入口：

- 全国大学生数学建模竞赛：`http://www.mcm.edu.cn/`
- CUMCM 2026 论文格式规范：`https://www.mcm.edu.cn/upload_cn/node/775/cQMeL0YY905244c8bd4b9af832f1699446d8385e.pdf`
- MCM/ICM：`https://www.comap.com/contests/mcm-icm`

竞赛规则可能更新。生成前必须确认届次和官方文件版本，不能把本 Skill 的默认值当作永久规则。

### CUMCM 篇幅的硬约束与质量目标

- 2026 年官方《全国大学生数学建模竞赛论文格式规范》规定摘要原则上不超过一页、正文不超过 30 页；正文之后的附录页数不限。完整可运行源码和支撑材料文件列表须放在论文附录中。
- 电子版论文必须包含附录，没有PDF总页数上限，单文件大小不超过20MB；另行提交的支撑材料RAR/ZIP也不超过20MB，并至少包含全部可运行源码等必要材料。
- 工具默认以渲染后的摘要版面充实度和正文恰好30页作为CUMCM优选完整度目标；固定字词数只作辅助诊断，30页整也是用户可覆盖的质量建议，不是官方最低要求。正文扩展必须来自必要推导、验证、图表和结果分析，不能注水凑页。
- 正文页数必须在渲染后按附录起始页单独统计，不能用PDF总页数代替，也不能根据字符数猜测。
- 官方没有规定代码附录占论文总页数的比例。不得设置“代码不超过全文20%”等硬限制；获奖案例的版面比例只能作为阅读体验参考，不能覆盖完整源码和附录页数不限的明文规则。
- 默认让摘要、正文、参考文献和代码附录保持统一的 A4 竖版单栏版式，并使用正常可读字号。附录页数不限时，不得仅为缩短页数擅自采用横版、双栏或极小字号；只有官方模板、特殊超宽对象或用户明确要求时才使用其他方向或栏数，并须逐页渲染检查阅读效果。
- 一级标题默认连续排版，不逐章设置“段前分页”。只在摘要到正文、正文到附录等结构边界，或为避免标题孤行、表格严重拆分等明确版面问题时分页；不得用强制分页制造页尾空白来达到页数目标。
- 图形可分为真实结果图和方法解释图。算法流程图、模型结构图、几何解释图、变量关系图和验证逻辑图可用 Python、矢量或流程图工具生成，不要求与主求解语言相同；所有图必须与最终模型一致并在正文引用，解释图不得冒充数值结果。

## 模板驱动生成

推荐流程是“官方参考模板 + `python-docx` 内容构建 + OMML 公式 + 结构校验 + 渲染抽检”。

```python
from pathlib import Path
import sys

skill_root = Path("<SKILL_ROOT>")
sys.path.insert(0, str(skill_root / "tools" / "docx" / "scripts"))
import paper_format as pf

doc = pf.new_document(
    contest="cumcm",
    template_path=Path("<PROJECT_ROOT>") / "当届官方模板.docx",
    preserve_template_content=False,
)
pf.title(doc, "论文题目")
pf.abstract_title(doc)
pf.body(doc, "摘要正文。")
pf.keywords(doc, "关键词一；关键词二")
pf.save_document(doc, Path("<PROJECT_ROOT>"), contest="cumcm")
```

传入模板时，`paper_format.py` 保留模板的样式、分节和页面设置。官方模板含固定摘要页、编号页或占位符时使用 `preserve_template_content=True` 并在原位填充；只借用样式时使用默认值清除示例正文。未提供官方模板时，`cumcm` 和 `mcm-icm` 配置仅提供构建基线，必须再与当届官方规则核对。

## 公式

- 使用 `paper_format.equation()` 或 `equations.py` 写入 Word 原生 OMML。
- 支持常用希腊字母、关系符号、反三角函数、分式、根式、上下标、矩阵与分段表达式，包括 `\nu`、`\mu`、`\approx`、`\arcsin`、`\arccos` 和 `\arctan`；未知命令、未闭合分组和不支持环境会明确失败。
- 复杂公式优先使用 Pandoc 的成熟 LaTeX→OMML 转换，再进行 DOCX 校验。
- 最终公式必须可编辑，不能是截图或纯文本 LaTeX。

## 表格与图

- 表格必须可编辑；三线表使用 `three_line_table()`。
- 图来自编程手真实运行结果，可从候选图中选择。
- 每幅图和每个表必须有连续编号与题注，并在正文中至少引用一次；单位和数值必须一致。

## 校验

```powershell
python ../../../../tools/docx/scripts/check_env.py
python ../../../../tools/docx/scripts/self_check.py
python ../../../../tools/docx/scripts/office/validate.py "<PROJECT_ROOT>/完整论文.docx"
```

生成后调用：

```python
issues = pf.validate_paper_structure(
    doc,
    contest="cumcm",
    rendered_pages=PDF总页数,
    rendered_body_pages=正文页数,
    abstract_fill_ratio=摘要页有效区域填充率,
    electronic_file_size_bytes=电子论文文件字节数,
)
```

该检查会报告正文篇幅、摘要渲染填充率、公式/图/表数量、图表编号与正文引用、参考文献双向对应、正文页数和电子文件大小问题。默认摘要有效区域填充率不低于约85%、正文以30页整为优选目标、公式5个、图3幅、表3个均为质量目标；2026年CUMCM正文30页和电子论文20MB属于官方硬约束，附录与PDF总页数不设上限。摘要填充率须按最终字号、行距、边距和关键词布局渲染后估算，不以固定字数替代。使用其他届次或竞赛时必须传入相应阈值。OOXML校验通过后仍需渲染抽检，因为XML合法不等于版面正确。
