# 论文自审框架

## 一、官方规则

- [ ] 已记录目标竞赛、届次、官方规则和官方模板来源。
- [ ] 页面、摘要页、编号、页数、字体、提交格式等逐项符合当届官方文件。
- [ ] 未把本 Skill 默认值或往届经验写成官方规定。

## 二、内容与证据

- [ ] 每个结论都有真实代码结果、图表、公式或文献支撑。
- [ ] 摘要中的数值与正文、表格、图和复现清单一致。
- [ ] 摘要按问题1至问题n分别成段或成行，每题核心方法与最终结果均为原生粗体，并覆盖验证和适用边界。
- [ ] 问题背景和逐题重述均存在，且已与题面及附件说明逐项核对，无遗漏、虚构或假设冒充条件。
- [ ] 每道子问题使用最少充分的模型体系；新增模型有独立证据价值，同一机制的不同近似按模型族说明清楚。
- [ ] 没有虚构背景数据或未核验引用。
- [ ] 局限和适用边界具体、可追溯。
- [ ] 模型评价的优势与局限均来自证据，不为条目数或篇幅比例删减、夸大或掩盖发现；局限说明影响范围和改进方向。
- [ ] 未把会使核心结论失效的重大缺陷留在论文中；发现此类问题时已回退修复、补证或替换模型，也没有隐瞒已知问题。

## 三、文档结构

- [ ] 公式是可编辑 OMML，无纯文本 LaTeX 和公式截图。
- [ ] 已核对正文篇幅与渲染页数；官方硬约束和非官方质量目标已明确区分。
- [ ] 摘要在不改变官方字号、页边距和行距的前提下达到项目声明的信息密度目标；未用空话、重复、参数清单或版式膨胀填页。
- [ ] 摘要和正文满足当届官方硬约束及发布清单中有依据的质量目标；未把往届页数、填充率或数量经验当成当前默认值。
- [ ] 公式、图和表的数量与各子问题论证需要相匹配，不是只有文字结论。
- [ ] 表格可编辑，每幅图和每个表都有连续编号、题注及正文引用，没有孤儿图表。
- [ ] 参考文献与正文引用双向对应，DOI 和出版信息已核验。
- [ ] 不含 `[待补充]`、模板示例正文或临时占位符。

## 四、技术验证

- [ ] `self_check.py` 通过。
- [ ] `office/validate.py` 通过。
- [ ] 渲染抽检通过，分页、页眉页脚、公式和图表无异常。
- [ ] 已交付 `PROJECT_ROOT/完整论文.docx`；当届官方提交格式包含 PDF 时，另有同一门禁发布的 `PROJECT_ROOT/完整论文.pdf`，没有把候选稿或检查日志混入交付。
