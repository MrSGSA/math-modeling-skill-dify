# 论文写作规范

- 术语和符号严格服从 `术语表格.md`。
- 每段围绕一个明确论点，先给事实或推理，再解释其含义。
- 数值、单位、公式、图号、表号和引用前后一致。
- 不使用“专家认为”“效果显著”等无来源表述。
- 不用宣传性语言代替证据；创新点必须对应具体方法、实现和验证。
- 不虚构数据、实验、文献或官方要求。
- 两个模型得到相近结论时，如有比较价值，可如实保留并解释。
- 摘要按全部子问题逐行或逐段组织，每题突出“方法—结果—验证”，方法名称与最终结果使用原生粗体；信息密度优先于一般背景铺陈。
- 问题背景和问题重述必须与题面逐项一致。可以贴近题面重新表述，但不能遗漏输入、条件、任务与输出，不能把后续假设提前写成已知条件。
- 用户提供或授权优秀论文时，学习其章节节奏、图表组织、公式解释与结果呈现；先锁定独立版本，只吸收经题面、代码和格式核验的写法，不复制案例数值、错误或专有措辞。
- 模型评价围绕证据、适用边界和改进路径组织；优势与局限的条目数及篇幅由真实发现和决策影响决定，不设固定比例。局限写具体、不重复、不泛化，并说明影响范围；重大缺陷必须在成稿前修复或更换模型，不留到评价部分。
- 中文或英文表达服从目标竞赛和用户要求。
